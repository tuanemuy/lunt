# 申立て・連絡・非公開 テスト

## 概要

このドキュメントは、取り下げの申立てとその対応、申立てで写真が削除された対象の再公開、情報の誤り・閉店の連絡とその対応、店舗管理者による確認、サービス運営者による運営による非公開・店舗の非公開・重複する店舗の整理に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/moderation.md`

画面名・画面 ID・共通の状態（CS）・共通の機能（CF）は `spec/pages/` の用語に従う。期待結果の「CS-xx の状態」は `spec/pages/index.md` の「共通の状態」が定める内容を指す。画面に示す文面は pages が定めないため、期待結果は画面の状態・示される内容・遷移先で書く。

テストケースの ID は追加の順に振っているため、文書の中の並びと番号の順が違う箇所がある。TC-MOD-113 は欠番。
