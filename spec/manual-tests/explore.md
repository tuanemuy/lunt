# 探索と詳細 テスト

## 概要

このドキュメントは、閲覧者が地図・地域・イベント・読みものから対象を探し、掲載・店舗・地域・イベント・記事の詳細を読み、関係のある対象をたどる操作に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/explore.md`（EXP-01〜EXP-12）

対象画面: VW-04 マップ、VW-05 まち、VW-06 地域内の一覧、VW-07 イベントの一覧、VW-08 参加店舗マップ、VW-09 読む（`spec/pages/browse.md`）、DT-01 掲載詳細〜DT-05 記事（`spec/pages/detail.md`）。詳細から始める手続きは、入口と、入口から開いた画面の始まりの状態までを扱う。

ID は追加の順に振っているため、文書の中の並びと番号の順が違う箇所がある（TC-EXP-086・TC-EXP-087 は TC-EXP-003 の後、TC-EXP-083 は TC-EXP-016 の後、TC-EXP-084 は TC-EXP-060 の後、異常系の TC-EXP-001 は正常系の最後の TC-EXP-038 の後、境界値の TC-EXP-010 は TC-EXP-040 の後にある）。

### 事前準備

1. 他の文書のテストデータを残さず、discover.md の基本データとこの文書の追加のデータだけを投入した環境で始める（同じメールアドレス・名称が他の文書では別の立場・状態を持つ）
2. discover.md の「事前準備」の2〜4を行う
3. 追加の店舗を、サービス運営者の代理登録（OM-02 で登録する店舗の名称を探し、結果（「結果」または CS-09）の代理登録の入口から開く SM-02 の新規）またはテスト環境のデータ投入で用意し、Y1〜Y4 を R1 に所属させる（所属の申請の承認、またはデータ投入）
4. 各テストケースの始めに、ブラウザ1の Chrome のサイト設定でテスト環境の位置情報を「確認する（デフォルト）」に戻し、DevTools の Sensors の Location を「No override」にする（位置情報の許可と Sensors の上書きは、サイトデータの消去では戻らない）。各テストケースは、特に書かない限り、ブラウザ1で新しいタブを開き、そのタブで DevTools を開いて（Sensors の Location は No override）から、Lunt のトップの URL を開いた状態から始める（ログインしない、条件なし、現在地を利用していない）。テストケースの事前準備の Sensors・Network の設定は、このタブで行う。ブラウザ1でログインしたテストケースの後は、ブラウザ1のテスト環境のサイトデータを消去してから次へ進む
5. テストデータを変えるテストケースは、確認ポイントに戻し方を書く。テスト環境の時刻を進めたテストケースは、確認ポイントで時刻を戻す。戻してから次のテストケースへ進む
6. 「存在しない URL」は、そのテストケースで控えた閲覧側の詳細の URL の ID の部分を、同じ形式のまま末尾の1文字だけ別の英数字に変えた、存在しない ID の URL を指す（ID の形式は変えない）
7. 手順が経路を書かずに「{対象} の DT-0n を開く」と書くときは、そのブラウザで Lunt のトップ（VW-01）の検索の入口から VW-03 を開き、対象の名称で検索して結果から開く（VW-03 は参照の場面で、閉店・提供開始前・提供終了・終了・中止の対象も状態とともに示す。scenario/index.md「表示範囲」）。VW-01 へは、開いている画面の下部ナビゲーションの「みつける」で同じタブの中を移る（選択中の条件は保たれる）。下部ナビゲーションを示さない画面（MY-01 など）からは、同じブラウザで新しいタブを開いて Lunt のトップを開く。閲覧できない対象の詳細は、そのテストケースが控えた URL で開く
8. 手順の「{タブ画面（VW-01・VW-04・VW-05・VW-09・VW-10）}を開き直す」は、同じタブで下部ナビゲーションの別の項目へ進み、続けて元の項目を選ぶことを指す（選択中の条件は CF-03 のとおり閲覧中の画面の間で保たれる）
