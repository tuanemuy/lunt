# 発見 テスト

## 概要

このドキュメントは、閲覧者がフィードを眺め、エリア・カテゴリーの絞り込み、キーワード、現在地で対象を探す操作に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/discover.md`（DIS-01〜DIS-06）

対象画面: VW-01 みつける、VW-02 絞り込み、VW-03 検索（`spec/pages/browse.md`）。遷移先の詳細（DT-01〜DT-05）とマップ（VW-04）・まち（VW-05）は、条件と現在地の共有を確かめる範囲で扱う。

ID は追加の順に振っているため、文書の中の並びと番号の順が違う箇所がある（TC-DIS-059 は TC-DIS-023 の後、TC-DIS-053・TC-DIS-057・TC-DIS-058 は正常系の最後の TC-DIS-027 の後、TC-DIS-060 は境界値の最後の TC-DIS-056 の後にある）。TC-DIS-051 は欠番（番号は詰めない）。

### 環境

- ブラウザ1: Google Chrome（通常のウィンドウ）。閲覧者の操作に使う。ログインしない
- ブラウザ2: Google Chrome のシークレットウィンドウ、または Firefox。管理側の操作（店舗管理者・地域運営者・イベント運営者・編集担当者・サービス運営者）に使う
- 位置情報は Chrome の DevTools の「Sensors」で上書きする。「現在地 X」は緯度 35.6812、経度 139.7671（東京駅）を指す
- 通信エラーは DevTools の「Network」で「Offline」に切り替えて起こす。読み込み中の確認には、Network の通信を遅くするプリセット（「3G」「Slow 3G」など、読み込み中の表示を目で確かめられる程度に遅いもの）を使う
- Sensors の Location の上書きと Network の設定は、DevTools を開いているタブにだけ効き、DevTools を閉じると外れる。手順と事前準備の Sensors・Network の設定は、その手順を行うタブで DevTools を開いて行い、テストケースの間そのタブの DevTools を閉じない。新しいタブで位置情報の上書きを使う手順は、新しいタブを開いてそのタブで DevTools を開き、Sensors を設定してから Lunt の URL を開く

- 日次のジョブ（掲載の提供終了の検出など）は、手順が実行を指示したときだけ動く（テスト環境で自動の実行を止めておく）。この文書の手順は日次のジョブの実行を指示しない
- 周辺の半径（設定値）が 2 km 以上 300 km 未満である。この範囲なら、現在地 X の周辺（地域の一覧）にも、周辺の円を囲む地図の範囲にも R1・R2・R4 が入り、大阪の S3・R3 はどちらにも入らない。違う場合は、下の位置を、R1・R2・R4 が周辺に入り、R3 が周辺にも地図の範囲にも入らないように読み替える
