# 掲載 テスト

## 概要

このドキュメントは、店舗管理者による掲載の作成・写真・提供の設定・公開・状態の変更・複製・削除と、管理者のいない店舗の掲載の申請・修正の申請、サービス運営者による申請の判断・代理作成・不在の代行に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/listing.md`

| 種別 | 件数 |
| --- | --- |
| 正常系 | 32 |
| 異常系 | 83 |
| 境界値 | 5 |
| 合計 | 120 |

ID は追加の順に振っているため、文書の中の並びと番号の順が違う箇所がある（TC-LST-110〜TC-LST-121）。TC-LST-004 は欠番。

## 前提条件

### 環境

- テスト環境の Lunt を、Cookie を共有しない3つのブラウザ（以下「ブラウザ1」「ブラウザ2」「ブラウザ3」。別のブラウザ、または別のプロファイル）で開ける。ブラウザ3 は閲覧者と申立人の専用で、ログインせず、事前準備の手順7から TC-LST-065 まで Cookie とサイトデータを消去しない（端末の保存を残すため。シークレットウィンドウは閉じると端末の保存が消えるので、ブラウザ3 には使わない）
- テスト環境で受け取ったメールを読める（ログインのコード、招待のメール、申立ての結果のメール）
- ドメインイベントのリレーと消費者（申請の前提の再評価による失効）が動いている。申請の失効は非同期に反映されるため、反映されるまで待ち、画面を読み込み直して確かめる
- ブラウザの開発者ツールで、ネットワークをオフラインに切り替えられる（TC-LST-018）
- テスト環境の時刻を進め、戻せる。テスト環境で日次のジョブ（掲載の提供終了の検出）を実行できる。日次のジョブは、手順が実行を指示したときだけ動く（テスト環境で自動の実行を止めておく）。時刻を進めるのは TC-LST-029 の、日本時間の翌日の 0 時 30 分までだけで、TC-LST-030 の後始末で戻す（TC-LST-029、TC-LST-030）
- 郵便番号・町域のデータに `110-0001`（東京都台東区谷中）が入っている
- 写真用のファイル: `coffee-1.jpg`、`coffee-2.jpg`、`coffee-3.jpg`、`cake-1.jpg`、`tenugui-1.jpg`、`tenugui-2.jpg`、`tenugui-3.jpg`、`furin-1.jpg`、`new-1.jpg`、`new-2.jpg`、`mado-1.jpg`、`mug-1.jpg`、`dango-1.jpg`、`kuzumochi-1.jpg`、`ginza-1.jpg`（いずれも JPEG の静止画）。写真として扱えないファイル: `menu.pdf`（PDF）、`movie.mp4`（動画）。写真用のファイルは、それぞれ見た目で区別できる画像にする（例: ファイル名を画像の中に大きく描き込む）。期待結果の「`{ファイル名}`」は、写真に描き込んだ名前で確かめる

日付は、テストを実行する日を「今日」とし、「今日+7日」のように相対で書く。日付は日本時間の暦日。

### アカウント

ログインは MY-02 でメールアドレスを入力し、テスト環境で受け取ったメールのコードで行う。Lunt にはログアウトの操作がないため、1つのブラウザで利用者を替えるときは、次のどちらかで行う。

- (a) そのブラウザの Cookie とサイトデータを消去し、MY-01 のログインから、替える利用者のメールアドレスでログインする
- (b) 別のブラウザの MY-02 で、替える利用者のメールアドレスを送り、テスト環境で受け取ったメールのリンクをこのブラウザで開く（リンクを開いたブラウザでログインが成立し、そのブラウザのアカウントが切り替わる）

手順の「{利用者}（{ブラウザ}）で」「{利用者}（{ブラウザ}）でログインし」は、そのブラウザでその利用者としてログインしている状態で操作することを指す。そのブラウザが別の利用者でログインしていれば、先に (a) か (b) で替える。ブラウザ3 は替えない。「閲覧者（ブラウザ3）で」はログインしていないブラウザ3 で操作することを、「ログインしていないブラウザ1 で」はブラウザ1 の Cookie とサイトデータを消去してから操作することを指す。前提の準備は、書いてある利用者として、書いてあるブラウザ（書いていなければ、店舗管理者と利用者はブラウザ1、サービス運営者はブラウザ2）で行う。

閲覧側の「{店舗}の DT-02」「{掲載}の DT-01」「{イベント}の DT-04」「{地域}の DT-03」は、そのブラウザで VW-03 を開き、対象の名称で検索して結果から開くことを指す（地域は VW-05 から開いてもよい）。閲覧できない対象の詳細は、そのテストケースが控えた URL で開く。
