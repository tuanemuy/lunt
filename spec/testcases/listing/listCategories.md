# listCategories

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 開設時のカテゴリーが入っている | 読む | 「食べる」「買う」「体験」「見る」の4つが、作成順で返る。1階層で、親子を持たない（AC-03、AC-49） | |
| カテゴリー「泊まる」が追加されている | 読む | 「泊まる」が並びの最後に返る | |
| カテゴリー「体験」が廃止されている | 読む | 「体験」は返らない。残りは作成順のまま | |
| カテゴリー「買う」の名称が「買いもの」に変更されている | 読む | 「買いもの」が、「買う」のあった位置で返る | |
| 保存された台帳がない | 読む | 空の並びが返る | |
