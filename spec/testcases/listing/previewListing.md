# previewListing

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 A の下書きに、写真2枚（1枚目に見せる範囲）、名称、カテゴリー、説明、提供期間がある。店舗 A は公開中の地域 R に所属している。操作する人は店舗 A の店舗管理者 | 見え方を確認する | 代表写真（1枚目）と見せる範囲、写真の並び、名称、店舗 A の名称、地域 R の名称、カテゴリー、説明、提供期間が返る。価格とキャッチコピーは含まれない。掲載は変わらず、`draft` のまま（AC-10、AC-38、AC-59） | |
| 店舗 A の一時非公開の掲載がある | 見え方を確認する | 保存済みの内容が同じ形で返る。公開状態は一時非公開と分かる | |
| 店舗 A の代表地域は公開を取り下げていて、店舗 A はほかに公開中の地域 S に所属している | 見え方を確認する | 地域の名称は地域 S で返る | |
| 店舗 A はどの地域にも所属していない | 見え方を確認する | 地域の名称なしで返る | |
| 店舗 A の下書きに写真がない | 見え方を確認する | 保存済みの内容が返る。確認は公開条件を確かめない | |
| 店舗 A の下書きが、運営による非公開になっている | 見え方を確認する | 内容が返り、運営による非公開であることが分かる | |
| 店舗 A が非公開になっている | 店舗 A の下書きの見え方を確認する | 内容が返り、店舗が非公開であることが分かる | |
| 別の店舗管理者が、先に同じ下書きを公開している | 見え方を確認する | 内容が返り、公開状態は `published` と分かる | |
| 店舗 B に店舗管理者がいない。操作する人はサービス運営者 | 店舗 B の下書きの見え方を確認する | 内容が返る | |
| 操作する人は店舗 A の管理権限を持たない利用者 | 店舗 A の下書きの見え方を確認する | `ForbiddenError` | |
| 掲載が削除されている | 見え方を確認する | `NotFoundError` | |
