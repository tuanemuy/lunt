# endListingOffering

日付に関わるケースは、今日を日本時間の 2026-07-10 とする。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 A の公開中の掲載がある。提供の設定は「設定しない」。操作する人は店舗 A の店舗管理者 | 提供終了にする | `manualEnd` が `{ ended: true; endedAt: 操作の日時 }` になる。提供状態は管理する人による提供終了。公開状態は `published` のまま。ドメインイベントは出ない（AC-58） | |
| 店舗 A の公開中の掲載の提供期間が 2026-07-01〜2026-08-31 | 提供終了にする | 提供状態は管理する人による提供終了になる。提供期間は変わらない | |
| 店舗 A の公開中の掲載が、運営による非公開になっている | 提供終了にする | 成立する。運営による非公開と公開状態は変わらない | |
| 店舗 B に店舗管理者がいない。操作する人はサービス運営者 | 店舗 B の公開中の掲載を提供終了にする | 成立する | |
| 店舗 A の公開中の掲載を、店舗管理者がすでに提供終了にしている | もう一度提供終了にする | `BusinessRuleError`（`LISTING_ALREADY_ENDED`）。`endedAt` は変わらない | |
| 店舗 A の下書きの掲載と、一時非公開の掲載がある | それぞれを提供終了にする | どちらも `BusinessRuleError`（`LISTING_NOT_PUBLISHED`）。掲載は変わらない（提供終了にできるのは公開中の掲載だけ） | |
| 店舗 A に店舗管理者がいる。操作する人は店舗 A の管理権限を持たないサービス運営者 | 店舗 A の公開中の掲載を提供終了にする | `ForbiddenError`。掲載は変わらない | |
| 操作する人は店舗 A の管理権限を持たない利用者 | 店舗 A の公開中の掲載を提供終了にする | `ForbiddenError`。掲載は変わらない | |
| 別の店舗管理者が掲載を削除している | 提供終了にする | `NotFoundError` | |
