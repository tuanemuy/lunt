# provisionInitialCategories

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 保存された台帳がない | 実行する | 台帳に、現役のカテゴリー「食べる」「買う」「体験」「見る」がこの順で入る。ドメインイベントは出ない（AC-49） | |
| 初期値の4つが入っている | もう一度実行する | 成功として扱う。台帳は書き込まれず、カテゴリーは4つのまま | |
| 開設の後に、カテゴリーの追加と廃止が行われている | 実行する | 成功として扱う。台帳は変わらない | |
| 保存された台帳がない | 同時に2つ実行する | 台帳に入るカテゴリーは初期値の4つだけ。一方の書き込みだけが確定する | |
