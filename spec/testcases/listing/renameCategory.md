# renameCategory

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 現役のカテゴリー「買う」があり、「買う」を設定した公開中の掲載がある。操作する人はサービス運営者 | 「買う」の名称を「買いもの」に変更する | 名称が「買いもの」になる。作成順は変わらない。掲載は書き込まれず、掲載の `categoryId`・公開状態・提供状態は変わらない。`getManagedListing` は、その掲載のカテゴリーを「買いもの」で返す。ドメインイベントは出ない | |
| カテゴリー「体験」が廃止済み。現役のカテゴリー「見る」がある | 「見る」の名称を「体験」に変更する | 変更できる。重複を確かめる相手は現役のカテゴリーだけ | |
| 現役のカテゴリー「買う」がある | 「買う」の名称を、同じ「買う」に変更する | 成功する。台帳は書き込まれない | |
| 現役のカテゴリー「買う」がある | 「買う」の名称を空にして変更する | `BusinessRuleError`（`CATEGORY_INVALID_NAME`）。台帳は変わらない | |
| 現役のカテゴリー「買う」と「見る」がある | 「買う」の名称を「見る」に変更する | `BusinessRuleError`（`CATEGORY_NAME_TAKEN`）。台帳は変わらない | |
| 変更しようとしたカテゴリーを、別のサービス運営者がすでに廃止している | 名称を変更する | `BusinessRuleError`（`CATEGORY_RETIRED`）。台帳は変わらない | |
| 指定した `CategoryId` が台帳にない | 名称を変更する | `BusinessRuleError`（`CATEGORY_NOT_FOUND`） | |
| 2人のサービス運営者が、同じ版の台帳を読んでいる | 同時に、別々のカテゴリーの名称を変更する | 一方が成立し、他方は `ConflictError`。他方の変更は反映されない | |
| 操作する人はサービス運営者の役割を持たない | 名称を変更する | `ForbiddenError`。台帳は変わらない | |
