# duplicateListing

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 A の公開中の掲載に、名称・説明・カテゴリー・写真2枚（1枚目に見せる範囲）・提供期間がある。操作する人は店舗 A の店舗管理者 | 新しい `ListingId` を指定して複製する | 店舗 A の `draft` の掲載ができる。名称・説明・カテゴリー・写真の並び順と見せる範囲を引き継ぐ。写真は新しい `PhotoId` の複製で、`stored` になり、持ち主は新しい掲載。提供の設定は「設定しない」。元の掲載と、元の写真の持ち主は変わらない。ドメインイベントは出ない（AC-58） | |
| 店舗 A に、下書き、一時非公開、提供終了の掲載がある | それぞれを複製する | どれも、同じ店舗の新しい下書きができる | |
| 店舗 A の下書きに写真がない | 複製する | 写真のない新しい下書きができる | |
| 元の掲載に保存されたカテゴリーが廃止済み | 複製する | 新しい下書きのカテゴリーは、移行先の現役のカテゴリーになる | |
| 店舗 B に店舗管理者がいない。操作する人はサービス運営者 | 店舗 B の掲載を複製する | 新しい下書きができる | |
| 店舗 A の公開中の掲載が、運営による非公開になっている。操作する人は店舗 A の店舗管理者 | 複製する | 同じ店舗の新しい下書きができる。新しい下書きは運営による非公開ではない。元の掲載は運営による非公開のまま変わらない | |
| 元にする掲載を、別の店舗管理者が削除している | 複製する | `NotFoundError`。新しい掲載は作られない | |
| 操作する人は店舗 A の管理権限を持たない利用者 | 店舗 A の掲載を複製する | `ForbiddenError`。新しい掲載は作られず、写真は複製されない | |
| 同じ元の掲載と同じ新しい `ListingId` の複製が、すでに成立している | 同じ要求を送り直す | 成功として扱う。書き込みはなく、写真は複製されない。新しい掲載は1件のまま | |
| 複製が成立した後に、店舗管理者が新しい下書きの内容を保存している | 同じ要求を送り直す | 成功として扱う（同じ店舗の掲載）。保存した内容は変わらない | |
| 指定した新しい `ListingId` と同じ ID の、別の店舗の掲載がすでにある | 複製する | `ConflictError`。新しい掲載は作られず、すでにある掲載は変わらない。写真は複製されず、元の掲載と元の写真は変わらない | |
