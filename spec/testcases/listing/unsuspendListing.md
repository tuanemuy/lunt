# unsuspendListing

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中だった掲載が、運営による非公開になっている。操作する人はサービス運営者 | 解除する | `suspension` が `{ suspended: false }` になる。公開状態は `published` がそのまま現れる。`listing.unsuspended`（`listingId`、`placeId`）が出る（AC-64） | |
| 一時非公開だった掲載が、運営による非公開になっている | 解除する | 公開状態は `unpublished`（`byManager`）がそのまま現れる | |
| 下書きだった掲載が、運営による非公開になっている | 解除する | 公開状態は `draft` がそのまま現れる | |
| 公開中だった掲載が、運営による非公開の間に、申立てで最後の写真が削除された | 解除する | 公開状態は `unpublished`（`photoTakedown`）で現れる。写真を登録して再公開するまで `published` に戻らない（AC-79） | |
| 運営による非公開の間に、店舗管理者が掲載の内容を保存した | 解除する | 保存した内容と、運営による非公開にする前の公開状態で現れる | |
| 別のサービス運営者が、先に解除している | 解除する | `BusinessRuleError`（`LISTING_NOT_SUSPENDED`）。ドメインイベントは出ない | |
| 操作する人は店舗 A の店舗管理者で、サービス運営者の役割を持たない | 店舗 A の掲載の運営による非公開を解除する | `ForbiddenError`。掲載は運営による非公開のまま（AC-64） | |
| 運営による非公開の間に、店舗管理者が掲載を削除した | 解除する | `NotFoundError` | |
