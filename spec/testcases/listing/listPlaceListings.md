# listPlaceListings

今日を日本時間の 2026-07-10 とする。

基本の前提: 店舗 A に次の7件の掲載がある。操作する人は店舗 A の店舗管理者。

- L1: 公開中で提供中
- L2: 公開中で提供開始前（開始日 2026-07-20）
- L3: 下書き（提供の設定なし）
- L4: 一時非公開（提供の設定なし）
- L5: 公開中で提供中、運営による非公開
- L6: 公開中で、終了日 2026-06-30 を過ぎた提供終了
- L7: 公開中で、店舗管理者が提供終了にした

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 基本の前提 | 公開状態の区分も提供状態の段階も指定せずに読む | 7件すべてが、更新の新しい順に返る。掲載ごとに、代表写真、名称、カテゴリー、公開状態、運営による非公開、提供状態が分かる。公開状態の区分ごとの件数は、公開中4・下書き1・非公開2。提供状態の段階ごとの件数は、提供開始前1・提供中4・提供終了2（AC-58） | |
| 基本の前提 | 公開状態の区分「公開中」で読む | L1、L2、L6、L7 が返る。L2 は提供開始前、L6・L7 は提供終了と分かる（AC-58） | |
| 基本の前提 | 公開状態の区分「下書き」で読む | L3 が返る（AC-58） | |
| 基本の前提 | 公開状態の区分「非公開」で読む | L4 と L5 が返る。一時非公開と運営による非公開が区別できる（AC-58） | |
| 基本の前提 | 提供状態の段階「提供終了」で読む | L6 と L7 が返る。期日による提供終了と、管理する人による提供終了が区別できる（AC-58） | |
| 店舗 A の下書きが、運営による非公開になっている | 公開状態の区分「非公開」と「下書き」で読む | その掲載は「非公開」にだけ現れる。どの掲載も、公開中・下書き・非公開のちょうど1つに入る | |
| 店舗 A の公開中の掲載の終了日が 2026-07-09 | 提供状態の段階「提供終了」と、公開状態の区分「公開中」で読む | その掲載はどちらにも返る。段階と件数は今日の暦日で決まる | |
| 基本の前提 | 公開状態の区分「公開中」と提供状態の段階「提供終了」を併せて読む | L6 と L7 が返る（2つの条件の両方に合う掲載） | |
| 基本の前提 | 提供状態の段階「提供開始前」で読む | L2 が返る | |
| 店舗 A の一時非公開の掲載の終了日が 2026-06-30 | 提供状態の段階「提供終了」と、公開状態の区分「非公開」で読む | その掲載はどちらにも返る（提供終了は公開状態を問わない） | |
| 店舗 A に掲載が1件もない | 読む | 空の一覧が返る。公開状態の区分ごと・提供状態の段階ごとの件数はすべて0 | |
| 店舗 A に公開中の掲載だけがある | 公開状態の区分「下書き」で読む | 空の一覧が返る。件数は、絞り込みにかかわらず店舗のすべての掲載で数える（公開中の件数を保つ） | |
| 店舗 B には、管理者のいなかった時期に、代理作成で公開された掲載、申請の承認で公開された掲載、サービス運営者が保存した下書きがある。その後、操作する人が店舗 B の店舗管理者に就いた | 店舗管理者が店舗 B の掲載を読む | 3件すべてが返る（AC-30） | |
| 操作する人は店舗 A と店舗 C の店舗管理者。どちらの店舗にも掲載がある | 店舗 A、店舗 C のそれぞれを指定して読む | 指定した店舗の掲載だけが返る（AC-37） | |
| 店舗 B の最後の店舗管理者が辞任し、店舗 B に下書きを含む掲載が残っている。操作する人はサービス運営者 | 店舗 B の掲載を読む | 下書きを含むすべての掲載が返る | |
| 店舗 A に店舗管理者がいる。操作する人は店舗 A の管理権限を持たないサービス運営者 | 店舗 A の掲載を読む | `ForbiddenError` | |
| 操作する人は店舗 A の管理権限を持たない利用者 | 店舗 A の掲載を読む | `ForbiddenError` | |
| 操作する人はサービス運営者 | 存在しない `PlaceId` を指定して読む | `NotFoundError`（空の一覧を返さない） | |
