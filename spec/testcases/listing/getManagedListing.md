# getManagedListing

日付に関わるケースは、今日を日本時間の 2026-07-10 とする。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 A の公開中の掲載がある。操作する人は店舗 A の店舗管理者 | 掲載を読む | 内容（名称、説明、カテゴリー、写真の並びと見せる範囲と表示用の参照、提供の設定）、版、公開状態 `published`、運営による非公開でないこと、提供状態を返す。この掲載を管理できることが分かる | |
| 店舗 A の下書き、一時非公開の掲載がある | それぞれを読む | 閲覧者に表示されない掲載も返る。公開状態が区別できる | |
| 掲載に保存されたカテゴリーが廃止済み | 掲載を読む | カテゴリーは、移行先の現役のカテゴリーで返る | |
| 掲載のカテゴリーの名称が変更された | 掲載を読む | カテゴリーは新しい名称で返る | |
| 店舗 A の公開中の掲載が、運営による非公開になっている | 掲載を読む | 運営による非公開であることと、公開状態 `published` が併せて返る | |
| 店舗 A の掲載が、申立てによる写真の削除で一時非公開になっている | 掲載を読む | 公開状態は `unpublished`、理由は `photoTakedown` で、店舗管理者の操作による一時非公開（`byManager`）と区別できる | |
| 店舗 A の公開中の掲載が、終了日 2026-06-30 を過ぎている | 掲載を読む | 提供状態は期日による提供終了（`cause: "schedule"`） | |
| 店舗 A の公開中の掲載を店舗管理者が提供終了にしていて、終了日 2026-06-30 も過ぎている | 掲載を読む | 提供状態は管理する人による提供終了（`cause: "manual"`）で、期日も過ぎていること（`scheduleElapsed: true`）が分かる | |
| 店舗 A の公開中の掲載の開始日が 2026-07-20 | 掲載を読む | 提供状態は提供開始前で、開始日が分かる | |
| 店舗 A が非公開になっている | 店舗 A の掲載を読む | 掲載が返る | |
| 店舗 B の掲載は、店舗管理者のいなかった時期にサービス運営者が代理作成した。その後、操作する人が店舗 B の店舗管理者に就いた | 店舗管理者がその掲載を読む | 自分で作成した掲載と同じ形で返る（AC-30） | |
| 店舗 B に店舗管理者がいない。操作する人はサービス運営者 | 店舗 B の掲載を読む | 掲載が返る。店舗管理者がいないことと、この掲載を管理できることが分かる | |
| 店舗 A に店舗管理者がいる。操作する人は店舗 A の管理権限を持たないサービス運営者 | 店舗 A の掲載を読む | 掲載が返る。店舗管理者がいることと、この掲載を管理できないことが分かる | |
| 操作する人は、店舗 A の管理権限もサービス運営者の役割も持たない利用者 | 店舗 A の掲載を読む | `ForbiddenError` | |
| 掲載が削除されている | 掲載を読む | `NotFoundError` | |
