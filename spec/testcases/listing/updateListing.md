# updateListing

日付に関わるケースは、今日を日本時間の 2026-07-10 とする。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 A の下書きの掲載がある。操作する人は店舗 A の店舗管理者 | 名称・説明・カテゴリーを変えて保存する | 内容が置き換わり、版が進み、`updatedAt` が保存の日時になる。`draft` のまま。ドメインイベントは出ない | |
| 店舗 A の公開中の掲載がある。操作する人は店舗 A の店舗管理者 | 名称と説明を変えて保存する | 保存した時点で、`published` のまま新しい内容が読める。承認は要らない（AC-27） | |
| 店舗 A の下書きの掲載に写真が1枚ある。操作する人が登録した、持ち主のない写真が2枚ある | 写真を3枚にし、加えた写真の1枚を先頭に並び替えて保存する | 写真は保存した順序で保持され、1枚目が代表写真になる。加わった2枚の持ち主がこの掲載になる（AC-44） | |
| 店舗 A の下書きの掲載に写真が2枚ある | 1枚目に見せる範囲を設定し、2枚目は調整せずに保存する | 1枚目は設定した `framing`、2枚目は `framing: null`（写真の全体）で保存される（AC-38） | |
| 店舗 A の公開中の掲載に写真が2枚ある | 2枚目を外して保存する | 写真は1枚になる。外した写真の `PhotoId` を載せた `photos.released` が出る | |
| 店舗 A の公開中の掲載がある | 写真をすべて外して保存する | `BusinessRuleError`（`LISTING_PUBLISH_CONDITION_UNMET`）。掲載は変わらず、`photos.released` は出ない | |
| 店舗 A の公開中の掲載がある | 名称を空にして保存する | `BusinessRuleError`（`LISTING_PUBLISH_CONDITION_UNMET`）。掲載は変わらない | |
| 店舗 A の一時非公開の掲載がある | 写真をすべて外して保存する | 保存される。外した写真の `photos.released` が出る | |
| 店舗 A の公開中の掲載がある。提供の設定は「設定しない」 | 提供期間を開始日 2026-07-20、終了日 2026-08-31 にして保存する | 保存される。提供状態は提供開始前で、開始日 2026-07-20 が分かる（AC-24） | |
| 店舗 A の公開中の掲載がある | 提供期間を終了日 2026-07-01 だけにして保存する | 保存される。提供状態は期日による提供終了になる（AC-24） | |
| 店舗 A の公開中の掲載が、終了日 2026-06-30 を過ぎて提供終了になっている | 終了日を 2026-08-31 に更新して保存する | 提供状態は提供中に戻る（AC-24） | |
| 店舗 A の公開中の掲載が、終了日 2026-06-30 を過ぎて提供終了になっている | 提供の設定を「設定しない」に切り替えて保存する | 提供期間は残らない。提供状態は提供中に戻る | |
| 店舗 A の掲載に提供期間が設定されている | 提供の設定を「開催日」に切り替え、開催日を指定して保存する | 提供の設定は開催日だけを持ち、提供期間は残らない。提供期間と開催日を同時には持てない（AC-24） | |
| 店舗 A の公開中の掲載がある | 開催日を 2026-08-03、2026-07-20、2026-07-27 の3つにして保存する | 開催日は昇順の3つで保存される。最初の開催日より前の今日も、提供状態は提供中（AC-47） | |
| 店舗 A の公開中の掲載の開催日が 2026-06-20 と 2026-06-27 で、提供終了になっている | 開催日に 2026-07-25 を追加して保存する | 提供状態は提供中に戻る（AC-47） | |
| 店舗 A の公開中の掲載が、運営による非公開になっている | 名称を変えて保存する | 保存される。運営による非公開と公開状態は変わらない | |
| 店舗 A の掲載が、申立てによる写真の削除で写真がなくなり、一時非公開（`photoTakedown`）になっている | 写真を1枚登録して保存する | 保存され、写真の持ち主がこの掲載になる。公開状態は一時非公開のまま変わらない（AC-79） | |
| 店舗 B の掲載は、店舗管理者のいなかった時期にサービス運営者が代理作成して公開した。その後、操作する人が店舗 B の店舗管理者に就いた | 店舗管理者がその掲載の内容を変えて保存する | 保存した時点で反映される（AC-30） | |
| 店舗 B に店舗管理者がいない。操作する人はサービス運営者 | 店舗 B の公開中の掲載の内容を変えて保存する | 保存した時点で反映される。承認は要らない（AC-19） | |
| 店舗 A に店舗管理者が1人残っている。操作する人は店舗 A の管理権限を持たないサービス運営者 | 店舗 A の掲載の内容を変えて保存する | `ForbiddenError`。掲載は変わらない | |
| 操作する人は、編集の途中で店舗 A の管理権限を失った | 店舗 A の掲載を保存する | `ForbiddenError`。掲載は変わらない | |
| 編集している間に、別の店舗管理者が掲載を削除した | 保存する | `NotFoundError` | |
| 編集を始めた後に、別の店舗管理者が同じ掲載を保存した | 編集を始めたときの版を添えて保存する | `ConflictError`。先に保存された内容は上書きされない | |
| 選んだカテゴリーが、保存までに廃止された | そのカテゴリーで保存する | `BusinessRuleError`（`LISTING_CATEGORY_NOT_AVAILABLE`）。掲載は変わらない | |
| 店舗 A の掲載がある | 提供期間の終了日を開始日より前にして保存する | `BusinessRuleError`（`LISTING_OFFERING_PERIOD_REVERSED`）。掲載は変わらない | |
| 店舗 A の掲載がある | 保存されている内容と同じ内容で保存する | 成功する。版は進まず、`updatedAt` は変わらず、ドメインイベントは出ない | |
| 店舗 A の掲載がある。加える写真の1枚が、すでに別の掲載を持ち主に持つ | その写真を加えて保存する | `BusinessRuleError`（`MEDIA_PHOTO_ALREADY_OWNED`）。掲載は変わらず、他の写真の持ち主も設定されない | |
