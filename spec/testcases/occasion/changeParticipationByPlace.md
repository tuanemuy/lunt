# changeParticipationByPlace

共通の前提: 店舗 P はイベント O に参加中。イベント O の開催期間は 10/1〜10/3。店舗 P の掲載 L1・L2 は公開中で提供中、L3 は公開中で提供開始前、L4 は下書き、L5 は公開中で提供終了、L6 は一時非公開。掲載 M1 は別の店舗の公開中で提供中の掲載。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人は店舗 P の店舗管理者。参加内容は、添えた掲載 L1、参加日 10/1 | 添える掲載を L2、L1 の順に、参加日を 10/3、10/2 にして保存する | 承認なしに保存される。添えた掲載は L2、L1 の順、参加日は 10/2、10/3 の昇順。版が1つ進む。`changedBy: "place"` の `occasion.participation_changed` が出る。掲載 L1・L2 と店舗 P の公開状態・提供状態は変わらない（AC-26、AC-73） | |
| 操作する人は店舗 P の店舗管理者 | 提供開始前の掲載 L3 を添えて保存する | 保存される（P-46） | |
| 操作する人は店舗 P の店舗管理者 | 掲載も参加日も空にして保存する | 保存される。参加は保たれる | |
| 店舗 P の参加は、店舗管理者のいなかった時期に `addParticipationDirectly` で成立した。その後に就任した店舗管理者が操作する | 添える掲載と参加日を変更して保存する | 保存される（AC-33） | |
| 操作する人は店舗 P の店舗管理者。イベント O は公開の取り下げ中で、開催の状態は終了 | 参加日を 10/2 に変更して保存する | 保存される。イベントの公開状態と開催の状態を問わない | |
| 操作する人は店舗 P の店舗管理者。参加内容は、添えた掲載 L6（添えた後に一時非公開になった） | 添える掲載を L6、L1 にして保存する | 保存される。すでに添えた掲載 L6 は添えたままにできる | |
| 操作する人は店舗 P の店舗管理者。参加内容に L5 はない | 提供終了の掲載 L5 を新しく添えて保存する | 保存される（I-22） | |
| 操作する人は店舗 P の店舗管理者。参加内容に L6 はない | 一時非公開の掲載 L6 を新しく添えて保存する | `BusinessRuleError`（`OCCASION_LISTING_NOT_ATTACHABLE`）。参加内容は変わらない | |
| 操作する人は店舗 P の店舗管理者 | 下書きの掲載 L4 を添えて保存する | `BusinessRuleError`（`OCCASION_LISTING_NOT_ATTACHABLE`） | |
| 操作する人は店舗 P の店舗管理者 | 別の店舗の掲載 M1 を添えて保存する | `BusinessRuleError`（`OCCASION_LISTING_NOT_ATTACHABLE`） | |
| 操作する人は店舗 P の店舗管理者 | 参加日を 10/4 にして保存する | `BusinessRuleError`（`OCCASION_PARTICIPATION_DATE_OUT_OF_PERIOD`）。参加内容は変わらない | |
| 操作する人は店舗 P の店舗管理者。参加日は 10/3。その後にイベントの開催期間が 10/1〜10/2 に更新された | 参加日を 10/2 にして保存する | 保存される。返る閲覧者に示す参加日は 10/2 | |
| 操作する人は店舗 P の店舗管理者。参加日は 10/3。その後にイベントの開催期間が 10/1〜10/2 に更新された | 参加日 10/3 を残したまま、添える掲載だけを変更して保存する | `BusinessRuleError`（`OCCASION_PARTICIPATION_DATE_OUT_OF_PERIOD`）。参加内容は変わらない | |
| 操作する人は店舗 P の店舗管理者 | 現在と同じ参加内容で保存する | 成功する。版は進まず、ドメインイベントは出ない | |
| 操作する人は店舗 P の店舗管理者。保存するまでの間に、イベントの運営者が店舗 P を除外した | 参加内容を変更して保存する | `NotFoundError`。参加は作られない | |
| 操作する人は店舗 P の店舗管理者。編集を始めた後に、別の店舗管理者が参加内容を保存して版が進んでいる | 編集を始めたときの版を添えて保存する | `ConflictError`。別の店舗管理者が保存した内容は上書きされない | |
| 操作する人は、イベント O の運営者で、店舗 P の管理権限を持たない | 参加内容を変更して保存する | `ForbiddenError`。イベントの管理権限は店舗管理者の操作に及ばない（AC-18） | |
| 店舗 P に店舗管理者がいない。操作する人はサービス運営者 | 参加内容を変更して保存する | `ForbiddenError`。店舗管理者の操作に代行はない | |
