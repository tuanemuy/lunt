# getPlaceParticipations

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人は店舗 P の店舗管理者。店舗 P は、イベント A（公開中、開催前）に先に、イベント B（公開中、開催中）に後から参加した。イベント A には掲載 L1 と参加日を添えている | 店舗 P の参加状況を確かめる | B、A の順（参加の新しい順）に2件と、全件数 2 が返る。それぞれにイベントの名称・開催期間・公開状態・開催の状態、添えた掲載（名称と提供状態）、参加日が付く | |
| 操作する人は店舗 P の店舗管理者。店舗 P は、公開の取り下げ中のイベント C、運営による非公開のイベント D、中止中のイベント E、開催期間を過ぎたイベント F に参加中 | 店舗 P の参加状況を確かめる | 4件とも返る。C は公開の取り下げ、D は運営による非公開、E は開催の状態が中止、F は終了として区別できる | |
| 操作する人は店舗 P の店舗管理者。店舗 P の参加日は 10/2・10/3。その後にイベントの開催期間が 10/1〜10/2 に更新された | 店舗 P の参加状況を確かめる | 参加日 10/2・10/3 が返り、10/3 が開催期間の外になった参加日として区別できる | |
| 店舗 P の参加は、店舗管理者のいなかった時期に `addParticipationDirectly` で成立した。その後に就任した店舗管理者が操作する | 店舗 P の参加状況を確かめる | その参加が返る（AC-33） | |
| 操作する人は店舗 P の店舗管理者。添えた掲載 L1 は、添えた後に提供終了になった | 店舗 P の参加状況を確かめる | L1 は添えた掲載として返り、提供状態は提供終了 | |
| 操作する人は店舗 P の店舗管理者。店舗 P はどのイベントにも参加していない | 店舗 P の参加状況を確かめる | 空の一覧と、全件数 0 が返る | |
