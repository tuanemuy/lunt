# updateOccasionContent

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人はイベント運営者。イベントは公開中で、公開条件を満たす | 紹介とキャッチコピーを書き換え、編集を始めたときの版を添えて保存する | イベント情報が置き換わり、版が1つ進む。公開状態は `published` のまま、`firstPublishedAt` は変わらない。開催期間が同じなので `occasion.period_changed` は出ない（AC-61） | |
| 操作する人はイベント運営者。イベントは公開中で、開催期間は過ぎていて開催の状態は終了。店舗 P が期間内の参加日を添えて参加中 | 開催期間を未来の日付に更新して保存する | 開催期間が置き換わり、`occasion.period_changed` が出る。返る開催の状態は開催前。店舗 P の参加と参加日は変わらない | |
| 操作する人はイベント運営者。イベントは中止中 | 開催期間を更新して保存する | 開催期間が置き換わり、`occasion.period_changed` が出る。中止のままで、返る開催の状態は中止 | |
| 操作する人はイベント運営者。イベントは公開中で、写真 A・B を A、B の順に持つ。写真 C は操作する人が登録した持ち主のない写真 | 写真を C、B の順にして保存する | 写真が C、B の順に置き換わり、C が代表写真になる。C の持ち主がこのイベントになる。A を載せた `photos.released` が出る。B の持ち主は設定し直されない | |
| 操作する人はイベント運営者。イベントは公開中 | 写真をすべて外して保存する | `BusinessRuleError`（`OCCASION_PUBLISH_CONDITION_UNMET`）。不足する項目として写真が示される。イベントは変わらず、`photos.released` は出ない（AC-68） | |
| 操作する人はイベント運営者。イベントは公開の取り下げ中 | 名称と写真を外して保存する | 保存される。公開条件を確かめない。公開状態は `unpublished` のまま | |
| 操作する人はイベント運営者。イベントは公開中で、運営による非公開 | 紹介を書き換えて保存する | 保存される。公開状態も運営による非公開も変わらない | |
| 操作する人はイベント運営者 | 終了日が開始日より前の開催期間で保存する | `BusinessRuleError`（`COMMON_INVALID_DATE_RANGE`）。イベントは変わらない | |
| 操作する人はイベント運営者。編集を始めた後に、別の運営者がイベント情報を保存して版が進んでいる | 編集を始めたときの版を添えて保存する | `ConflictError`。別の運営者が保存した内容は上書きされない | |
| イベントにイベント運営者がいない。操作する人はサービス運営者 | イベント情報を書き換えて保存する | 保存される（代行）（AC-67） | |
| イベントにイベント運営者がいる。操作する人は、そのイベントの管理権限を持たないサービス運営者 | イベント情報を書き換えて保存する | `ForbiddenError`。イベントは変わらない | |
| 操作する人は、編集を始めた後にそのイベントの管理権限を解除された利用者 | イベント情報を書き換えて保存する | `ForbiddenError`。イベントは変わらない | |
| 操作する人は、別のイベントの管理権限だけを持つ利用者 | イベント情報を書き換えて保存する | `ForbiddenError` | |
| 指定した ID のイベントがない | イベント情報を保存する | `NotFoundError` | |
| 操作する人はイベント運営者。イベントは、申立てによって写真 A・B から A が削除され、写真は B | 写真の並びを B のまま、紹介だけを書き換えて保存する | 保存される。管理するイベントを確かめる読み取りで、申立てで写真が削除されたことが引き続き返る | |
| 操作する人はイベント運営者。選んだ町域が `AreaCatalog` にない | その町域を開催場所にして保存する | `BusinessRuleError`（`AREA_TOWN_NOT_FOUND`）。イベントは変わらない | |
| 操作する人はイベント運営者。載せる写真 D は、別の人が登録した写真 | 写真 D を載せ、名称も変えて保存する | `BusinessRuleError`（`MEDIA_PHOTO_NOT_REGISTRANT`）。名称を含めてイベントは変わらず、写真 D の持ち主は設定されない | |
| 操作する人はイベント運営者。載せる写真の1枚は、存在しない `PhotoId` | その写真を載せて保存する | `BusinessRuleError`（`MEDIA_PHOTO_NOT_AVAILABLE`）。イベントは変わらない | |
| 操作する人はイベント運営者。自分が登録した写真 E は、すでに別のイベントが持ち主 | 写真 E を載せて保存する | `BusinessRuleError`（`MEDIA_PHOTO_ALREADY_OWNED`）。イベントは変わらず、E の持ち主も変わらない | |
