# searchOccasionsForOperation

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人はサービス運営者。名称に「マルシェ」を含むイベントが、公開中・`draft`・公開の取り下げ中・運営による非公開・中止中・終了の6件ある | 「マルシェ」で探す | 6件とも返る。それぞれに公開状態、運営による非公開、開催の状態が付く | |
| 操作する人はサービス運営者。「秋のマルシェ」にはイベント運営者がいて、「春のマルシェ」にはいない | 「マルシェ」で探す | 「秋のマルシェ」はイベント運営者あり、「春のマルシェ」はイベント運営者なしとして返る | |
| 操作する人はサービス運営者。名称が「マルシェ」「マルシェ広場」「秋のマルシェ」のイベントがある | 「マルシェ」で探す | 「マルシェ」（完全一致）、「マルシェ広場」（前方一致）、「秋のマルシェ」（部分一致）の順に返る | |
| 操作する人はサービス運営者。名称がなく、紹介に「マルシェ」を含む `draft` のイベントがある | 「マルシェ」で探す | そのイベントが返る | |
| 操作する人はサービス運営者。名称に「マルシェ」を含むイベントと、名称に含まず紹介にだけ含むイベントがある | 「マルシェ」で探す | どちらも返り、名称に含むイベントが先に並ぶ | |
| 操作する人はサービス運営者。キーワードに合うイベントがない | 探す | 空の一覧と、全件数 0 が返る | |
| 操作する人は、サービス運営者の役割を持たない利用者（イベント運営者を含む） | 探す | `ForbiddenError` | |
| 操作する人はサービス運営者。イベントが登録されている | 空のキーワードと、空白だけのキーワードでそれぞれ探す | どちらも、空の一覧と、全件数 0 が返る | |
