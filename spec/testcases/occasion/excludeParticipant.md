# excludeParticipant

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人はイベント O の運営者。店舗管理者のいる店舗 P が、参加の申請の承認で、掲載 L1 を添えて参加中 | 店舗 P を除外する | 承認も理由もなしに参加が削除される。`ParticipationRepository.findById` は `null` を返す。`cause: "excluded"` の `occasion.participation_dissolved` が出る。店舗 P と掲載 L1 の公開状態・提供状態は変わらない（AC-17、AC-73） | |
| 操作する人はイベント O の運営者。店舗管理者のいない店舗 Q が、直接の追加で参加中 | 店舗 Q を除外する | 参加が削除される。店舗管理者の有無と成立の経緯を問わない | |
| 操作する人はイベント O の運営者。イベント O は開催期間を過ぎて終了している | 店舗 P を除外する | 参加が削除される。開催の状態を問わない | |
| イベント O にイベント運営者がいない。操作する人はサービス運営者 | 店舗 P を除外する | 参加が削除される（代行）（AC-17） | |
| 操作する人はイベント O の運営者。除外するまでの間に、店舗 P の店舗管理者が参加を取りやめた | 店舗 P を除外する | `NotFoundError`。`occasion.participation_dissolved` は重ねて出ない | |
| 操作する人はイベント O の運営者。店舗 P を除外した後 | もう一度、店舗 P を除外する | `NotFoundError`。除外は取り消せず、参加は戻らない | |
| イベント O にイベント運営者がいる。操作する人は、イベント O の管理権限を持たないサービス運営者 | 店舗 P を除外する | `ForbiddenError`。参加は保たれる | |
| 操作する人は、店舗 P の店舗管理者で、イベント O の管理権限を持たない | 店舗 P を除外する | `ForbiddenError` | |
