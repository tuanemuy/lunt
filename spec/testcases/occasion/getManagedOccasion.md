# getManagedOccasion

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人はイベント O の運営者。イベント O は公開中で、今日は開催期間の中 | 管理するイベントを確かめる | イベント情報、公開状態 `published`、運営による非公開でないこと、開催の状態 開催中、閲覧者が閲覧できること、空の不足する公開条件、申立てで写真が削除されていないこと、イベント運営者がいることが返る。操作する人はイベントを管理でき、立場は管理者（`basis` は `steward`）（AC-61） | |
| 操作する人はイベント O の運営者。イベント O は `draft` で、名称だけを持つ | 管理するイベントを確かめる | 公開状態 `draft`、不足する公開条件（開催期間・開催場所・写真）が返る。開催期間がないので開催の状態は決まらない | |
| 操作する人はイベント O の運営者。イベント O は、申立てによる最後の写真の削除で公開の取り下げになった | 管理するイベントを確かめる | 公開状態 `unpublished`（`reason: "photoTakedown"`）と、不足する公開条件（写真）、申立てで写真が削除されたことが返る（AC-79） | |
| 操作する人はイベント O の運営者。イベント O は公開中で、申立てによって写真 A・B から A が削除された | 管理するイベントを確かめる | 公開状態 `published` と、申立てで写真が削除されたことが返る | |
| 上のイベント O で、イベント運営者が写真を B・C の並びにして保存した | 管理するイベントを確かめる | 申立てで写真が削除されたことは返らない | |
| 操作する人はイベント O の運営者。イベント O は公開中で、運営による非公開、中止中 | 管理するイベントを確かめる | 公開状態 `published`、運営による非公開、開催の状態 中止が、それぞれ独立して返る。閲覧者は閲覧できない | |
| イベント O にイベント運営者がいない。操作する人はサービス運営者 | 管理するイベントを確かめる | イベントの内容と状態、イベント運営者がいないことが返る。操作する人はイベントを管理でき、立場は不在の代行（`basis` は `absence_proxy`）（AC-67） | |
| イベント O にイベント運営者がいる。操作する人は、イベント O の管理権限を持たないサービス運営者。イベント O は公開中で運営による非公開 | 管理するイベントを確かめる | イベントの内容と状態（`published`、運営による非公開）、イベント運営者がいることが返る。操作する人はイベントを管理できない（代行できない） | |
| 操作する人は、イベント O の管理権限も、サービス運営者の役割も持たない利用者（管理権限を解除された人、編集担当者を含む） | 管理するイベントを確かめる | `ForbiddenError` | |
| 指定した ID のイベントがない | 管理するイベントを確かめる | `NotFoundError` | |
