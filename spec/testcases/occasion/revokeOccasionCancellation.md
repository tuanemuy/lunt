# revokeOccasionCancellation

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人はイベント運営者。イベントは中止中で、今日は開催期間の開始日より前 | 中止を取り消す | 中止でなくなり、返る開催の状態は開催前。ドメインイベントは出ない（AC-69） | |
| 操作する人はイベント運営者。イベントは中止中で、今日は開催期間の中 | 中止を取り消す | 返る開催の状態は開催中 | |
| 操作する人はイベント運営者。イベントは中止中で、開催期間を過ぎている | 中止を取り消す | 取り消せる。返る開催の状態は終了 | |
| 操作する人はイベント運営者。イベントは中止中で、運営による非公開 | 中止を取り消す | 取り消せる。運営による非公開と公開状態は変わらない | |
| 操作する人はイベント運営者。中止を取り消した後のイベント | `cancelOccasion` で再び中止にする | 中止になり、`occasion.cancelled` が出る | |
| 操作する人はイベント運営者。別の運営者がすでに中止を取り消している | 中止を取り消す | `BusinessRuleError`（`OCCASION_NOT_CANCELLED`）。イベントは変わらない | |
| イベントにイベント運営者がいる。操作する人は、そのイベントの管理権限を持たないサービス運営者 | 中止を取り消す | `ForbiddenError` | |
| 操作する人は、そのイベントの管理権限を持たない利用者 | 中止を取り消す | `ForbiddenError` | |
