# withdrawParticipation

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人は店舗 P の店舗管理者。店舗 P は、掲載 L1 を添えてイベント O に参加中。イベント O は公開中で開催前 | 参加を取りやめる | 承認なしに参加が削除される。`ParticipationRepository.findById` は `null` を返し、イベント O の参加店舗にも店舗 P の参加中のイベントにも現れない。`cause: "withdrawn"` の `occasion.participation_dissolved` が出る。店舗 P と掲載 L1 の公開状態・提供状態は変わらない（AC-26、AC-73） | |
| 操作する人は店舗 P の店舗管理者。イベント O は中止中で、運営による非公開 | 参加を取りやめる | 取りやめられる。イベントの開催の状態と公開状態を問わない | |
| 店舗 P の参加は、店舗管理者のいなかった時期に `addParticipationDirectly` で成立した。その後に就任した店舗管理者が操作する | 参加を取りやめる | 取りやめられる（AC-33） | |
| 操作する人は店舗 P の店舗管理者。取りやめるまでの間に、イベントの側が店舗 P を除外した | 参加を取りやめる | `NotFoundError`。`occasion.participation_dissolved` は重ねて出ない | |
| 操作する人は店舗 P の店舗管理者。取りやめた後 | もう一度、参加を取りやめる | `NotFoundError`。取りやめは取り消せず、参加は戻らない | |
| 操作する人は、店舗 P の管理権限を持たない利用者（イベント O の運営者を含む） | 参加を取りやめる | `ForbiddenError`。参加は保たれる | |
| 店舗 P に店舗管理者がいない。操作する人はサービス運営者 | 参加を取りやめる | `ForbiddenError`。店舗の側の操作に代行はない | |
