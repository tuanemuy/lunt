# updateRegionContent

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人が地域運営者。地域は `published` で、写真 A・B を持つ。操作する人が登録した、持ち主のない写真 C がある | 名称と紹介を変え、写真を C・A の順にして保存する（B を外す） | 地域情報が置き換わり、版が1つ進む。公開状態は `published` のままで、`firstPublishedAt` は変わらない。写真は C・A の順で、C の持ち主がこの地域になる。B を載せた `photos.released` が出る（AC-60） | |
| 操作する人が地域運営者。地域は `published` | 写真をすべて外した内容で保存する | `BusinessRuleError("REGION_PUBLISH_CONDITION_UNMET")`。不足する項目として写真が示される。地域は変わらず、ドメインイベントは出ない（AC-68） | |
| 操作する人が地域運営者。地域は `draft` | 名称・所在地・位置・写真をすべて未入力にして保存する | 保存される。公開状態は `draft` のまま。不足する公開条件として4項目が返る | |
| 操作する人が地域運営者。地域は `published` で運営による非公開 | 紹介を変えて保存する | 保存される。公開状態と運営による非公開は変わらない | |
| 操作する人が地域運営者。地域は申立てによる写真の削除で `unpublished`（`photoTakedown`）。操作する人が登録した、持ち主のない写真がある | その写真を加えて保存する | 保存され、写真の持ち主がこの地域になる。公開状態は `unpublished`（`photoTakedown`）のまま（AC-79） | |
| 地域に地域運営者がいない。操作する人がサービス運営者 | 地域情報を変えて保存する | 保存される（AC-67） | |
| 地域に地域運営者がいる。操作する人は、その地域の管理権限を持たないサービス運営者 | 地域情報を変えて保存する | `ForbiddenError`。地域は変わらない | |
| 操作する人が、この地域の管理権限も役割も持たない（別の地域運営者、所属店舗の店舗管理者を含む） | 地域情報を変えて保存する | `ForbiddenError`。地域は変わらない | |
| 操作する人は、編集を始めた後に地域の管理権限を解除された | 地域情報を変えて保存する | `ForbiddenError`。地域は変わらない | |
| 操作する人が地域運営者。編集を始めた後に、別の運営者が地域情報を保存した | 編集を始めたときの版で保存する | `ConflictError`。別の運営者が保存した内容が残る | |
| 操作する人が地域運営者。加える写真は、別の人が登録した写真 | その写真を加えて、名称も変えて保存する | `BusinessRuleError("MEDIA_PHOTO_NOT_REGISTRANT")`。名称を含めて地域は変わらず、写真の持ち主は設定されない | |
| 指定した ID の地域がない | 地域情報を保存する | `NotFoundError` | |
| 操作する人が地域運営者。選んだ町域が `AreaCatalog` にない | その町域を所在地にして保存する | `BusinessRuleError("AREA_TOWN_NOT_FOUND")`。地域は変わらない | |
