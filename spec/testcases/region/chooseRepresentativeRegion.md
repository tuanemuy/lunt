# chooseRepresentativeRegion

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人が店舗管理者。店舗は地域 X（先に所属）と地域 Y（後に所属）に所属中で、代表地域を選んでいない | Y を代表地域に選ぶ | 選んだ代表地域が Y になり、代表地域として Y が返る。所属の集合は変わらない。ドメインイベントは出ない（AC-25） | |
| 操作する人が店舗管理者。店舗は X・Y に所属中で、Y を選んでいる | X を代表地域に選ぶ | 選んだ代表地域が X になる | |
| 操作する人が店舗管理者。店舗は X（先に所属）・Y に所属中で、代表地域を選んでいない | X を代表地域に選ぶ | `BusinessRuleError("REGION_REPRESENTATIVE_ALREADY_CHOSEN")`（X は最初に所属した地域として、すでに代表地域）。選んだ代表地域は `null` のまま | |
| 操作する人が店舗管理者。店舗は X・Y に所属中で、Y を選んでいる（別の画面で先に選んだ） | Y を代表地域に選ぶ | `BusinessRuleError("REGION_REPRESENTATIVE_ALREADY_CHOSEN")`。店舗の所属は変わらない | |
| 操作する人が店舗管理者。店舗は X・Y に所属中。Y は `unpublished` | Y を代表地域に選ぶ | 選んだ代表地域が Y になる | |
| 操作する人が店舗管理者。店舗は X・Y に所属中。Y は運営による非公開 | Y を代表地域に選ぶ | 選んだ代表地域が Y になる | |
| 操作する人が店舗管理者。店舗は X に所属中。Y との所属は、選ぶまでの間に除外で解除された | Y を代表地域に選ぶ | `BusinessRuleError("REGION_NOT_AFFILIATED")`。店舗の所属は変わらない | |
| 操作する人が店舗管理者。店舗に所属の記録がない | X を代表地域に選ぶ | `BusinessRuleError("REGION_NOT_AFFILIATED")`。店舗の所属の記録は作られない | |
| 店舗に店舗管理者がいない。操作する人がサービス運営者。店舗は X・Y に所属中 | Y を代表地域に選ぶ | `ForbiddenError`。店舗として行う操作に代行はない。店舗の所属は変わらない | |
| 店舗に店舗管理者がいる。操作する人は、店舗の管理権限を持たないサービス運営者 | Y を代表地域に選ぶ | `ForbiddenError`。店舗の所属は変わらない | |
| 操作する人は、店舗が所属中の地域 X の運営者で、店舗の管理権限を持たない。店舗に店舗管理者がいる | X を代表地域に選ぶ | `ForbiddenError`。店舗の所属は変わらない（AC-13、AC-45） | |
| 操作する人が店舗管理者。代表地域を選ぶ操作と、同じ店舗の別の地域からの除外が同時に確定する | Y を代表地域に選ぶ | 後に確定する側が `ConflictError` になり、その側の変更は残らない | |
