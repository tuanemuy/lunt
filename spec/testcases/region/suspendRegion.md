# suspendRegion

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人がサービス運営者。地域は `published` で、地域運営者がいる | 運営による非公開にする | 運営による非公開になり、`suspendedAt` は操作の日時。公開状態は `published` のまま。`region.suspended` が出る（AC-64） | |
| 操作する人がサービス運営者。地域は `draft` で、地域運営者がいない | 運営による非公開にする | 運営による非公開になる。公開状態は `draft` のまま。`region.suspended` が出る | |
| 操作する人がサービス運営者。地域は `published`。店舗が所属中 | 運営による非公開にする | 店舗の所属と選んだ代表地域は変わらない。店舗と掲載への書き込みはない | |
| 操作する人がサービス運営者。地域は別のサービス運営者の操作ですでに運営による非公開 | 運営による非公開にする | `BusinessRuleError("REGION_ALREADY_SUSPENDED")`。地域は変わらず、ドメインイベントは出ない | |
| 操作する人が地域運営者で、サービス運営者でない | 運営による非公開にする | `ForbiddenError`。地域は変わらない | |
| 指定した ID の地域がない | 運営による非公開にする | `NotFoundError` | |
