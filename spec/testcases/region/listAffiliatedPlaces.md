# listAffiliatedPlaces

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人が地域運営者。店舗 P（先に所属）と店舗 Q（後に所属）が所属中 | 所属店舗を確かめる | Q・P の順（所属の新しい順）に、名称・営業状況・非公開かどうか・所属が成立した日時とともに返る。全件数は 2（AC-60） | |
| 操作する人が地域運営者。所属中の店舗に、閉店した店舗と、非公開の店舗がある | 所属店舗を確かめる | どちらの店舗も、その状態とともに返る | |
| 操作する人が地域運営者。店舗 P は別の地域にも所属中。別の地域にだけ所属する店舗 R がある | 所属店舗を確かめる | P は返り、R は返らない | |
| 操作する人が地域運営者。店舗 P が除外された | 所属店舗を確かめる | P は返らない（AC-11） | |
| 操作する人が地域運営者。地域に所属店舗がない | 所属店舗を確かめる | 空の並びと、全件数 0 が返る | |
| 地域に地域運営者がいない。操作する人がサービス運営者 | 所属店舗を確かめる | 所属店舗が返る | |
| 地域に地域運営者がいる。操作する人は、その地域の管理権限を持たないサービス運営者 | 所属店舗を確かめる | `ForbiddenError` | |
| 操作する人が、この地域の管理権限も役割も持たない（所属店舗の店舗管理者を含む） | 所属店舗を確かめる | `ForbiddenError` | |
