# searchRegionsForOperation

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 操作する人がサービス運営者。名称にキーワードを含む地域が、`draft`・`published`・`unpublished`・運営による非公開のそれぞれにある | キーワードで探す | 4つの地域がすべて、公開状態と運営による非公開とともに返る。全件数は 4 | |
| 操作する人がサービス運営者。キーワードと名称が完全に一致する地域、名称がキーワードで始まる地域、名称の途中にキーワードを含む地域がある | キーワードで探す | 完全一致、前方一致、部分一致の順に返る | |
| 操作する人がサービス運営者。キーワードに合う地域のうち、1つには地域運営者がいて、1つにはいない（管理権限を付与されたことがない）、1つは最後の運営者が辞任している | キーワードで探す | 地域ごとに、地域運営者の有無（あり・なし・なし）が返る | |
| 操作する人がサービス運営者。名称にキーワードを含む地域と、名称に含まずキャッチコピー・紹介・所在地のどれかにだけ含む地域がある | キーワードで探す | どちらも返り、名称に含む地域が先に並ぶ | |
| 操作する人がサービス運営者。名称・キャッチコピー・紹介・所在地のどれにもキーワードを含む地域がない | キーワードで探す | 空の並びと、全件数 0 が返る | |
| 操作する人がサービス運営者でない（地域運営者、編集担当者を含む） | キーワードで探す | `ForbiddenError` | |
| 操作する人がサービス運営者。地域が登録されている | 空のキーワードと、空白だけのキーワードでそれぞれ探す | どちらも、空の並びと、全件数 0 が返る | |
