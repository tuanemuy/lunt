# getManagedPlace

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A は店舗 p1 の店舗管理者。p1 は写真2枚、営業中、非公開でない | A が p1 を読む | 店舗情報（名称、写真の並び、紹介、所在地、位置、営業時間、連絡先）、営業状況、非公開でないことを返す。管理者がいること、A が店舗管理者の立場で管理できることを含む | |
| 利用者 A は店舗 p1 の店舗管理者。p1 は地域 X に、次に地域 Y に所属している | A が、掲載の作成を始めるために p1 を読む | 所在地と、所属中の地域の名称 X、Y を、最初に所属した順に返す（LST-01） | |
| 利用者 A は店舗 p1 の店舗管理者。p1 はどの地域にも所属していない | A が p1 を読む | 所属中の地域は空で返る | |
| 利用者 A は店舗 p1 の店舗管理者。サービス運営者が p1 を非公開にしている | A が p1 を読む | 店舗情報と営業状況を返し、非公開であることを含む。A は店舗管理者の立場で管理できる | |
| 店舗 p1 に店舗管理者がいない。操作する人はサービス運営者 O | O が p1 を読む | 店舗を返す。管理者がいないこと、O がサービス運営者の立場で管理できる（代行できる）ことを含む | |
| 店舗 p1 に店舗管理者 A がいる。操作する人は、p1 の店舗管理者でないサービス運営者 O | O が p1 を読む | 店舗と、非公開かどうかを返す（サービス運営者は、管理者の有無にかかわらず店舗を開いて確かめられる）。管理者がいること、O は管理できない（代行できない）ことを含む | |
| 店舗 p1 は非公開で、店舗管理者 A がいる。操作する人は、p1 の店舗管理者でないサービス運営者 O | O が p1 を読む | 店舗を返し、非公開であること、管理者がいることを含む | |
| 店舗 p1 に店舗管理者 A がいる。利用者 U は、p1 の店舗管理者でもサービス運営者でもない | U が p1 を読む | `ForbiddenError` になる | |
| 利用者 A は店舗 p1 の店舗管理者だったが、サービス運営者に権限を解除された | A が p1 を読む | `ForbiddenError` になる | |
| 利用者 A は店舗 p1 の店舗管理者。店舗 p2 の店舗管理者ではない（p2 には別の店舗管理者がいる） | A が p2 を読む | `ForbiddenError` になる（権限は対象ごとに独立） | |
| 利用者 A は店舗 p1 の店舗管理者。p1 の写真 ph1、ph2 のうち ph1 が申立てで削除された | A が p1 を読む | 申立てで写真が削除されたことが分かる | |
| 上の p1 で、A が写真を変えずに紹介だけを保存した | A が p1 を読む | 申立てで写真が削除されたことが、まだ分かる | |
| 上の p1 で、A が写真の並びを変えて保存した | A が p1 を読む | 申立てで写真が削除されたことは示されなくなる | |
| 操作する人はサービス運営者 O。ID が p9 の店舗はない | O が p9 を読む | `NotFoundError` になる | |
