# listStewardedPlaces

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A は、店舗 p1（営業中）と店舗 p2（休業、非公開）の店舗管理者で、地域 r1 の地域運営者でもある。A が管理者でない店舗 p3 がある | A が管理する店舗の一覧を読む | p1、p2 の2件を、`PlaceId` の昇順で返す。店舗ごとに名称、代表写真、営業状況、非公開かどうかを持つ。非公開の p2 を含む。p3 と地域 r1 は含まれない | |
| 利用者 A は、どの店舗の管理権限も持たない | A が管理する店舗の一覧を読む | 空の一覧を返す。エラーにならない | |
| 利用者 A は店舗 p1 の店舗管理者だったが、辞任した | A が管理する店舗の一覧を読む | p1 は含まれない | |
| 利用者 A は、店舗 p1 への承諾前の招待の宛先であるだけで、管理者ではない | A が管理する店舗の一覧を読む | p1 は含まれない | |
