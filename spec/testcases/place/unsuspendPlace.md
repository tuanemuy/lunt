# unsuspendPlace

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 p1 は非公開。操作する人はサービス運営者 O | O が p1 の非公開を解除する | 店舗が非公開でない状態で保存され、版が進む。`place.unsuspended` が出る。掲載は書き換えられない。既存店舗の確認（`matchPlaces`）に p1 が再び現れる（AC-64） | |
| 店舗 p1 は非公開。非公開の間に、店舗管理者 A が名称を変え、営業状況を休業にした。操作する人はサービス運営者 O | O が p1 の非公開を解除する | 解除が成立する。店舗情報と営業状況は、非公開の間に更新された内容のまま現れる | |
| 店舗 p1 は非公開でない（別のサービス運営者が先に解除した）。操作する人はサービス運営者 O | O が p1 の非公開を解除する | `BusinessRuleError`（`PLACE_NOT_SUSPENDED`）になる。ドメインイベントは出ない | |
| 店舗 p1 は非公開。利用者 A は p1 の店舗管理者で、サービス運営者の役割を持たない | A が p1 の非公開を解除する | `ForbiddenError` になる。店舗は非公開のまま（解除できるのはサービス運営者だけ）（AC-64） | |
| 操作する人はサービス運営者 O。ID が p9 の店舗はない | O が p9 の非公開を解除する | `NotFoundError` になる | |
