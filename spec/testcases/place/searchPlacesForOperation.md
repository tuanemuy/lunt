# searchPlacesForOperation

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 非公開の店舗「山田」（店舗管理者あり）と、公開されている店舗「山田珈琲店」（管理者不在）がある。操作する人はサービス運営者 O | O が、店名「山田」で店舗を探す | 非公開の「山田」を含む2件を、関連度の高い順で返す。全件数は 2。店舗ごとに、種別、名称、所在地、営業状況、代表写真の表示用の参照、関連度、非公開かどうか、管理者の有無（「山田」は管理者あり、「山田珈琲店」は管理者不在）を持つ（AC-78） | |
| 店舗「山田珈琲店」（大阪府大阪市北区梅田）と「梅田食堂」（東京都中央区銀座）がある。操作する人はサービス運営者 O | O が、キーワード「梅田」を店名と住所の両方に入れて店舗を探す | 住所が一致する「山田珈琲店」と、店名が一致する「梅田食堂」の両方を返す | |
| 休業の店舗「山田珈琲店 別館」と、閉店の店舗「純喫茶 山田珈琲店」がある。操作する人はサービス運営者 O | O が、店名「山田珈琲店」で店舗を探す | 休業・閉店の店舗も結果に含まれ、営業状況を区別できる | |
| 写真のない非公開の店舗「海の家」があり、その店舗に公開中の掲載（写真あり）がある。操作する人はサービス運営者 O | O が、店名「海の家」で店舗を探す | 「海の家」を、非公開であることとともに、写真なしで返す。写真を代用しない | |
| 操作する人は、サービス運営者の役割を持たない店舗管理者 A | A が、店名「山田」で店舗を探す | `ForbiddenError` になる。店舗は返らない | |
| 操作する人はサービス運営者 O | O が、店名も住所も空（空白だけ）で店舗を探す | `BusinessRuleError`（`PLACE_MATCH_TEXT_REQUIRED`）になる | |
| 店名「存在しない店」に一致する店舗がない。操作する人はサービス運営者 O | O が、店名「存在しない店」で店舗を探す | 空の一覧と全件数 0 を返す。エラーにならない | |
