# updatePlaceProfile

エリアのマスターは [../ports/areaCatalog.md](../ports/areaCatalog.md) の「テスト用のマスター」。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A は店舗 p1（東京都千代田区大手町、`areaCode` 1000004、版 0）の店舗管理者 | A が、版 0 を添えて、名称と紹介を変え、町域を「銀座」（1040061）に変えた内容で更新する | 店舗が入力の内容に置き換わって保存される。版は 1、更新の日時は現在時刻、登録の日時は変わらない。所在地の `areaCode` は 1040061 になる（店舗のエリアは新しい所在地で決まる）。営業状況は変わらない。ドメインイベントは出ない | |
| 利用者 A は店舗 p1 の店舗管理者。p1 の写真は ph1、ph2 の順。A が登録した、持ち主のない写真 ph3 がある | A が、写真の並びを ph3、ph2 にして更新する | 店舗の写真は ph3、ph2 の順（ph3 が代表写真）。ph3 の持ち主は p1 になる。外れた ph1 を載せた `PhotosReleased` が出る | |
| 利用者 A は店舗 p1 の店舗管理者 | A が、現在と同じ内容で更新する | 成功として現在の店舗を返す。書き込みはなく、版は進まず、ドメインイベントは出ない | |
| 店舗 p1 は代理登録された店舗で、利用者 B の管理権限の申請が承認され、B が p1 の店舗管理者になっている | B が p1 の店舗情報を更新する | 更新が成立する（AC-57） | |
| 店舗 p1 に店舗管理者がいない。操作する人はサービス運営者 O | O が p1 の店舗情報を更新する | 申請なしで更新が成立し、保存した時点で店舗に反映される（AC-65） | |
| 利用者 A は店舗 p1 の店舗管理者。p1 の種別は「店舗」 | A が、種別を「スポット」に変えて更新する | 種別がスポットになる。ほかの項目と同じ手続きで変わる（AC-74） | |
| 利用者 A は店舗 p1 の店舗管理者。サービス運営者が p1 を非公開にしている | A が p1 の店舗情報を更新する | 更新が成立する。店舗は非公開のまま | |
| 店舗 p1 に店舗管理者 A がいる。操作する人は、p1 の店舗管理者でないサービス運営者 O | O が p1 の店舗情報を更新する | `ForbiddenError` になる。店舗は変わらない（管理者のいる店舗は代行できない） | |
| 店舗 p1 に店舗管理者がいない間にサービス運営者 O が編集を始め、保存の前に利用者 B が p1 の店舗管理者に就いた | O が p1 の店舗情報を更新する | `ForbiddenError` になる。店舗は変わらない | |
| 利用者 U は、店舗 p1 の店舗管理者でもサービス運営者でもない | U が p1 の店舗情報を更新する | `ForbiddenError` になる。店舗は変わらない | |
| 利用者 A は店舗 p1 の店舗管理者だったが、編集の途中で権限を解除された | A が p1 の店舗情報を更新する | `ForbiddenError` になる。店舗は変わらない | |
| 利用者 A と B は店舗 p1（版 0）の店舗管理者。どちらも版 0 で編集を始め、B が先に更新して版が 1 になった | A が、版 0 を添えて更新する | `ConflictError` になる。店舗は B が保存した内容のまま | |
| 利用者 A は店舗 p1 の店舗管理者 | A が、名称を空白だけにして更新する | `BusinessRuleError`（`PLACE_NAME_REQUIRED`）になる。店舗は変わらない | |
| 利用者 A は店舗 p1 の店舗管理者 | A が、マスターにない町域（`TownRef` を解決できない）を指定して更新する | `BusinessRuleError`（`AREA_TOWN_NOT_FOUND`）になる。店舗は変わらない | |
| 利用者 A は店舗 p1 の店舗管理者。写真 ph4 は別の利用者が登録した、持ち主のない写真 | A が、名称を変え、ph4 を加えて更新する | `BusinessRuleError`（`MEDIA_PHOTO_NOT_REGISTRANT`）になる。名称も写真も変わらず、ph4 の持ち主は設定されない（同じ UnitOfWork でロールバックされる） | |
| 操作する人はサービス運営者 O。ID が p9 の店舗はない | O が p9 の店舗情報を更新する | `NotFoundError` になる | |
