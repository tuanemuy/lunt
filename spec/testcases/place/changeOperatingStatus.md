# changeOperatingStatus

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A は店舗 p1（営業中、版 0）の店舗管理者。p1 に公開中の掲載がある | A が、版 0 を添えて、営業状況を閉店にする | 営業状況が閉店で保存され、版は 1。`place.operating_status_changed`（`from` は営業中、`to` は閉店）が出る。店舗は公開されたままで、公開の期限はない。掲載の公開状態・提供状態は書き換えられない（AC-14） | |
| 利用者 A は店舗 p1（営業中）の店舗管理者 | A が、営業状況を休業にする | 営業状況が休業で保存される。`place.operating_status_changed`（`from` は営業中、`to` は休業）が出る | |
| 利用者 A は店舗 p1（閉店）の店舗管理者 | A が、営業状況を営業中にする | 営業状況が営業中で保存される。`place.operating_status_changed`（`from` は閉店、`to` は営業中）が出る（AC-65） | |
| 利用者 A は店舗 p1（休業）の店舗管理者 | A が、営業状況を閉店にする | 営業状況が閉店で保存される（休業と閉店の間も切り替えられる） | |
| 利用者 A は店舗 p1（休業）の店舗管理者 | A が、営業状況を休業にする（現在と同じ値） | 成功として現在の店舗を返す。書き込みはなく、版は進まず、ドメインイベントは出ない | |
| 店舗 p1（営業中）に店舗管理者がいない。操作する人はサービス運営者 O | O が、営業状況を閉店にする | 申請なしで営業状況が閉店で保存される。`place.operating_status_changed` が出る（AC-65） | |
| 利用者 A は店舗 p1 の店舗管理者。サービス運営者が p1 を非公開にしている | A が、営業状況を休業にする | 営業状況が休業で保存される。店舗は非公開のまま | |
| 店舗 p1 に店舗管理者 A がいる。操作する人は、p1 の店舗管理者でないサービス運営者 O | O が、p1 の営業状況を閉店にする | `ForbiddenError` になる。営業状況は変わらない | |
| 店舗 p1 に店舗管理者がいない間にサービス運営者 O が p1 を開き、変更の前に利用者 B が p1 の店舗管理者に就いた | O が、p1 の営業状況を閉店にする | `ForbiddenError` になる（管理者のいる店舗は代行できない）。営業状況は変わらず、ドメインイベントは出ない | |
| 利用者 U は、店舗 p1 の店舗管理者でもサービス運営者でもない | U が、p1 の営業状況を閉店にする | `ForbiddenError` になる。営業状況は変わらず、ドメインイベントは出ない | |
| 店舗 p1 は地域 X に所属している。利用者 R は X の地域運営者で、店舗の管理権限を持たない | R が、p1 の営業状況を休業にする | `ForbiddenError` になる。営業状況は変わらず、ドメインイベントは出ない（AC-13） | |
| 店舗 p1 はイベント E に参加している。利用者 V は E のイベント運営者で、店舗の管理権限を持たない | V が、p1 の営業状況を休業にする | `ForbiddenError` になる。営業状況は変わらず、ドメインイベントは出ない（AC-18） | |
| 利用者 A と B は店舗 p1（営業中、版 0）の店舗管理者。B が先に営業状況を休業にして、版が 1 になった | A が、版 0 を添えて、営業状況を閉店にする | `ConflictError` になる。営業状況は休業のまま | |
| 操作する人はサービス運営者 O。ID が p9 の店舗はない | O が、p9 の営業状況を閉店にする | `NotFoundError` になる | |
