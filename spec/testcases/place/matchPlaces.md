# matchPlaces

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗「山田珈琲店」（東京都千代田区大手町、写真あり、営業中）と「山田珈琲店 別館」（東京都中央区銀座、写真あり）がある。ログインしていない | 店名「山田珈琲店」で照合する | 「山田珈琲店」「山田珈琲店 別館」を、関連度の高い順で返す。全件数は 2。店舗ごとに種別、名称、所在地、営業状況、代表写真（1枚目の写真）の表示用の参照、関連度を持つ（AC-56） | |
| 上と同じ | 住所「銀座」だけで照合する | 「山田珈琲店 別館」を返す（店名と住所のどちらか一方で探せる）（AC-56） | |
| 上と同じ | 店名「山田珈琲店」と住所「東京都千代田区」で照合する | 両方が一致する「山田珈琲店」が先頭、店名だけが一致する「山田珈琲店 別館」が続く | |
| 写真のない店舗「海の家」があり、その店舗に公開中の掲載（写真あり）がある | 店名「海の家」で照合する | 「海の家」を返す。写真は、Discovery の `ReferenceQueries.resolve` が返す `substituteCover`（その店舗の公開中の掲載の代表写真）で代用される（AC-29） | |
| 写真のない店舗「海の家」があり、その店舗の掲載は下書きと一時非公開だけ | 店名「海の家」で照合する | 「海の家」を、写真なしで返す。写真がなくても結果に含まれる（AC-29） | |
| 休業の店舗「山田珈琲店 別館」と、閉店の店舗「純喫茶 山田珈琲店」がある | 店名「山田珈琲店」で照合する | 休業・閉店の店舗も結果に含まれ、営業状況（休業、閉店）を区別できる | |
| 非公開の店舗「山田」だけが、店名「山田」に一致する。ログインしていない | 店名「山田」で照合する | 空の一覧と全件数 0 を返す。非公開の店舗は現れない | |
| 非公開の店舗「山田」だけが、店名「山田」に一致する。操作する人はサービス運営者としてログインしている | 店名「山田」で照合する | 空の一覧と全件数 0 を返す。操作する人の役割にかかわらず、非公開の店舗は現れない | |
| 店舗「山田珈琲店」（店舗管理者あり）がある。ログインしていない | 店名「山田珈琲店」で照合する | 「山田珈琲店」を返す。結果は、非公開かどうかと管理者の有無を持たない | |
| 店舗がある | 店名も住所も空（空白だけ）で照合する | `BusinessRuleError`（`PLACE_MATCH_TEXT_REQUIRED`）になる | |
| 店名「存在しない店」に一致する店舗がない | 店名「存在しない店」で照合する | 空の一覧と全件数 0 を返す。エラーにならない | |
