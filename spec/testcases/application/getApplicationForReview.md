# getApplicationForReview

期間超過の代行ができるまでの期間（`ReviewPolicy.proxyAfterMs`）は7日とする。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 登録申請 r1 が確認中で、管理権限の申請 s1 を併せている。r1 の名称・所在地に近い公開中の店舗 p1 と、サービス運営者が非公開にしている店舗 p2 がある。操作する人はサービス運営者 O | O が r1 を確かめる | 店舗の情報、申請者、版、`ReviewPermission` は `approver`。併せた申請として s1 の ID と確認中の状態、近い既存の店舗として p1 と p2（非公開であること）が返る。対象の店舗（予約した ID）は、閲覧できるかどうかではなく、対象はまだないとして返る（AC-78） | |
| 併せた管理権限の申請 s1 が確認中。登録申請 r1 も確認中 | O が s1 を確かめる | `ReviewPermission` は `registrationPending`。併せた登録申請 r1 の ID が返る。対象の店舗は、対象はまだないとして返る。エラーにならない | |
| 登録申請 r1 は承認されている。s1 は確認中 | O が s1 を確かめる | `ReviewPermission` は `approver`。対象の店舗は閲覧できるとして返る | |
| 登録申請 r2 は承認されて店舗 p3 が作られ、その後 p3 はサービス運営者が非公開にした | O が r2 を確かめる | 承認の状態と、対象の店舗が閲覧できないことが返る | |
| 登録申請 r1 に併せた s1 が取り下げになり、その後に r1 を参照する再申請 s2 が確認中 | O が r1 を確かめる | 併せた申請として s2 の ID と確認中の状態が返る | |
| 利用者 A の、店舗 p1 への管理権限の申請 a1 が確認中。p1 に店舗管理者 S がいる | O が a1 を確かめる | 店舗との関係、確認に使える連絡先または資料、既存の店舗管理者がいることが返る | |
| A の管理権限の申請 a1 は、追加で必要な確認 q で差し戻された後、回答 w を添えて再提出されて確認中 | O が a1 を確かめる | 再提出された内容、前の差し戻しの q、回答 w が返る | |
| 店舗 p1 への情報修正の申請 a2（名称の項目）が確認中。a2 の提出の後に、別の承認で p1 の名称が変わった | O が a2 を確かめる | 名称について、p1 の読んだ時点の現在の値と、申請の値の組が返る。変更しない項目は返らない。承認で反映される内容として、p1 の読んだ時点の内容に a2 の名称を重ねた内容が返る | |
| 掲載 l1 への修正の申請 a3（説明と写真の項目）が確認中 | O が a3 を確かめる | 説明と写真について、l1 の現在の値と申請の値の組（`FieldPatch.compare`）が返る。写真は表示用の参照を含む。承認で反映される内容（`FieldPatch.preview`）が返る | |
| l1 の写真は ph1、ph2。掲載の修正の申請 a5 の写真の項目は ph3、ph1（ph3 は a5 が持ち主）。a5 の提出の後に、ph1 は申立てで l1 から削除された | O が a5 を確かめる | 写真の見比べの申請の値は ph3、ph1。承認で反映される内容の写真は ph3 だけ | |
| 公開中の掲載 l1 への修正の申請 a7 が確認中の間に、l1 が紐づく店舗 p1 がサービス運営者によって非公開になった | O が a7 を確かめる | a7 は確認中で、見比べと承認で反映される内容が返る。対象の店舗 p1 と掲載 l1 が、どちらも閲覧できないことが併せて返る | |
| 掲載 l1 への修正の申請 a6（名称の項目）が、l1 の削除で失効している | O が a6 を確かめる | 失効の状態と、名称の申請の値だけが返る。見比べと承認で反映される内容は返らず、対象の掲載がないことが返る（`getMyApplication` と同じ） | |
| 掲載の申請 a4 の内容のカテゴリー c1 は廃止され、移行先は c2 | O が a4 を確かめる | カテゴリーは c2 で返る | |
| 情報修正の申請 a2 の対象の店舗 p1 が、確認中の間にサービス運営者によって非公開になった | O が a2 を確かめる | a2 は確認中で、`ReviewPermission` は `approver`。対象の店舗が閲覧できないことが併せて返る | |
| 利用者 R は地域 X の運営者。X への所属の申請 b1 が確認中 | R が b1 を確かめる | 種類（所属）、対象の店舗と地域、申請者が返る。`ReviewPermission` は `approver` | |
| 利用者 V はイベント e1 の運営者。e1 への参加の申請 b2 が、掲載 l1 と参加日を添えて確認中 | V が b2 を確かめる | 対象の店舗、添えた掲載 l1、参加日が返る。`ReviewPermission` は `approver` | |
| b2 に添えた掲載は l1・l2・l3。確認中に、l1 は一時非公開、l2 は運営による非公開になり、l3 は削除された | V が b2 を確かめる | 添えた掲載として l1・l2・l3 のすべてが、l1 は一時非公開、l2 は運営による非公開、l3 は削除されたこととともに返る | |
| 地域 X に運営者がいる。b1 は3日前から確認中。O は X の運営者でない | O が b1 を確かめる | `ReviewPermission` は `awaitingStewards`（期間超過の前）。エラーにならない | |
| 地域 X に運営者がいる。b1 は10日前から確認中 | O が b1 を確かめる | `ReviewPermission` は `overdue_proxy`（AC-67） | |
| 地域 Y に運営者がいない。Y への所属の申請 b3 が、1日前から確認中 | O が b3 を確かめる | `ReviewPermission` は `approver`（AC-16） | |
| b1 は、サービス運営者の期間超過の代行で否認されている | R が b1 を確かめる | 否認の状態、理由、判断の立場が期間超過の代行（`overdue_proxy`）であることが返る | |
| A の申請 a1 は、判断の前に取り下げられた | O が a1 を確かめる | 取り下げの状態が返る | |
| 写真 ph1 を内容に持つ登録申請 r3 は否認されている | O が r3 を確かめる | 否認の状態と、写真 ph1 を含む内容が返る | |
| 利用者 U は、地域 X の運営者でも、サービス運営者でもない | U が b1 を確かめる | `ForbiddenError` になる | |
| R は地域 X の運営者で、サービス運営者でない | R が、情報修正の申請 a2 を確かめる | `ForbiddenError` になる | |
| ID が a9 の申請はない | O が a9 を確かめる | `NotFoundError` になる | |
