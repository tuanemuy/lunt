# getApplicationForReview

代行できるまでの期間は7日とする。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 登録申請 r1 が確認中で、管理権限の申請 s1 を併せている。r1 の名称・所在地に近い公開中の店舗 p1 と、サービス運営者が非公開にしている店舗 p2 がある。操作する人はサービス運営者 O | O が r1 を確かめる | 種別と店舗の情報、申請者、補足、版、`ReviewPermission` は `approver`。併せた申請 s1 の ID と、近い既存の店舗として p1 と p2（非公開であること）が返る（AC-78） | |
| 併せた管理権限の申請 s1 が確認中。登録申請 r1 も確認中 | O が s1 を確かめる | `ReviewPermission` は `registrationPending`。併せた登録申請 r1 の ID が返る。エラーにならない | |
| 登録申請 r1 は承認されている。s1 は確認中 | O が s1 を確かめる | `ReviewPermission` は `approver` | |
| 利用者 A の、店舗 p1 への管理権限の申請 a1 が確認中。p1 に店舗管理者 S がいる | O が a1 を確かめる | 店舗との関係、確認に使える連絡先または資料、既存の店舗管理者がいることが返る | |
| A の管理権限の申請 a1 は、追加で必要な確認 q で差し戻された後、再提出されて確認中 | O が a1 を確かめる | 再提出された内容と補足、前の差し戻しの q が返る | |
| 店舗 p1 への情報修正の申請 a2（名称の項目）が確認中。a2 の提出の後に、別の承認で p1 の名称が変わった | O が a2 を確かめる | 名称について、p1 の読んだ時点の現在の値と、申請の値の組が返る。変更しない項目は返らない | |
| 掲載 l1 への修正の申請 a3（説明と写真の項目）が確認中 | O が a3 を確かめる | 説明と写真について、l1 の現在の値と申請の値の組（`ListingPatch.compare`）が返る。写真は表示用の参照を含む | |
| 掲載の申請 a4 の内容のカテゴリー c1 は廃止され、移行先は c2 | O が a4 を確かめる | カテゴリーは c2 で返る | |
| 情報修正の申請 a2 の対象の店舗 p1 が、確認中の間にサービス運営者によって非公開になった | O が a2 を確かめる | a2 は確認中で、`ReviewPermission` は `approver`。対象の店舗が閲覧できないことが併せて返る | |
| 利用者 R は地域 X の運営者。X への所属の申請 b1 が確認中 | R が b1 を確かめる | 種類（所属）、対象の店舗と地域、申請者が返る。`ReviewPermission` は `approver` | |
| 利用者 V はイベント e1 の運営者。e1 への参加の申請 b2 が、掲載 l1 と参加日を添えて確認中 | V が b2 を確かめる | 対象の店舗、添えた掲載 l1、参加日が返る。`ReviewPermission` は `approver` | |
| 地域 X に運営者がいる。b1 は3日前から確認中。O は X の運営者でない | O が b1 を確かめる | `ReviewPermission` は `awaitingStewards`。エラーにならない | |
| 地域 X に運営者がいる。b1 は10日前から確認中 | O が b1 を確かめる | `ReviewPermission` は `proxy`（AC-67） | |

| b1 は、サービス運営者の代行で否認されている | R が b1 を確かめる | 否認の状態、理由、判断した人の立場が代行であることが返る | |
