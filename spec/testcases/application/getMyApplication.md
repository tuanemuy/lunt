# getMyApplication

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A の管理権限の申請 a1 が確認中 | A が a1 を確かめる | 種類、対象の店舗とその名称、申請者、店舗との関係と連絡先、確認中の状態、版が返る | |
| A の申請 a1 は、追加で必要な確認 q で差し戻された後、回答 w を添えて再提出されて確認中 | A が a1 を確かめる | 確認中の状態と、答えている q と、回答 w が返る | |
| A の申請 a1 は、q で差し戻され、回答 w を添えて再提出された後に、承認された | A が a1 を確かめる | 承認の状態と反映先が返る。q と w は返らない（回答は確認中の間だけ示す） | |
| A の申請 a1 が、追加で必要な確認 q を添えて差し戻されている | A が a1 を確かめる | 差し戻しの状態と q が返る（AC-21） | |
| A の申請 a1 が、理由 r を添えて否認されている | A が a1 を確かめる | 否認の状態と r が返る（AC-21） | |
| A の情報修正の申請 a2（店舗 p1）が、`placeHasNoSteward` を欠いて失効している | A が a2 を確かめる | 失効の状態と、成り立たなくなった前提 `placeHasNoSteward` が返る | |
| A の情報修正の申請 a2（店舗 p1、名称と営業時間の項目）が確認中 | A が a2 を確かめる | 名称と営業時間だけについて、p1 の現在の値と申請の値の組が返る。変更しない項目は返らない。p1 の現在の内容に申請の項目を重ねた内容を併せて返す | |
| A の掲載の修正の申請 a3（掲載 l1、名称の項目）が確認中 | A が a3 を確かめる | 名称だけについて、l1 の現在の値と申請の値の組が返る | |
| A の掲載の申請 a4 が承認されている | A が a4 を確かめる | 承認の状態と、反映先として予約した `reservedListingId` の掲載への参照が返る | |
| A の管理権限の申請 a1 が承認されている | A が a1 を確かめる | 反映先として店舗への参照が返る | |
| A の掲載の申請 a4 が承認された後に、その掲載が削除された | A が a4 を確かめる | 承認の状態と反映先の参照が返る（申請の結果は確かめられる） | |
| A の掲載の申請 a7（写真 ph1、ph2）が否認されている | A が a7 を確かめる | 否認の状態と理由、写真 ph1・ph2（表示用の参照を含む）と名称・説明・カテゴリー・提供の設定が返る（終わった申請も写真を持つ） | |
| A の情報修正の申請 a8（店舗 p1 の写真 ph0 に、新たに ph3 を加える写真の項目）が取り下げになっている | A が a8 を確かめる | 写真の項目の申請の値と、重ねた内容の写真は、どちらも ph0、ph3 | |
| A の掲載の修正の申請 a9（掲載 l1、名称と写真の項目。写真は l1 の ph1 と、a9 が持ち主の ph5）が、l1 の削除で失効している | A が a9 を確かめる | 失効の状態と `listingExists`、名称の申請の値、写真の項目の ph5 だけが返る。見比べと重ねた内容は返らず、対象の掲載がないことが返る | |
| A の登録申請 r1 と、併せた管理権限の申請 s1 がある | A が r1 と s1 をそれぞれ確かめる | r1 は併せた申請として s1 の ID と状態を、s1 は r1 の ID を含む。状態はそれぞれの申請のもの | |
| A の登録申請 r1 に併せた s1 が取り下げになり、その後に r1 を参照する再申請 s2 が確認中 | A が r1 を確かめる | 併せた申請として s2 の ID と確認中の状態が返る（進行中のもの） | |
| A の登録申請 r1（店舗の名称は N）が差し戻し | A が r1 を確かめる | 対象の店舗は、閲覧できない対象としてではなく、対象はまだないとして、名称 N とともに返る | |
| 同上。その後、s2 も取り下げになった | A が r1 を確かめる | 併せた申請として s2 の ID と取り下げの状態が返る（最も新しく提出されたもの） | |
| A の掲載の申請 a5 の内容のカテゴリー c1 は、提出の後に廃止され、移行先は c2 | A が a5 を確かめる | カテゴリーは c2 で返る | |
| 店舗 p1 の店舗管理者 T が店舗管理者として行った参加の申請 a6 がある。S は p1 の別の店舗管理者 | S が a6 を確かめる | T が確かめたときと同じ内容が返る。申請者は店舗 p1（AC-66） | |
| a6 に添えた掲載 l1 が、確認中に一時非公開になった | S が a6 を確かめる | 添えた掲載に l1 が残り、一時非公開であることとともに返る | |
| A の申請 a1 がある。利用者 B は申請者でない | B が a1 を確かめる | `ForbiddenError` になる。申請の内容は返らない | |
| 店舗 p1 について店舗管理者として行った申請 a6 がある。T は p1 の管理権限を解除されている | T が、自分が提出した a6 を確かめる | `ForbiddenError` になる | |
| ID が a9 の申請はない | A が a9 を確かめる | `NotFoundError` になる | |
