# getMyApplication

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A の管理権限の申請 a1 が確認中 | A が a1 を確かめる | 種類、対象の店舗、申請者、店舗との関係と連絡先、補足、確認中の状態、版が返る | |
| A の申請 a1 が、追加で必要な確認 q を添えて差し戻されている | A が a1 を確かめる | 差し戻しの状態と q が返る（AC-21） | |
| A の申請 a1 が、理由 r を添えて否認されている | A が a1 を確かめる | 否認の状態と r が返る（AC-21） | |
| A の情報修正の申請 a2（店舗 p1）が、`placeHasNoSteward` を欠いて失効している | A が a2 を確かめる | 失効の状態と、成り立たなくなった前提 `placeHasNoSteward` が返る | |
| A の情報修正の申請 a2（店舗 p1、名称と営業時間の項目）が確認中 | A が a2 を確かめる | 名称と営業時間だけについて、p1 の現在の値と申請の値の組が返る。変更しない項目は返らない。p1 の現在の内容に申請の項目を重ねた内容を併せて返す | |
| A の掲載の修正の申請 a3（掲載 l1、名称の項目）が確認中 | A が a3 を確かめる | 名称だけについて、l1 の現在の値と申請の値の組が返る | |
| A の掲載の申請 a4 が承認されている | A が a4 を確かめる | 承認の状態と、反映先として予約した `reservedListingId` の掲載への参照が返る | |
| A の管理権限の申請 a1 が承認されている | A が a1 を確かめる | 反映先として店舗への参照が返る | |
| A の掲載の申請 a4 が承認された後に、その掲載が削除された | A が a4 を確かめる | 承認の状態と反映先の参照が返る（申請の結果は確かめられる） | |
| A の掲載の申請 a7（写真 ph1、ph2）が否認されていて、ph1 と ph2 は手放されている | A が a7 を確かめる | 否認の状態と理由、名称・説明・カテゴリー・提供の設定が返る。内容の写真は1枚も返らない | |
| A の情報修正の申請 a8（店舗 p1 の写真 ph0 に、新たに ph3 を加える写真の項目）が取り下げになっていて、ph3 は手放されている | A が a8 を確かめる | 写真の項目の申請の値と、重ねた内容の写真は、どちらも ph0 だけ。ph3 は返らない | |
| A の登録申請 r1 と、併せた管理権限の申請 s1 がある | A が r1 と s1 をそれぞれ確かめる | r1 は s1 の ID を、s1 は r1 の ID を含む。状態はそれぞれの申請のもの | |
| A の掲載の申請 a5 の内容のカテゴリー c1 は、提出の後に廃止され、移行先は c2 | A が a5 を確かめる | カテゴリーは c2 で返る | |
| 店舗 p1 の店舗管理者 T が行った参加の申請 a6 がある。S は p1 の別の店舗管理者 | S が a6 を確かめる | T が確かめたときと同じ内容が返る。申請者は店舗 p1（AC-66） | |
| A の申請 a1 がある。利用者 B は申請者でない | B が a1 を確かめる | `ForbiddenError` になる。申請の内容は返らない | |
| 店舗 p1 が行った申請 a6 がある。T は p1 の管理権限を解除されている | T が、自分が提出した a6 を確かめる | `ForbiddenError` になる | |
| ID が a9 の申請はない | A が a9 を確かめる | `NotFoundError` になる | |
