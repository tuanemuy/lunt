# notifyOverdueReviews

代行できるまでの期間は7日とする。地域 X とイベント e1 は運営者がいる。地域 Y は運営者が不在。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| X への所属の申請 b1（10日前から確認中）と、e1 への参加の申請 c1（8日前から確認中）がある。どちらも通知した記録がない | ジョブを実行する | b1 と c1 のそれぞれに、`pendingSince` が確認中になった日時の `application.review_overdue` が1つずつ出る。それぞれの通知した記録が保存される。申請は変わらず、版は進まない（AC-67） | |
| X への離脱の申請 b2 は、3日前から確認中 | ジョブを実行する | b2 のドメインイベントは出ず、記録も作られない | |
| Y への所属の申請 b3（10日前から確認中）と、情報修正の申請 a1（10日前から確認中）がある | ジョブを実行する | どちらのドメインイベントも出ない（サービス運営者が承認者の申請は対象でない） | |
| X への申請 b4 は、10日前から差し戻し。X への申請 b5 は、10日前に確認中になり、その後に否認された | ジョブを実行する | どちらのドメインイベントも出ない | |
| b1 は、前の実行で通知されている。確認中のまま | ジョブをもう一度実行する（同じ日、または翌日） | b1 のドメインイベントは出ない（1回の確認中につき1回） | |
| b1 は、通知された後に差し戻され、再提出で確認中に戻り、再提出から8日が過ぎた | ジョブを実行する | b1 に、`pendingSince` が再提出の日時の `application.review_overdue` がもう一度出る。記録は置き換わる | |
| b1 は、通知された後に差し戻され、再提出で確認中に戻り、再提出から2日が過ぎた | ジョブを実行する | b1 のドメインイベントは出ない | |
| 対象の申請が、1回に読む件数を超えてある | ジョブを実行する | すべての対象の申請に、ドメインイベントが1つずつ出る | |
| 対象の申請 b1 と c1 がある。b1 の記録とドメインイベントの保存が失敗する | ジョブを実行する | c1 の記録とドメインイベントは確定する。b1 は記録もドメインイベントも残らず、次の実行が b1 を取り出す | |
| 対象の申請がない | ジョブを実行する | 何も書き込まれず、ドメインイベントは出ない | |
| 対象の申請 b1 と c1 がある。どちらの記録とドメインイベントの保存も失敗する | ジョブを実行する | ジョブは、読んだページの全件が失敗した時点で打ち切る。記録もドメインイベントも残らず、次の実行が b1 と c1 を取り出す | |
