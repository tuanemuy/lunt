|---|---|---|---|
| 店舗 p2 に店舗管理者がいない。利用者 A が個人として行った、p2 の地域 X への所属の申請 a1（確認中）、p2 の地域 Y への所属の申請 a2（差し戻し）、p2 の情報修正の申請 a3（確認中）がある | A が p2 について読む | a1・a2・a3 が、種類、対象（a1 は X、a2 は Y）、状態とともに返る | |
