# previewListingSubmission

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 p1 は公開されていて、公開中の地域 X に所属している。利用者 A が登録した写真 ph1、ph2 がある | A が、p1 と、写真 ph1・ph2（見せる範囲を含む）、名称、カテゴリー、説明、提供期間を入力して、見え方を確かめる | 掲載の要約と掲載詳細と同じ形の内容が返る。代表写真は ph1 で、見せる範囲と表示用の参照を含む。名称、p1 の店舗名、X の地域名、現役に解決したカテゴリー、説明、提供の設定と提供状態を、別の項目として含む。価格とキャッチコピーを含まない | |
| 同上 | 見え方を確かめる | 申請は作られず、写真の持ち主は設定されない。ドメインイベントは出ない | |
| 店舗 p1 の掲載 l1 の修正を入力している | A が、修正後の内容（名称を変え、写真を1枚加えた）を入力して、見え方を確かめる | 修正後の内容の見え方が返る。l1 は変わらない | |
| 店舗 p1 は、公開中の地域 X と、公開を取り下げた地域 Z に所属している | A が見え方を確かめる | 閲覧者に示す地域の名称は X だけ | |
| 店舗 p1 はどの地域にも所属していない | A が見え方を確かめる | 地域の名称を含まない内容が返る | |
| 店舗 p1 は公開されている | A が、写真も名称も入力せずに、見え方を確かめる | 名称と代表写真のない見え方が返る（公開条件を欠く内容も投影する） | |
| 店舗 p1 はサービス運営者が非公開にしている | A が p1 で見え方を確かめる | `NotFoundError` になる | |
