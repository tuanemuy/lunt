# listMyApplications

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A は店舗 p1 の店舗管理者。A の個人の申請 a1（先に提出、否認）と a2（最後に提出、確認中）、p1 が行った所属の申請 a3（a1 と a2 の間に、別の店舗管理者 T が提出）が保存されている | A が、絞り込みなしで一覧を読む | a2・a3・a1 の順（提出の新しい順）に返る。申請ごとに、種類、対象、申請者（a3 は店舗 p1）、状態を含む。全件数は 3 | |
| A の登録申請 r1 と、併せた管理権限の申請 s1 が保存されている | A が一覧を読む | r1 と s1 が、別の申請として返る | |
| A は店舗 p1 と p2 の店舗管理者。p1 が行った申請と、p2 が行った申請、A の個人の申請が保存されている | A が、p1 に絞って一覧を読む | p1 が行った申請だけが返る。A の個人の申請と p2 の申請は返らない | |
| A は店舗 p1 の管理権限を手放した。p1 が行った申請 a3 は、A が提出したもの | A が、絞り込みなしで一覧を読む | a3 は返らない | |
| A が個人として行った、店舗 p3 の情報修正の申請がある。A は p3 の店舗管理者でない | A が一覧を読む | その申請が返る | |
| 利用者 B の個人の申請だけが保存されている。A は申請を1件も出していない | A が一覧を読む | 空の一覧と、全件数 0 が返る | |
| A は店舗 p1 の店舗管理者でない | A が、p1 に絞って一覧を読む | `ForbiddenError` になる | |
