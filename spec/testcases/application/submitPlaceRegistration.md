# submitPlaceRegistration

エリアのマスターは [../ports/areaCatalog.md](../ports/areaCatalog.md) の「テスト用のマスター」。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A がログインしている | A が、申請の ID r1、種別「店舗」、名称、町域、位置、補足を入力して、登録を申請する | 確認中の登録申請 r1 が保存される。申請者は A、`submittedAt` と `since` は現在時刻、`answering` は `null`。`reservedPlaceId` は新しく予約された ID で、その ID の店舗はまだない。承認者の席が `operator` の `application.submitted` が1つ出る | |
| A が登録した、持ち主のない写真 ph1、ph2 がある | A が、写真を ph1、ph2 の順に添えて登録を申請する | 申請の内容の写真は ph1、ph2 の順。ph1 と ph2 の持ち主は、その申請になる | |
| 利用者 A がログインしている | A が、登録申請の ID r1 と管理権限の申請の ID s1、店舗の情報、店舗との関係、確認に使える連絡先を入力して、管理権限の申請を併せて登録を申請する | 2つの申請がそれぞれ確認中で保存される。s1 の対象の指定は、`registrationId` が r1 で、`placeId` は r1 の `reservedPlaceId` と同じ。`application.submitted` が2つ出る（AC-08） | |
| A の登録申請 r1 が確認中 | A が、同じ店舗の情報で、別の ID r2 の登録を申請する | r2 が確認中で保存される。r1 は変わらない（登録申請は重ねて出せる） | |
| A の登録申請 r1（写真 ph1）が否認になっていて、ph1 は手放されている。A が新しく登録した、持ち主のない写真 ph4 がある | A が、r1 の内容から写真を除いた内容を直し、ph4 を添えて、別の ID r2 で登録を申請する | r2 が確認中で保存される。ph4 の持ち主は r2 になる。r1 は否認のまま残り、r2 は r1 との結びつきを持たない（AC-21） | |
| A の登録申請 r1 が確認中で保存されている | A が、同じ ID r1 と同じ内容・補足で、もう一度申請する | 成功として r1 を返す。書き込みはなく、版は進まず、ドメインイベントは出ない。`reservedPlaceId` は変わらない | |
| A の登録申請 r1 と併せた申請 s1 が確認中で保存されている | A が、同じ ID r1・s1 と同じ内容で、もう一度申請する | 成功として r1 と s1 を返す。書き込みもドメインイベントもない。新しい ID は予約されず、s1 の対象の指定は、保存されている r1 の `reservedPlaceId` で作って比べられる | |
| A の登録申請 r1 が確認中で保存されている | A が、同じ ID r1 で、名称の違う内容を申請する | `ConflictError` になる。r1 は変わらない | |
| 利用者 A がログインしている | A が、名称を空白だけにして登録を申請する | `BusinessRuleError`（`PLACE_NAME_REQUIRED`）になる。申請は作られない | |
| 利用者 A がログインしている | A が、マスターにない町域を指定して登録を申請する | `BusinessRuleError`（`AREA_TOWN_NOT_FOUND`）になる。申請は作られない | |
| 利用者 A がログインしている | A が、管理権限の申請を併せ、店舗との関係を空にして申請する | `BusinessRuleError`（`APPLICATION_CLAIM_REQUIRED`）になる。登録申請も管理権限の申請も作られない | |
| 写真 ph3 は別の利用者が登録した、持ち主のない写真 | A が、ph3 を添えて登録を申請する | `BusinessRuleError`（`MEDIA_PHOTO_NOT_REGISTRANT`）になる。申請は作られず、ph3 の持ち主は設定されない | |
| 同じ ID s1 の管理権限の申請が、すでに別の内容で保存されている | A が、登録申請の ID r1 と管理権限の申請の ID s1 で、併せて申請する | `ConflictError` になる。r1 も作られない（2つの申請は同じ UnitOfWork で確定する） | |
