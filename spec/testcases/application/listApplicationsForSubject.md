# listApplicationsForSubject

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 R は地域 X の運営者。X への所属の申請 x1（最も先に提出、承認）、離脱の申請 x2（次に提出、確認中）、所属の申請 x3（次に提出、否認）、所属の申請 x4（最後に提出、差し戻し）が保存されている | R が X の申請を読む | x4・x2・x3・x1 の順（進行中を先に、次に提出の新しい順）に返る。申請ごとに、種類（所属・離脱）、対象の店舗、申請者、状態を含む。確認中の申請の件数は 1 | |
| X への所属の申請 x5 は、サービス運営者が代行で承認した | R が X の申請を読む | x5 は承認の状態で、判断した人の立場が代行として返る | |
| 利用者 V はイベント e1 の運営者。e1 への参加の申請が、掲載 l1 と参加日を添えて確認中 | V が e1 の申請を読む | 申請が、対象の店舗、申請者（店舗）、添えた掲載と参加日、状態とともに返る | |
| 地域 Y に運営者がいない。操作する人はサービス運営者 O | O が Y の申請を読む | Y への申請が返る（運営者が不在の地域の代行） | |
| 利用者 S は店舗 p1 の店舗管理者。p1 が行った所属の申請 a1（確認中、別の店舗管理者 T が提出）、参加の申請 a2（差し戻し）、離脱の申請 a3（承認）と、利用者 B が個人として行った p1 の管理権限の申請 a4（確認中）が保存されている | S が p1 の申請を読む | a1 と a2 だけが返る。終わった a3 と、個人の申請 a4 は返らない | |
| X への申請が1件もない | R が X の申請を読む | 空の一覧、全件数 0、確認中の件数 0 が返る | |
| 利用者 U は X の運営者でも、サービス運営者でもない | U が X の申請を読む | `ForbiddenError` になる | |
| 地域 X に運営者がいる。サービス運営者 O は X の運営者でない | O が X の申請を読む | `ForbiddenError` になる | |

| 店舗 p2 に店舗管理者がいない。操作する人はサービス運営者 O | O が p2 の申請を読む | `ForbiddenError` になる（店舗として行う操作に代行はない） | |
