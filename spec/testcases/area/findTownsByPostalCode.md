# findTownsByPostalCode

マスターの内容は [../ports/areaCatalog.md](../ports/areaCatalog.md) の「テスト用のマスター」。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| テスト用のマスター。ログインしていない | 郵便番号「1040061」で町域の候補を引く | 銀座（東京都中央区、`AreaCode` 1040061）の1件を返す。候補は `AreaCode`、市区町村コード、地名、表示名、都道府県と市区町村の名称を持つ | |
| テスト用のマスター | 郵便番号「１０４－００６１」（全角の数字とハイフン）で町域の候補を引く | 「1040061」と同じ結果を返す | |
| テスト用のマスター | 複数の町域が対応する郵便番号「9990001」で町域の候補を引く | 乙町、甲町の2件を、この順（`AreaCatalog.listTowns` の並び順）で返す。どちらの `AreaCode` も 9990001 | |
| テスト用のマスター | 市区町村の全域を指す郵便番号「1000000」で町域の候補を引く | 地名が空の町域（東京都千代田区）の1件を返す | |
| テスト用のマスター | 事業所固有の郵便番号「1008111」で町域の候補を引く | `BusinessRuleError`（`AREA_TOWN_NOT_FOUND`）になる。所在地は決まらない | |
| テスト用のマスター | 7桁の数字にならない「10400」で町域の候補を引く | `BusinessRuleError`（`AREA_INVALID_POSTAL_CODE`）になる | |
