| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| テスト用のマスター。ログインしていない | 都道府県の一覧を読む | 13 東京都、27 大阪府を、コードの昇順で返す。各件は、都道府県の単位の選択を組み立てられるコードと名称を持つ（AC-03） | |
| テスト用のマスター | 都道府県 13 の市区町村の一覧を読む | 13101 千代田区、13102 中央区を、コードの昇順で返す。各件は、市区町村の単位の選択を組み立てられるコードと名称を持つ（AC-03） | |
| テスト用のマスター | 市区町村 13101 の町域の一覧を読む | 市区町村の全域を指す町域（1000000）、大手町（1000004）、千代田（1000001）を、この順で返す。各件は `AreaCode`、市区町村コード、地名、郵便番号と対応する地名を併せた表示名を持つ。市区町村の全域を指す町域の表示名の地名は、東京都と千代田区だけ（AC-03） | |

| テスト用のマスター | マスターにない都道府県 47 の市区町村の一覧を読む | 空の一覧を返す。エラーにならない | |
| テスト用のマスター | マスターにない市区町村 13103 の町域の一覧を読む | 空の一覧を返す。エラーにならない | |
