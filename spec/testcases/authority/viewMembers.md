# viewMembers

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 P の管理者は A、B（就任の古い順）。承諾前の招待が、C のメールアドレス宛て、D のメールアドレス宛て（招待の古い順）にある | A を `Actor` として P を確認する | 管理者を A、B の順に、それぞれのメールアドレスつきで返す。A が自分であることが分かる。招待を C 宛て、D 宛ての順に、宛先のメールアドレスつきで返す。管理者不在でないことと、立場が `steward` であることを返す | |
| 地域 R の管理者は A だけ。承諾前の招待はない | A を `Actor` として R を確認する | 管理者 A と、空の招待の一覧を返す | |
| 店舗 P の管理者は A。O はサービス運営者で、P の管理者ではない | O を `Actor` として P を確認する | 管理者と招待を返す。立場は `operator` | |
| イベント E は管理者不在で、承諾前の招待が1件残っている。O はサービス運営者 | O を `Actor` として E を確認する | 管理者不在であることと、空の管理者の一覧、残っている招待を返す。立場は `operator` | |
| 管理体制が保存されたことのない地域 R がある。O はサービス運営者 | O を `Actor` として R を確認する | 管理者不在であることと、空の管理者・招待の一覧を返す | |
| 店舗 P の管理者は A。X は P の管理者でもサービス運営者でもない | X を `Actor` として P を確認する | `ForbiddenError` | |
| X は地域 R の管理者で、店舗 P の管理者ではない | X を `Actor` として P を確認する | `ForbiddenError`。権限は対象ごとに独立している（AC-45） | |
| X は編集担当者で、店舗 P の管理者ではない | X を `Actor` として P を確認する | `ForbiddenError` | |
| A は店舗 P の管理者だったが、辞任した（または解除された） | A を `Actor` として P を確認する | `ForbiddenError` | |
