# listRoleHolders

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| サービス運営者は O1、O2（付与の古い順）。編集担当者は E1、O1（付与の古い順） | O1 を `Actor` として実行する | 編集担当者を E1、O1 の順に、サービス運営者を O1、O2 の順に、それぞれのメールアドレスつきで返す。どちらの一覧でも O1 が自分であることが分かる | |
| サービス運営者は O1 だけ。編集担当者はいない | O1 を `Actor` として実行する | 空の編集担当者の一覧と、O1 だけのサービス運営者の一覧を返す | |
| E1 は編集担当者で、サービス運営者ではない | E1 を `Actor` として実行する | `ForbiddenError` | |
| O2 はサービス運営者だったが、役割を解除されている | O2 を `Actor` として実行する | `ForbiddenError` | |
