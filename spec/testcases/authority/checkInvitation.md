# checkInvitation

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 P に、C のメールアドレス宛ての承諾前の招待がある | C を `Actor` として、P とその `InvitationId` で確認する | `"acceptable"` と、対象が店舗であること、P の名称を返す | |
| 下書きの地域 R に、C のメールアドレス宛ての承諾前の招待がある | C を `Actor` として確認する | `"acceptable"` と、対象が地域であること、R の名称を返す。閲覧者に公開されていない対象でも返す | |
| 名称が未入力の下書きのイベント E に、C のメールアドレス宛ての承諾前の招待がある | C を `Actor` として確認する | `"acceptable"` と、対象がイベントであることを、名称なしで返す | |
| イベント E は管理者不在で、C のメールアドレス宛ての承諾前の招待が残っている | C を `Actor` として確認する | `"acceptable"` を返す | |
| 店舗 P に、C のメールアドレス宛ての承諾前の招待がある。X のメールアドレスは C と異なる | X を `Actor` として確認する | `"addressed_to_other"` を返す。対象の名称は返さない | |
| 店舗 P の C 宛ての招待が取り消されている | C を `Actor` として確認する | `"not_found"` を返す | |
| 店舗 P1 に、C のメールアドレス宛ての承諾前の招待がある。店舗 P2 に招待はない | C を `Actor` として、P2 と、P1 の招待の `InvitationId` で確認する | `"not_found"` を返す。招待は対象と `InvitationId` の組で引く | |
| C は店舗 P の管理者（C 宛ての招待の後、管理権限の申請が先に承認された） | C を `Actor` として、その招待の `InvitationId` で確認する | `"already_steward"` を返す | |
| 店舗 P に、C のメールアドレス宛ての承諾前の招待がある | C を `Actor` として確認する | 実行の後も、P の管理体制は変わらない。ドメインイベントは出ない | |
