# previewWithdrawal

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| アカウント A は、どの対象の管理者でもなく、役割も持たない | A を `Actor` として実行する | 退会できることと、管理者不在になる対象が空であることを返す | |
| A は店舗 P の唯一の管理者で、地域 R の2人の管理者の1人 | A を `Actor` として実行する | 退会できることと、管理者不在になる対象として P だけを、P の名称つきで返す。R は含めない | |
| A は店舗 P、地域 R、イベント E の唯一の管理者。R は名称が未入力の下書き。P は運営による非公開 | A を `Actor` として実行する | 管理者不在になる対象を P、R、E の順で返す。P と E は名称つき、R は名称なしで返す。公開状態と運営による非公開を問わない | |
| A は店舗 P の招待の宛先であるだけで、管理者ではない | A を `Actor` として実行する | 管理者不在になる対象は空 | |
| A は唯一のサービス運営者 | A を `Actor` として実行する | 退会できないことと、その理由（`RoleRoster.removal` の `last_operator`。唯一のサービス運営者である）を返す（AC-76） | |
| A と B がサービス運営者 | A を `Actor` として実行する | 退会できることを返す | |
| A は唯一の編集担当者 | A を `Actor` として実行する | 退会できることを返す（編集担当者は最後の1人でも退会できる） | |
| A は店舗 P の唯一の管理者 | A を `Actor` として実行する | 実行の後も、A のアカウント、P の管理体制、名簿は変わらない。ドメインイベントは出ない | |
