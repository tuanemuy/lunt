# getInfoReport

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗管理者のいる店舗についての、未対応の連絡がある。操作する人はサービス運営者 | 連絡を読む | 連絡の対象とその名称、種類、内容、連絡した人の `AccountId` とメールアドレス、受け付けた日時、状態（未対応）を返す。対象は「ある・閲覧できる」。店舗管理者の有無は「いる」（AC-77） | |
| 未対応の連絡の対象の店舗で、連絡の後にすべての店舗管理者が辞任・退会した | サービス運営者が連絡を読む | 連絡を返す。店舗管理者の有無は「いない」 | |
| 掲載を対象にした未対応の連絡があり、その掲載は提出の後に削除されている | サービス運営者が連絡を読む | エラーにならない。連絡を返し、対象は掲載の ID と店舗の `placeId` を持つ。対象は「ない」で、掲載の名称は持たず、店舗の名称を持つ。店舗管理者の有無は、その店舗について返す | |
| 未対応の連絡の対象の店舗が、連絡の後に非公開になっている | サービス運営者が連絡を読む | 対象は「ある・閲覧できない」。店舗の名称を返す | |
| 未対応の連絡があり、連絡した人は提出の後に退会している | サービス運営者が連絡を読む | 連絡を返す。連絡した人は `AccountId` だけを持ち、メールアドレスを持たない | |
| 確認依頼中の連絡がある | サービス運営者が連絡を読む | 状態（確認依頼中）と、依頼の日時を返す | |
| 依頼を経て対応済みになった連絡がある | サービス運営者が連絡を読む | 状態（対応済み）と、依頼の日時を返す | |
| 依頼せずに対応済みになった連絡がある | サービス運営者が連絡を読む | 状態（対応済み）を返す。依頼の日時は持たない | |
| 未対応の連絡がある。操作する人はサービス運営者の役割を持たない | 連絡を読む | `ForbiddenError`。連絡の内容は返らない | |
