# getConfirmationRequest

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 P を対象にした確認依頼中の連絡がある。操作する人は P の店舗管理者 | 依頼を読む | 対象（店舗）とその名称、種類、内容、依頼の日時と、連絡が確認依頼中であることを返す（AC-77） | |
| 店舗 P の掲載を対象にした確認依頼中の連絡がある | P の店舗管理者が依頼を読む | 対象（掲載とその店舗）とそれぞれの名称、対象の掲載が「ある」こと、種類、内容、依頼の日時を返す | |
| 店舗 P の掲載を対象にした確認依頼中の連絡があり、その掲載は削除されている | P の店舗管理者が依頼を読む | エラーにならない。対象（掲載の ID と店舗の `placeId`）と依頼の内容を返す。対象の掲載は「ない」で、掲載の名称は持たない | |
| 依頼を経て、サービス運営者が対応を終えた連絡がある | P の店舗管理者が依頼を読む | 依頼の内容と、連絡が対応済みであることを返す | |
| 店舗 P に店舗管理者が2人いて、確認依頼中の連絡がある | 2人がそれぞれ依頼を読む | 2人に同じ内容を返す | |
| 店舗 P についての未対応の連絡がある（依頼を持たない） | P の店舗管理者が、その連絡の ID で依頼を読む | `NotFoundError`。連絡の内容は返らない | |
| 店舗 P についての、依頼せずに対応済みになった連絡がある | P の店舗管理者が、その連絡の ID で依頼を読む | `NotFoundError`。連絡の内容は返らない | |
| 店舗 P を対象にした確認依頼中の連絡がある。操作する人は、依頼を受けた後に P の店舗管理者を辞任した | 依頼を読む | `ForbiddenError`。依頼の内容は返らない | |
| 店舗 P を対象にした確認依頼中の連絡がある。操作する人は店舗 Q だけの店舗管理者 | 依頼を読む | `ForbiddenError`。依頼の内容は返らない | |
| 店舗 P を対象にした確認依頼中の連絡がある。P のすべての店舗管理者が辞任し、店舗管理者がいない | サービス運営者が依頼を読む | `ForbiddenError`。管理者のいない店舗でも、サービス運営者は依頼を読めない | |
| 店舗 P についての未対応の連絡がある（依頼を持たない）。操作する人は店舗 Q だけの店舗管理者 | その連絡の ID で依頼を読む | `ForbiddenError`。店舗管理者の確認を、依頼の有無より先に判定する | |
| P の店舗管理者。存在しない `InfoReportId` | 依頼を読む | `NotFoundError` | |
