# listConfirmationRequestsForPlace

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 P に、店舗を対象にした確認依頼中の連絡と、P の掲載を対象にした確認依頼中の連絡がある。操作する人は P の店舗管理者 | P の依頼の一覧を読む | 2件を、依頼の日時の新しい順で返す。`count` は 2。各行は連絡の ID、対象とその名称、種類、内容、依頼の日時を持つ（AC-77） | |
| 店舗 P に、未対応の連絡、確認依頼中の連絡、依頼を経て対応済みになった連絡が1件ずつある | P の店舗管理者が一覧を読む | 確認依頼中の1件だけを返す。`count` は 1 | |
| 店舗 P と店舗 Q に、確認依頼中の連絡が1件ずつある。操作する人は P だけの店舗管理者 | P の依頼の一覧を読む | P の連絡だけを返す | |
| 店舗 P の掲載を対象にした確認依頼中の連絡があり、その掲載は削除されている | P の店舗管理者が一覧を読む | その連絡を含めて返す。掲載の名称は持たない | |
| 店舗 P に店舗管理者が2人いて、確認依頼中の連絡がある | 2人がそれぞれ一覧を読む | 2人に同じ内容を返す | |
| 店舗 P に確認依頼中の連絡がない | P の店舗管理者が一覧を読む | 空の並びと、`count` 0 を返す | |
| 店舗 P の一時非公開の掲載を対象にした確認依頼中の連絡がある | P の店舗管理者が一覧を読む | その連絡を、掲載の名称とともに返す | |
| 店舗 P に確認依頼中の連絡がある。P のすべての店舗管理者が辞任し、店舗管理者がいない | サービス運営者が P の依頼の一覧を読む | `ForbiddenError`。管理者のいない店舗でも、サービス運営者は依頼を読めない | |
| 店舗 P に確認依頼中の連絡がある。操作する人は P の管理権限を持たない利用者 | P の依頼の一覧を読む | `ForbiddenError`。連絡は返らない | |
| 店舗 P に確認依頼中の連絡がある。操作する人は、依頼を受けた後に P の店舗管理者を辞任した | P の依頼の一覧を読む | `ForbiddenError`。連絡は返らない | |
