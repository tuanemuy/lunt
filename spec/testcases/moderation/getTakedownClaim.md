# getTakedownClaim

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 写真の権利者が、閲覧できる掲載の写真3枚のうち1枚を示した、未対応の申立てがある。操作する人はサービス運営者 | 申立てを読む | 申立ての立場、対象とその名称、示された写真、理由、メールアドレス、受け付けた日時、状態（未対応）を返す。対象は「ある・閲覧できる」。対象の現在の写真3枚を並び順のまま返し、示された1枚にだけ、申立人が示した写真であることが添えられる（AC-31） | |
| 店舗本人が店舗を対象にした、未対応の申立てがある。店舗は写真を持つ | サービス運営者が申立てを読む | 示された写真は空。対象の現在の写真をすべて返し、どの写真にも、申立人が示した写真であることは添えられない | |
| 未対応の申立ての対象の掲載が、運営による非公開になっている | サービス運営者が申立てを読む | 対象は「ある・閲覧できない」。対象の名称と現在の写真を返す | |
| 未対応の申立ての対象の掲載の店舗が、非公開になっている | サービス運営者が申立てを読む | 対象は「ある・閲覧できない」。対象の現在の写真を返す | |
| 未対応の申立ての対象の掲載が、提出の後に削除されている | サービス運営者が申立てを読む | エラーにならない。申立ての内容を返し、対象は「ない」。対象の名称はなく、現在の写真は空 | |
| 未対応の申立てで示された写真が、提出の後に対象から外されている。対象は残っている | サービス運営者が申立てを読む | エラーにならない。対象の現在の写真にその写真は含まれず、示された写真が削除済みであることが分かる | |
| 対応済みの申立てがある | サービス運営者が申立てを読む | 状態（対応済み）と、添えた結果を返す | |
| サービス運営者。存在しない `TakedownClaimId` | 申立てを読む | `NotFoundError` | |
| 未対応の申立てがある。操作する人はサービス運営者の役割を持たない | 申立てを読む | `ForbiddenError`。申立ての内容も申立人のメールアドレスも返らない | |

## 読みものの公開状態

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中の読みものへの未対応の申立てがある | サービス運営者が申立てを読む | 対象の現在の状態に、読みものの公開状態（公開中）が添えられる | |
| 申立てによる最後の写真の削除で公開の取り下げになった読みものへの申立てがある | サービス運営者が申立てを読む | 読みものの公開状態は公開の取り下げで、理由は申立てによる写真の削除 | |
| 掲載への申立てがある | サービス運営者が申立てを読む | 読みものの公開状態は添えられない | |
