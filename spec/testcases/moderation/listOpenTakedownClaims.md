# listOpenTakedownClaims

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 未対応の申立てが3件あり、受け付けた日時が互いに違う。操作する人はサービス運営者 | 一覧を読む | 3件を、受け付けた日時の古い順で返す。`count` は 3。各行は立場、対象とその名称、申立人のメールアドレス、受け付けた日時を持つ | |
| 未対応の申立てが2件、対応済みの申立てが1件ある。操作する人はサービス運営者 | 一覧を読む | 未対応の2件だけを返す。`count` は 2 | |
| 未対応の申立てがあり、その対象の掲載は提出の後に削除されている | サービス運営者が一覧を読む | その申立てを含めて返す。対象は `ContentRef` だけを持ち、名称を持たない | |
| 未対応の申立てがあり、その対象の掲載は提出の後に運営による非公開になっている | サービス運営者が一覧を読む | その申立てを、対象の名称とともに返す。名称は、閲覧できない対象についても返る | |
| 申立てが1件もない。操作する人はサービス運営者 | 一覧を読む | 空の並びと、`count` 0 を返す | |
| 未対応の申立てが1件ある | サービス運営者が `resolveTakedownClaim` で対応を終えた後、一覧を読む | その申立ては一覧に現れない。`count` は 0 | |
| 未対応の申立てがある。操作する人はサービス運営者の役割を持たない | 一覧を読む | `ForbiddenError`。申立ては返らない | |
