# previewArticle

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| タイトル・本文・写真と、閲覧できる紹介先を持つ下書き | 編集担当者が見え方を確かめる | 記事（写真・本文・紹介先）と、読みものの一覧・フィードで紹介されるときの見え方を返す。欠けている公開条件は空。読みものは変わらず、版も進まない（AC-62） | |
| 上の下書きを `publishArticle` で公開した | Discovery の記事の読み取りを読む | 確かめた見え方と同じ表現で返る（AC-62） | |
| 閲覧できる紹介先と、閲覧できない紹介先を持つ下書き | 見え方を確かめる | 見え方には、閲覧できる紹介先だけが現れる。閲覧できない紹介先は、見え方に現れない紹介先として返る | |
| 紹介先をすべて、運営による非公開の掲載と公開を取り下げた地域にした下書き | 見え方を確かめる | 見え方に紹介先は現れない。2つの紹介先が、見え方に現れない紹介先として返る。紹介先のない読みものと区別できる | |
| 紹介先のない下書き | 見え方を確かめる | 見え方に紹介先は現れず、見え方に現れない紹介先もない | |
| 紹介先に、提供終了の掲載と終了したイベントを持つ下書き | 見え方を確かめる | どちらも見え方に現れ、状態を区別できる | |
| タイトルと写真のない下書き | 見え方を確かめる | 見え方と、欠けている公開条件 `title`・`photos` を返す。エラーにならない（AC-68） | |
| 公開を取り下げた読みもの | 見え方を確かめる | 保存されている内容の見え方と、欠けている公開条件を返す | |
| 編集担当者 A が下書きを開いた後、編集担当者 B が公開した | A が見え方を確かめる | エラーにならない。見え方と欠けている公開条件（空）とともに、現在の公開状態（`published`）を値で返す | |
| 存在しない `ArticleId` | 見え方を確かめる | `NotFoundError` | |
| 編集担当者の役割を持たない利用者 | 見え方を確かめる | `ForbiddenError` | |
