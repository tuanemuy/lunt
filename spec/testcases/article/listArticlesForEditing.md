# listArticlesForEditing

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 編集担当者 A が作成した下書き、編集担当者 B が作成した公開中の読みもの、公開を取り下げた読みもの | A が、状態を絞らずに読む | 3件とも返す。それぞれ公開状態が分かる。並び順は `updatedAt` の新しい順。`count` は 3 | |
| 上と同じ | 下書きで絞って読む | 下書きの1件だけを返す。`count` は 1 | |
| 上と同じ | 公開で絞って読む | 公開中の1件だけを返す | |
| 上と同じ | 公開の取り下げで絞って読む | 公開を取り下げた1件だけを返す | |
| 編集担当者が取り下げた読みものと、申立てによる写真の削除で取り下げられた読みもの | 公開の取り下げで絞って読む | 2件とも返す。事由（`byManager`、`photoTakedown`）で区別できる（AC-79） | |
| 申立てに基づいて写真が1枚削除され、公開が続いている読みもの | 読む | 公開中として返し、申立てで写真が削除されたことが分かる | |
| 一覧の最後にある読みもの | `reviseArticle` で保存してから読む | その読みものが先頭に現れる | |
| 読みものが1件もない | 読む | 空の並びと `count` 0 を返す | |
| 公開中の読みものがない | 公開で絞って読む | 空の並びと `count` 0 を返す | |
| 編集担当者の役割を持たない利用者 | 読む | `ForbiddenError` | |
| 任命を解かれた利用者 | 読む | `ForbiddenError`（AC-75） | |
