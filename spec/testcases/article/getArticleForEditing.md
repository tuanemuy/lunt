# getArticleForEditing

紹介先の状態の判定そのものは、Discovery の読み取りのテストが確かめる。ここでは、読みものと解決の結果の合成を確かめる。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 写真2枚と、閲覧できる掲載・店舗・地域・イベントを紹介先に持つ下書き | 編集担当者が読む | 内容、公開状態、版、写真それぞれの表示用の参照、紹介先それぞれの現在の状態を返す。写真と紹介先は、読みものが持つ順のまま | |
| 別の編集担当者が作成した読みもの | 読む | 成功する。作成者にかかわらず返す | |
| 紹介先の掲載が、運営によって非公開になった公開中の読みもの | 読む | その紹介先を、閲覧できない紹介先として、対象の情報なしで返す。結びつけは残り、読みものは公開中のまま（AC-15） | |
| 紹介先の掲載が削除された読みもの | 読む | その紹介先を、閲覧できない紹介先として返す | |
| 紹介先の地域の公開が取り下げられ、その後に再び公開された読みもの | 読む | その紹介先を、閲覧できる紹介先として返す | |
| 紹介先に、提供終了の掲載、閉店した店舗、終了したイベント、中止したイベントを持つ読みもの | 読む | どれも閲覧できる紹介先として返し、状態を区別できる | |
| 申立てによる写真の削除で公開が取り下げられた読みもの | 読む | 公開状態が `unpublished`、事由が `photoTakedown` と分かる。削除された写真は内容にない（AC-79） | |
| 読んだ読みもの | 返された版で `reviseArticle` を実行する | 成功する | |
| 編集担当者の役割を持たない利用者 | 読む | `ForbiddenError`。読みものの内容を返さない | |
