# sweepUnownedPhotos

`PhotoPolicy.unownedRetentionMs` を「残す期間」と書く。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 登録から残す期間を過ぎた、持ち主のない `stored` の写真 | ジョブを実行する | 写真の実体と記録が削除される。ドメインイベントは出ない | |
| 登録から残す期間を過ぎた、`accepted` のまま残った写真（登録または複製の途中で失敗したもの） | ジョブを実行する | 記録が削除される。実体があれば削除される | |
| 登録から残す期間を過ぎていない、持ち主のない `stored` の写真 | ジョブを実行する | 写真は変わらない。後から持ち主を設定できる | |
| 登録から残す期間を過ぎた、持ち主のある `stored` の写真 | ジョブを実行する | 写真は変わらない。実体も残る | |
| 実体の削除で失敗し、`discarded` のまま残った写真。登録から残す期間を過ぎていない | ジョブを実行する | 実体の削除から続け、実体と記録が削除される | |
| 掃除の対象の写真が、1ページの件数より多い | ジョブを実行する | 先頭のページを読み直して進み、対象の全件が削除される | |
| 掃除の対象が2枚。1枚目の `PhotoStorage.delete` が失敗する | ジョブを実行する | 2枚目は削除される。1枚目は `discarded` のまま残る。読んだページの全件が失敗した時点で打ち切り、終わらない繰り返しにならない | |
| 上の実行の後。`PhotoStorage.delete` が成功するようになった | ジョブをもう一度実行する | 残っていた `discarded` の写真の実体と記録が削除される | |
| 登録から残す期間を過ぎた、持ち主のない写真。ジョブが読んだ後、破棄を確定する前に、その写真を載せた読みものの保存が確定する | ジョブが破棄を確定しようとする | 破棄は `ConflictError` で成立せず、写真は持ち主を持つ `stored` のまま残る。実体は削除されない。ジョブは他の写真の掃除を続ける | |
| 掃除の対象がない | ジョブを実行する | 成功する。何も変わらない | |
