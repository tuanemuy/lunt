# listListingsOfPlace

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗に、提供中の掲載 a1（先に公開）・a2（後に公開）、提供開始前の掲載 u1、提供終了の掲載 e1 がある | 読む | a2、a1、u1、e1 の順と、全件数 4。それぞれ状態（提供開始前は開始日）を区別でき、詳細を開くための ID を持つ（AC-02、AC-14） | |
| 店舗に公開中の掲載が8件ある | 1ページ6件で1ページ目と2ページ目を読む（店舗の詳細の掲載の区分と、その続き） | 1ページ目は先頭6件、2ページ目は残りの2件。どちらも全件数は 8。合わせると、全件が店舗の掲載の順に1回ずつ現れる | |
| 店舗に、下書き・一時非公開・運営による非公開の掲載がある | 読む | どれも現れない | |
| 休業中の店舗と閉店した店舗に、公開中の掲載がある | それぞれの店舗で読む | どちらもその掲載が現れる（店舗の掲載は参照の場面）（AC-14） | |
| 店舗に公開中の掲載がない | 読む | 空の並びと全件数 0。エラーにならない | |
| 店舗が非公開。または、その ID の店舗がない | 読む | どちらも `NotFoundError`。理由を区別しない | |
