# findRegions

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 位置が選択エリアにある地域 R1、位置は外で所属する店舗の所在地が選択エリアにある地域 R2、どちらも外の地域 R3 がある | エリアを選び、現在地なしで読む | R1 と R2 が、最初の公開の新しい順で返る。要約は写真・名称・所在地を持つ。効いている条件を併せて返す（AC-04） | |
| 上と同じ。R2 に所属する選択エリアの店舗が、閉店した店舗だけ | エリアを選んで読む | R2 は現れる（閉店した所属店舗も判定に使う） | |
| 上と同じ。R2 に所属する選択エリアの店舗が、非公開の店舗だけ | エリアを選んで読む | R2 は現れない | |
| 現在地から設定値の半径の中に地域 R1・R2（R1 のほうが近い）、半径の外に地域 R3 がある | 条件なし、現在地つきで読む | R1、R2 の順で返る。R3 は現れない | |
| 地域 R4 の位置は現在地から遠いが、R4 に所属する休業中の店舗の位置は現在地のすぐ近く。地域 R5 の位置は、R4 の店舗より遠く、R4 の位置より近い。どちらも選択エリアにある | エリアを選び、現在地つきで読む | R4、R5 の順で返る（地域の位置と閲覧できる所属店舗の位置のうち、現在地に最も近いものまでの距離の順） | |
| 地域 R4 の位置は設定値の半径の外で、R4 に所属する閉店した店舗の位置が半径の中にある。地域 R5 の位置も半径の外で、R5 に所属する半径の中の店舗は非公開の店舗だけ | 条件なし、現在地つきで読む | R4 は現れ、R5 は現れない（周辺にあるかは、地域の位置と閲覧できる所属店舗の位置で決まる） | |
| 現在地から設定値の半径の中に地域 R1・R2、半径の外に地域 R3 がある | 条件なし、現在地なしで読む | R1・R2・R3 のすべてが、最初の公開の新しい順で返る。エラーにならない（AC-55） | |
| 選択エリアの地域 R1・R2 が、どちらも現在地から設定値の半径の外にある | エリアを選び、現在地つきで読む | R1 と R2 が、現在地に近い順で返る。周辺では絞り込まれない | |
| 地域 R に所属する店舗が、どれも「食べる」の掲載を持たない | カテゴリー「食べる」だけを選んで読む | R は結果に現れる。カテゴリーの条件は地域に効かない。効いている条件には「食べる」が含まれる | |
| 下書き、公開の取り下げ、運営による非公開の地域がある | 読む | どれも現れない | |
| 選択エリアに地域がない | エリアを選んで読む | 空の並びと全件数 0。エラーにならない | |
