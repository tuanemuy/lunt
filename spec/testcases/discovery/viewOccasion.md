# viewOccasion

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 開催中のイベント E に、掲載と参加日を添えた参加店舗、関連づけられた公開中の地域、E を紹介先に持つ公開中の読みものがある | E を読む | イベントの写真（登録された順）・名称・キャッチコピー・紹介・開催期間・開催場所・開催の状態と、参加店舗・地域・読みものの区分を返す。参加店舗は、店舗ごとに、添えた掲載と参加日を持つ。各要約は、詳細を開くための ID を持つ（AC-05） | |
| 店舗 P（先に参加が成立）と店舗 Q（後に成立）が参加中。P は掲載 l2・l1 をこの順に添え、参加日は 5/3 と 5/1 | E を読む | 参加店舗は P、Q の順。P の添えた掲載は l2、l1 の順、参加日は 5/1、5/3 の順 | |
| 参加日 5/1・5/5 を持つ参加があり、その後に開催期間が 5/1〜5/3 に更新された | E を読む | その参加店舗の参加日は 5/1 だけ | |
| 参加店舗に、閉店した店舗と休業中の店舗がある。添えた掲載に、提供開始前の掲載と提供終了の掲載がある | E を読む | どれも現れ、状態を区別できる（AC-63） | |
| 参加店舗の1つが非公開。別の参加店舗の添えた掲載の1つが一時非公開 | E を読む | イベントは変わらずに返る。非公開の店舗は参加店舗に現れず、一時非公開の掲載は添えた掲載に現れない（AC-15、AC-48） | |
| 開催期間の開始が今日より後のイベント | 読む | 開催前であることを返す（AC-32） | |
| 開催期間の終了が今日より前のイベントと、中止にしたイベント | それぞれを読む | どちらも閲覧できる。終了・中止を、開催中と区別できる（AC-32、AC-63） | |
| 参加店舗はあるが、添えた掲載に閲覧できるものが1つもない | E を読む | 参加店舗は返り、どの参加店舗の添えた掲載も空。イベントに閲覧できる掲載がないことを、エラーにせずに区別できる（AC-54） | |
| 地域 X（先に関連づけ）と地域 Y（後に関連づけ）が関連づけられている。地域 Z との関連づけは地域の側が解除している。地域 W は公開の取り下げ中 | E を読む | 地域の区分は X、Y の順。Z と W は現れない | |
| E を紹介先に持つ公開中の読みものが4件ある | E を読む | 読みものの区分は、公開の新しい順の先頭3件と全件数 4（AC-71） | |
| イベントが、下書き、公開の取り下げ、運営による非公開のいずれか。または、その ID のイベントがない | そのイベントを読む | どれも `NotFoundError`。理由を区別せず、イベントの名称・写真を返さない | |
