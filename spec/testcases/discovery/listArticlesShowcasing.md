# listArticlesShowcasing

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 P を紹介先に持つ公開中の読みものが5件ある | P を指定して、1ページ3件で1ページ目と2ページ目を読む（詳細の読みものの区分と、その続き） | 1ページ目は公開の新しい順の先頭3件、2ページ目は残りの2件。どちらも全件数は 5。合わせると、全件が公開の新しい順に1回ずつ現れる。要約は、詳細を開くための ID を持つ（AC-02、AC-71） | |
| 掲載 L、地域 R、イベント E のそれぞれを紹介先に持つ公開中の読みものが4件ずつある | L、R、E をそれぞれ指定して、1ページ3件で1ページ目を読む | それぞれ、その対象を紹介先に持つ読みものだけの先頭3件と、全件数 4（AC-71） | |
| 地域 R を紹介先に持つ公開中の読みものが4件、公開を取り下げた読みものが1件ある | R を指定して読む | 公開中の4件だけを返し、全件数は 4（AC-71） | |
| 店舗 P を紹介先に持つ読みものが、下書きと公開の取り下げだけ | P を指定して読む | 空の並びと全件数 0。エラーにならない | |
| 店舗 P の掲載 L だけを紹介先に持つ公開中の読みものがある | P を指定して読む | その読みものは現れない（紹介先は対象そのものの一致で決まる） | |
| 店舗 P を紹介先に持つ公開中の読みものがある。P は非公開。別に、公開を取り下げた地域 R と、その ID の掲載がない掲載の参照 | P、R、その掲載をそれぞれ指定して読む | どれも `NotFoundError`。理由を区別しない | |
