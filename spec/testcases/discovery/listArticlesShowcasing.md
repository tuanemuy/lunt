# listArticlesShowcasing

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 店舗 P を紹介先に持つ公開中の読みものが5件ある | P を指定して、1ページ3件で2ページ目を読む | 残りの2件を返す。詳細の読みものの区分（先頭3件）と合わせると、全件が公開の新しい順に1回ずつ現れる。全件数は 5（AC-71） | |
| 掲載 L、地域 R、イベント E のそれぞれを紹介先に持つ公開中の読みものがある | L、R、E をそれぞれ指定して読む | それぞれ、その対象を紹介先に持つ読みものだけを返す（AC-71） | |
| 店舗 P を紹介先に持つ読みものが、下書きと公開の取り下げだけ | P を指定して読む | 空の並びと全件数 0 | |
| 店舗 P を紹介先に持つ公開中の読みものがある。P は非公開 | P を指定して読む | 空の並びと全件数 0。エラーにならない | |
| 店舗 P の掲載 L だけを紹介先に持つ公開中の読みものがある | P を指定して読む | その読みものは現れない（紹介先は対象そのものの一致で決まる） | |
