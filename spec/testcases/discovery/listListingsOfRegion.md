# listListingsOfRegion

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中の地域 R に所属する別々の店舗に、公開中かつ提供中の掲載 L1・L2・L3 があり、この順に最初に公開された | R で読む | L3、L2、L1 の順と、全件数 3。要約は写真・掲載の名称・店舗の名称・地域名と、詳細を開くための ID を持ち、価格とキャッチコピーを持たない（AC-02、AC-04） | |
| R に所属する店舗に、公開中かつ提供中の掲載が合わせて9件ある | 1ページ6件で1ページ目を読む（地域の詳細の掲載の区分） | 最初の公開の新しい順の先頭6件と、全件数 9 | |
| 掲載の店舗は地域 R と地域 S に所属し、代表地域は S | R で読む | その掲載の要約の地域名は R | |
| R に所属する店舗に、提供開始前の掲載、提供終了の掲載、一時非公開の掲載がある。R に所属する閉店した店舗と非公開の店舗に、公開中かつ提供中の掲載がある | R で読む | どれも現れない。休業中の店舗の公開中かつ提供中の掲載は現れる（AC-14、AC-63） | |
| R に所属する店舗の掲載は、どれも選択中のエリア・カテゴリーの条件に合わない | R で読む | 掲載がすべて現れる（入力に絞り込みの条件を持たない） | |
| R に所属する店舗はあるが、公開中かつ提供中の掲載がない | R で読む | 空の並びと全件数 0。地域に閲覧できる掲載がないことを、エラーにせずに区別できる（AC-54） | |
| R の掲載が、1ページの件数より多い | 1ページ目と2ページ目を読む | 2つのページを合わせると、全件が新しい順に1回ずつ現れる | |
| 地域が公開の取り下げ、運営による非公開、または存在しない | その地域で読む | `NotFoundError` | |
