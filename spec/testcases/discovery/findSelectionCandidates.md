# findSelectionCandidates

候補の範囲（`SelectionScope`）は、特に書かなければ、種類ごとに範囲で絞らない値（店舗は `vacantOnly: false`、イベントは `openOnly: false`）。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 名称に「港」を含む公開中の地域が2つと、公開を取り下げた地域が1つある | 範囲を `region` にして、「港」で探す | 公開中の2つだけを、関連度の高い順の要約で返す。全件数は 2 | |
| 名称に「マルシェ」を含む、開催前・開催中・終了・中止のイベントがある | 範囲を `occasion`（`openOnly: false`）にして、「マルシェ」で探す（AM-02 の紹介先） | 4つとも候補に現れ、開催の状態を区別できる | |
| 上と同じ | 範囲を `occasion`（`openOnly: true`）にして、「マルシェ」で探す（RQ-06 の参加するイベント） | 開催前と開催中の2つだけが、開催の状態とともに候補に現れる。終了・中止のイベントは現れず、全件数は 2 | |
| 「マルシェ」に一致する開催前・開催中のイベントが7件、終了したイベントが5件ある | 範囲を `occasion`（`openOnly: true`）にして、1ページ5件で1ページ目と2ページ目を読む | 5件、2件。どちらのページも開催前・開催中のイベントだけで、全件数は 7 | |
| 名称に「桃」を含む、提供中・提供開始前・提供終了の掲載と、一時非公開の掲載がある | 範囲を `listing` にして、「桃」で探す | 一時非公開の掲載を除く3つが候補に現れ、提供状態を区別できる | |
| 店舗「山田珈琲店」（所在地は千代田区）と、店舗「梅田食堂」（所在地は中央区）がある | 範囲を `place` にして、「山田」で探す。別に「中央区」で探す | 「山田」では「山田珈琲店」、「中央区」では「梅田食堂」を返す（店舗は店名と住所のどちらでも探せる） | |
| 上と同じ | 範囲を `place`（`vacantOnly: false`）にして「山田」で探す。別に、`searchByKeyword` の店舗の種類を「山田」で読む | 2つの結果の店舗の並びと全件数が一致する | |
| キーワードに一致する、休業中の店舗、閉店した店舗、非公開の店舗がある | 範囲を `place` にして探す | 休業中と閉店の店舗は候補に現れ、営業状況を区別できる。非公開の店舗は現れず、全件数にも含まれない | |
| キーワードに一致する、店舗管理者のいる店舗と、いない店舗がある | 範囲を `place`（`vacantOnly: false`）にして探す | 両方が候補に現れ、候補ごとに店舗管理者の有無を区別できる | |
| 上と同じ | 範囲を `place`（`vacantOnly: true`）にして探す（RQ-05 を DT-03 から開いたときの店舗、CM-04 の加える店舗） | 店舗管理者のいない店舗だけが候補に現れる。店舗管理者のいる店舗は現れず、全件数にも含まれない | |
| キーワードに一致する、店舗管理者のいない店舗 V1・V2 がある。V1 はイベント E にすでに参加中 | 範囲を `place`（`vacantOnly: true`）にして探す | V1 と V2 がどちらも候補に現れる。すでに参加中かどうかは、このユースケースは区別しない（範囲の中の「受け付けない事情」は、呼び出す画面が呼び出す操作の読み取りで決める） | |
| キーワードに一致する写真のない店舗に、閲覧できる掲載がある | 範囲を `place` にして探す | 候補の写真は、その掲載の代表写真で代用される（AC-29） | |
| キーワードに一致する対象が、その種類にない | 探す | 空の並びと全件数 0。エラーにならない | |
| どの種類にも閲覧できる対象がある | 店舗・掲載・地域・イベントのそれぞれの範囲で、空のキーワード、または空白だけのキーワードで探す | どの種類も、空の並びと全件数 0。エラーにならない | |
