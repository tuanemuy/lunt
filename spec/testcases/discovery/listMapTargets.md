# listMapTargets

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 範囲と条件に合う店舗 P・Q と地域 R がある | 地域を選ばない `readMapCells` と同じ範囲と条件で、両方の種類を読む | 店舗は `readMapCells` の区画に含まれる店舗と同じ P・Q、地域は同じ R が、種類ごとに分かれて返る。店舗と地域それぞれの全件数と、効いている条件を持つ（AC-40、AC-53） | |
| 店舗の登録の日時と、地域の最初の公開の日時が、それぞれ違う | 現在地なしで読む | 店舗は登録の新しい順、地域は最初の公開の新しい順（AC-53） | |
| 店舗と地域の位置が、現在地から違う距離にある | 現在地つきで読む | 店舗も地域も、現在地に近い順 | |
| 2つの地域に所属し、代表地域を選んでいる休業中の店舗 P がある | 読む | P の要約は、写真・名称・所在地・代表地域の名称と、休業中であることを持つ（AC-25） | |
| 範囲に、閉店した店舗がある | 読む | 閉店した店舗は現れない（AC-63） | |
| 条件に合う店舗が、1ページの件数より多い | 種類に店舗だけを指定して、2ページ目を読む | 店舗の2ページ目だけを返す。1ページ目と合わせると、全件が1回ずつ現れる | |
| 範囲と条件に合う店舗も地域もない | 読む | どちらの種類も、空の並びと全件数 0 | |
