# listOccasions

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 開催期間の開始が 5/1 のイベント E1、4/20 のイベント E2（開催中）、5/1 開始で終了が E1 より早いイベント E3 が、どれも公開中 | 読む | E2、E3、E1 の順（開始の早い順、次に終了の早い順）。要約は写真・名称・開催期間・開催場所と開催の状態を持つ。全件数は 3（AC-05） | |
| 参加店舗を持たない開催前のイベントと、参加に添えた掲載が提供開始前だけの開催前のイベントがある | 読む | どちらも現れ、開催前であることを区別できる（AC-32） | |
| 終了したイベントと、中止のイベントがある | 読む | どちらも現れない（AC-32、AC-63） | |
| 下書き、公開の取り下げ、運営による非公開のイベントがある | 読む | どれも現れない | |
| 開催場所が選択中のエリアの外にあるイベントがある | 読む | 現れる（入力に絞り込みの条件を持たない） | |
| イベントが、1ページの件数より多い | 1ページ目と2ページ目を読む | 2つのページを合わせると、全件が開催日の順に1回ずつ現れる | |
| 開催前・開催中の公開中のイベントがない | 読む | 空の並びと全件数 0。エラーにならない | |
