# listArticles

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中の読みもの A1・A2・A3 が、この順に最初に公開された | 読む | A3、A2、A1 の順と、全件数 3。要約は代表写真・タイトル・読みものの ID を持つ（AC-06） | |
| A1 が公開を取り下げられた後、再び公開された | 読む | 順は変わらない（最初の公開の日時が基準） | |
| 下書きの読みものと、公開を取り下げた読みものがある | 読む | どちらも現れない | |
| 公開中の読みものが、1ページの件数より多い | 1ページ目と2ページ目を読む | 2つのページを合わせると、全件が新しい順に1回ずつ現れる | |
| 公開中の読みものがない | 読む | 空の並びと全件数 0。エラーにならない | |
