# viewListing

紹介する読みものの区分は、画面が `listArticlesShowcasing` で読み、そのテストが確かめる。他の掲載の件数は、特に書かなければ 6（`spec/pages/index.md`「詳細の関連情報」）。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中かつ提供中の掲載 L。店舗 P は営業中で、地域 X に所属している。L を参加に添えた開催中のイベントがある | L を読む | 掲載の写真（登録された順と見せる範囲）・名称・説明・カテゴリー・提供の設定・提供状態と、店舗・地域・イベント・他の掲載の区分を返す。価格とキャッチコピーを持たない。各区分の要約は、詳細を開くための ID を持つ（AC-02） | |
| 商品・体験・景色・見どころの掲載がある | それぞれを読む | どれも同じ形で返る | |
| 掲載に開催日が3日設定されている | 読む | 3日すべてを返す | |
| 提供期間の開始日が今日より後の掲載 | 読む | 閲覧できる。提供開始前であることと、開始日を返す（AC-63） | |
| 期日で提供終了になった掲載と、管理する人が提供終了にした掲載 | それぞれを読む | どちらも閲覧できる。提供終了であることを返す。紐づく店舗と、店舗の提供中の別の掲載（他の掲載の区分）を併せて返す（AC-14） | |
| 紐づく店舗が休業中の掲載と、閉店した店舗の掲載 | それぞれを読む | どちらも閲覧できる。店舗の休業・閉店を、営業中と区別できる（AC-14） | |
| 店舗が地域 X・Y・Z の順に所属し、代表地域に Y を選んでいる。Z は公開の取り下げ中 | 読む | 地域の区分は Y、X の順。Z は現れない（AC-25） | |
| 店舗 P に、L のほかに提供中の掲載 p1・p2、提供開始前の掲載 p3 がある。一覧に示す地域 X に所属する他の店舗に、提供中の掲載が5件と、閉店した店舗の掲載が1件ある | 他の掲載の件数を 6 にして L を読む | 他の掲載は6件。p1・p2（新しい順）に続けて、X の他の店舗の提供中の掲載が新しい順に4件。L 自身、p3、閉店した店舗の掲載は含まれない | |
| 店舗 P に、L（最も新しく公開）のほかに提供中の掲載が6件ある | 他の掲載の件数を 6 にして L を読む | 他の掲載は、L を除いた P の6件（新しい順）。L を除いても件数を満たす | |
| 上と同じ | 他の掲載の件数を 3 にして L を読む | 他の掲載は、L を除いた P の掲載の新しい順の先頭3件 | |
| 店舗に公開中の所属地域がない | 読む | 地域の区分は空。他の掲載は、同じ店舗の提供中の掲載だけ | |
| L を参加に添えた、開催前のイベント E1 と終了したイベント E2 がある。店舗は E3 にも参加しているが、L を添えていない | L を読む | イベントの区分は E1 だけ（AC-32） | |
| 掲載のカテゴリー K が廃止され、移行先は M。掲載には K が保存されたまま | 読む | カテゴリーは M で返る | |
| 店舗に店舗管理者がいる掲載と、いない掲載 | それぞれを読む | 店舗管理者の有無を区別できる | |
| L の所属地域と、L を添えたイベントが、どちらも公開を取り下げられた | L を読む | 掲載は変わらずに返り、その地域とイベントだけが区分から外れる（AC-15） | |
| 掲載が、下書き、一時非公開、運営による非公開、削除済みのいずれか。または、紐づく店舗が非公開。または、その ID の掲載がない | その掲載を読む | どれも `NotFoundError`。理由を区別せず、掲載の名称・写真を返さない（AC-48） | |
