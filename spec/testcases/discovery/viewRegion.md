# viewRegion

所属する店舗・その掲載・紹介する読みものの区分は、画面が `listPlacesOfRegion`・`listListingsOfRegion`・`listArticlesShowcasing` で読み、それぞれのテストが確かめる。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中の地域 R に、関連づけられた開催前のイベントがある | R を読む | 地域の写真（登録された順）・名称・キャッチコピー・紹介・所在地・位置と、イベントの区分を返す。イベントの要約は、詳細を開くための ID を持つ（AC-02、AC-04） | |
| R に、開催前のイベント E1（開始が遅い）、開催中のイベント E2、終了したイベント E3、中止のイベント E4 が関連づけられている。イベント E5 との関連づけは、地域の側が解除している | R を読む | イベントの区分は E2、E1 の順（開催日の順）。E3・E4・E5 は現れない（AC-32） | |
| R に関連づけられたイベントがない | R を読む | 地域の内容が返り、イベントの区分は空。エラーにならない | |
| R に関連づけられたイベントの1つが、地域の詳細を読んだ後に公開を取り下げられた | R をもう一度読む | 地域は変わらずに返り、そのイベントだけが区分から外れる（AC-15） | |
| 地域が、下書き、公開の取り下げ、運営による非公開のいずれか。または、その ID の地域がない | その地域を読む | どれも `NotFoundError`。理由を区別せず、地域の名称・写真を返さない | |
