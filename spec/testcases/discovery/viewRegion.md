# viewRegion

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中の地域 R に、閲覧できる店舗が所属し、その店舗にフィード対象の掲載がある。R に関連づけられた開催前のイベントと、R を紹介先に持つ公開中の読みものがある | R を読む | 地域の写真（登録された順）・名称・キャッチコピー・紹介・所在地・位置と、店舗・掲載・イベント・読みものの区分を返す。各区分の要約は、詳細を開くための ID を持つ（AC-02、AC-04） | |
| R に8つの店舗が、違う日時に所属している。その店舗に、公開中かつ提供中の掲載が合わせて9件ある | R を読む | 店舗は、所属した日時の新しい順の先頭6件と全件数 8。掲載は、最初の公開の新しい順の先頭6件と全件数 9 | |
| 店舗 P は地域 R と地域 S に所属し、代表地域は S。P にフィード対象の掲載がある | R を読む | 店舗の区分の P の要約と、掲載の区分の P の掲載の要約の地域名は R。代表地域の S ではない | |
| R に、休業中の店舗、閉店した店舗、非公開の店舗が所属している。どの店舗にも公開中かつ提供中の掲載がある | R を読む | 店舗と掲載の区分に、休業中の店舗とその掲載は現れる。閉店した店舗と非公開の店舗、その掲載は現れない（AC-14） | |
| R に所属する営業中の店舗に、提供開始前の掲載と提供終了の掲載がある | R を読む | どちらの掲載も、掲載の区分に現れない（AC-63） | |
| R に、開催前のイベント E1（開始が遅い）、開催中のイベント E2、終了したイベント E3、中止のイベント E4 が関連づけられている。イベント E5 との関連づけは、地域の側が解除している | R を読む | イベントの区分は E2、E1 の順（開催日の順）。E3・E4・E5 は現れない（AC-32） | |
| R を紹介先に持つ公開中の読みものが4件、公開を取り下げた読みものが1件ある | R を読む | 読みものの区分は、公開の新しい順の先頭3件と全件数 4（AC-71） | |
| R に所属する店舗はあるが、その店舗に公開中かつ提供中の掲載がない | R を読む | 店舗の区分は返り、掲載の区分は空で全件数 0。地域に閲覧できる掲載がないことを、エラーにせずに区別できる（AC-54） | |
| R の所属店舗の1つが、地域の詳細を読んだ後に非公開になった | R をもう一度読む | 地域は変わらずに返り、その店舗とその掲載だけが区分から外れる（AC-15） | |
| 地域が、下書き、公開の取り下げ、運営による非公開のいずれか。または、その ID の地域がない | その地域を読む | どれも `NotFoundError`。理由を区別せず、地域の名称・写真を返さない | |
