# readFeed

前提条件の「フィード対象の掲載」は、公開中かつ提供中で、運営による非公開でなく、閉店も非公開もしていない店舗の掲載を指す。特に書かなければ、条件なし・現在地なし・1ページの件数は20件で読む。

## 対象と表示範囲

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 複数の地域の店舗に、商品・体験・景色・見どころのフィード対象の掲載がある。公開中の地域、公開中の読みもの、参加店舗を持つ開催前のイベントがある。選定の操作は誰も行っていない | 条件もカテゴリーも選ばずに読む | 掲載の要約が同じ形で並び、複数の地域の掲載が混ざる。掲載の間に、地域・読みもの・イベントの大きな枠が入る（AC-01、AC-35） | |
| 上と同じ | 読む | 掲載の要約は、代表写真、掲載の名称、店舗の名称、一覧に示す地域名、掲載と店舗の ID を持つ。価格とキャッチコピーを持たない。大きな枠は、写真と名称（読みものはタイトル）と対象の ID を持ち、地域とイベントはキャッチコピーがあれば持つ（AC-50、AC-51、AC-52） | |
| 地域 X の枠の直後に並ぶ掲載の店舗は、地域 Y だけに所属している | 読む | その掲載の要約の地域名は Y。隣り合う枠の地域とは関係しない（AC-02） | |
| 提供開始前の掲載、期日で提供終了になった掲載、管理する人が提供終了にした掲載、閉店した店舗の掲載がある | 読む | どれも現れない（AC-14、AC-35、AC-63） | |
| 休業中の店舗のフィード対象の掲載と、イベントの参加に添えた掲載がある | 読む | どちらも、他の掲載と同じ条件で現れる（AC-51、AC-63） | |
| 下書き・一時非公開・運営による非公開の掲載と、非公開の店舗の公開中の掲載がある | 読む | どれも現れない（AC-48） | |
| 店舗の代表地域が公開の取り下げ中で、公開中の所属地域がほかに2つある | 読む | その店舗の掲載の要約の地域名は、公開中の所属地域のうち最初に所属した地域（AC-25） | |
| 店舗に公開中の所属地域がない | 読む | その店舗の掲載の要約は、地域名を持たない | |
| 開催前のイベント E に参加店舗があり、参加に添えた掲載は提供開始前だけ。終了したイベント、中止のイベント、参加店舗を持たない開催前のイベントがある | 読む | イベントの枠に E が、開催前であることが分かる形で現れる。ほかの3つは枠に現れない（AC-32） | |
| 公開中の地域 R に所属する店舗の掲載が、提供終了のものだけ | 読む | R は地域の枠に現れない | |

## 並び順と混ぜ方

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 別々の店舗・別々の地域の掲載 L1・L2・L3 が、この順に最初に公開された。L1 は一時非公開の後に再公開されている | 現在地なしで読む | L3、L2、L1 の順（最初の公開の新しい順）。再公開は順を変えない。現在地がなくてもエラーにならない（AC-55） | |
| 別々の店舗・別々の地域の掲載があり、店舗の位置が現在地から近い順に P1、P2、P3。地域とイベントも現在地からの距離が違う | 現在地つきで読む | 掲載は P1、P2、P3 の店舗の順。地域の枠とイベントの枠も、現在地に近いものから使われる。読みものの枠は公開の新しい順（AC-39） | |
| 新しい順で、店舗 A の掲載 a1、店舗 A の掲載 a2、別の地域の店舗 B の掲載 b1 | 読む | a1、b1、a2 の順。同じ店舗の掲載が連続しない（AC-39） | |
| 近い順で、地域 X に所属する別々の店舗の掲載 x1・x2、地域 Y の店舗の掲載 y1（どの店舗も一覧に示す地域は所属する地域） | 現在地つきで読む | x1、y1、x2 の順。同じ地域の掲載が連続しない（AC-39） | |
| フィード対象の掲載が、店舗 A の掲載3件だけ | 読む | 3件が優先順のまま連続して並ぶ | |
| 新しい順で、店舗 A の掲載 a1〜a20 の後に、別の地域の店舗 B の掲載 b1 | 読む | a1、b1、a2、a3、…、a20 の順。b1 は優先順で離れていても、a1 の直後に置かれる。残りが店舗 A の掲載だけになってから連続する | |
| 公開中の所属地域のない別々の店舗の掲載が、新しい順で並んでいる | 読む | 新しい順のまま並ぶ。地域名を示さない掲載どうしは、同じ地域として扱わない | |

|---|---|---|---|
| フィード対象の掲載が13件。枠の候補は、地域2件、読みもの2件、イベント2件 | 読む | 地域の枠、掲載6件、読みものの枠、掲載6件、イベントの枠、掲載1件の順。地域の枠は新しい順の先頭、読みものの枠は公開の新しい順の先頭、イベントの枠は開催日の順の先頭 | |
| フィード対象の掲載が13件。枠の候補は、地域2件とイベント1件で、読みものはない | 読む | 先頭が地域、6件目の後ろがイベント、12件目の後ろが2件目の地域。読みものは飛ばされる | |
| フィード対象の掲載が13件。枠の候補は、地域1件だけ | 読む | 先頭に地域の枠が1回だけ入り、以降は掲載だけが並ぶ。同じ地域は繰り返されない | |
| フィード対象の掲載があり、公開中の地域・読みもの・イベントが1つもない | 読む | 掲載だけが並ぶ | |

## ページ

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| フィード対象の掲載が14件。枠の候補は、地域・読みもの・イベントが1件ずつ。読み込みの間に候補は変わらない | 1ページ6件で、1〜3ページ目を同じ条件で読む | 1ページ目は地域の枠・掲載6件・読みものの枠、2ページ目は掲載6件・イベントの枠、3ページ目は掲載2件。掲載の全件数はどのページでも 14。次のページがあるかどうかは、順に「ある」「ある」「ない」 | |
| 同じ店舗・同じ地域の掲載が混ざった、フィード対象の掲載が30件 | 1ページ10件で1〜3ページ目を読み、別に1ページ30件で読む | 3つのページをつないだ並びが、1回で読んだ並びと一致する。ページの境目でも、同じ店舗・同じ地域の掲載が連続しない。同じ枠の対象は2回現れない | |
| フィード対象の掲載が5件 | 1ページ20件で2ページ目を読む | 空の並び。掲載の全件数は 5。次のページは「ない」 | |

## 絞り込み

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 都道府県 A の店舗の「食べる」の掲載、都道府県 B の町域 b の店舗の「買う」の掲載、町域 b の店舗の「体験」の掲載、都道府県 C の店舗の「食べる」の掲載がある | エリアに都道府県 A と町域 b、カテゴリーに「食べる」と「買う」を選んで読む | 1つ目と2つ目の掲載だけが現れ、条件なしと同じ順と間隔で並ぶ。効いている条件は、選んだエリア2つとカテゴリー2つ（AC-03、AC-40、AC-49） | |
| 上と同じ | エリアに都道府県 A だけを選んで読む。別に、カテゴリーに「食べる」だけを選んで読む | エリアだけでは、都道府県 A の店舗の掲載がカテゴリーを問わず現れる。カテゴリーだけでは、「食べる」の掲載がエリアを問わず現れる（AC-03） | |
| 条件を選んで読んだ後 | 条件を空にして読む | 絞り込みのないフィードが返る。効いている条件は空（AC-03） | |
| 選択エリアに、条件に合う掲載を持つ店舗が所属する地域 R1 と、条件に合う掲載を持たない地域 R2 がある。開催場所が選択エリアにあるイベント E1、選択エリアの外のイベント E2、読みものがある | エリアとカテゴリーを選んで読む | 地域の枠は R1 だけ、イベントの枠は E1 だけ。E1 はカテゴリーの条件で絞られない。読みものの枠は、条件にかかわらず現れる（AC-80） | |
| 条件に合うフィード対象の掲載がない。公開中の地域・読みもの・イベントはある | 条件を選んで読む | 空の並び。掲載の全件数は 0。大きな枠を1つも持たない。エラーにならない | |
| 選んだカテゴリーの1つが廃止されている | そのカテゴリーと現役のカテゴリーを選んで読む | 廃止されたカテゴリーは条件から外れ、現役のカテゴリーだけで絞り込まれる。効いている条件に、廃止されたカテゴリーは含まれない | |
| カテゴリー K が廃止され、移行先は M。K が保存されたままの掲載がある | カテゴリー M を選んで読む | K が保存された掲載が、M の掲載として現れる | |
