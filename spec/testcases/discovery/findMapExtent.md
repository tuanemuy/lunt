# findMapExtent

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 選択エリアの中に店舗 P・Q、外に店舗 S がある | エリアの選択から求める | P と Q の位置が収まる最小の範囲を返す。S は範囲に関わらない。現在地がなくても、選択エリアから地図の範囲が決まる（AC-53） | |
| 閲覧できる店舗 P・Q・S が離れた位置にある | 空のエリアの選択から求める | P・Q・S のすべての位置が収まる範囲を返す | |
| 上に加えて、さらに離れた位置に、閉店した店舗と非公開の店舗がある | 空のエリアの選択から求める | 範囲は変わらない。閉店した店舗と非公開の店舗は範囲に関わらない | |
| 選択エリアの中に、店舗 P と、離れた位置の閉店した店舗 C がある | エリアの選択から求める | P の位置が収まる範囲を返す。エリアを選択中も、閉店した店舗（発見の場面に表示されない店舗）は範囲に関わらない | |
| 選択エリアの中に、掲載を持つ店舗 P と、掲載を持たない店舗 T がある | エリアの選択から求める | P と T の位置が収まる範囲を返す。掲載とカテゴリーは範囲に関わらない | |
| 地域 R に、閲覧できる店舗 P・Q が所属している | R を指定して求める | R の位置と、P・Q の位置が収まる範囲を返す（AC-04） | |
| 選択エリアの中に、閲覧できて閉店していない店舗が1つもない | エリアの選択から求める | 日本全体が収まる範囲（`Geo.JAPAN`）を返す。エラーにならない | |
| 店舗が1つもない | 空のエリアの選択から求める | 日本全体が収まる範囲（`Geo.JAPAN`）を返す | |
| 閲覧できる店舗 P・Q・S がある | 空のエリアの選択と現在地から求める | 現在地の周辺（地域の一覧と同じ半径の設定値）を囲む範囲（`Geo.boundsOf`）を返す。店舗の位置は範囲に関わらない | |
| 選択エリアの中に店舗 P・Q がある | エリアの選択と現在地から求める | P と Q の位置が収まる範囲を返す。現在地は範囲に関わらない | |
| 地域 R が運営による非公開 | R を指定して求める | `null` を返す | |
