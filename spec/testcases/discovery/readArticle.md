# readArticle

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開中の読みもの A が、イベント E、掲載 L、地域 R、店舗 P をこの順に紹介先に持つ。すべて閲覧できる | A を読む | タイトル・写真（登録された順）・本文と、紹介先の要約を E、L、R、P の順で返す。紹介先は種類を区別でき、詳細を開くための ID を持つ（AC-06、AC-71） | |
| 紹介先に、提供終了の掲載、閉店した店舗、終了したイベントがある | A を読む | どれも紹介先に現れ、状態を区別できる（AC-14） | |
| 紹介先の掲載 L が一時非公開に、地域 R が公開の取り下げになった | A を読む | 読みものは同じ本文で返る。L と R は紹介先に現れず、残りの紹介先は並べた順のまま返る（AC-15） | |
| 紹介先の店舗 P が非公開になった。紹介先には P の掲載 L もある | A を読む | P も L も紹介先に現れない（AC-48） | |
| 紹介先の掲載が削除された | A を読む | その掲載は紹介先に現れない。エラーにならない | |
| 紹介先が、どれも閲覧できない。または、紹介先を持たない | A を読む | 読みものの内容と、空の紹介先を返す | |
| 読みものが、下書き、公開の取り下げのいずれか。または、その ID の読みものがない | その読みものを読む | どれも `NotFoundError`。理由を区別しない | |
