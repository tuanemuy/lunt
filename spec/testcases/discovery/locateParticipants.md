# locateParticipants

特に書かなければ、格子は 4 × 4、範囲は `null` で読む。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| イベント E に、離れた位置の店舗 P・Q・S が参加中 | E で読む | 3つの店舗が別々の区画に、それぞれ1件の店舗の区画として、店舗の要約（営業状況と店舗の ID を含む）つきで返る。3つの位置が収まる範囲を併せて返す（AC-05） | |
| イベント E の参加店舗 P・Q が近い位置にあり、同じ区画に入る。離れた位置に S | E で読む | P と Q は位置の違う店舗のまとまり（件数 2、P と Q の位置が収まる範囲）、S は1件の店舗の区画。地図（`readMapCells`）と同じまとめ方 | |
| 上と同じ | 上のまとまりの範囲を範囲にして読む | P と Q が別々の区画に、それぞれ1件の店舗として返る。すべての参加店舗が収まる範囲は、範囲を渡さないときと同じ | |
| 同じ位置の参加店舗 P・Q | E で読む | 同じ位置の店舗だけのまとまりで、その位置と P・Q の店舗の要約の一覧を持つ | |
| 参加店舗に、休業中の店舗と閉店した店舗がある | E で読む | どちらも現れ、状態を区別できる | |
| 参加店舗に、非公開の店舗がある | E で読む | その店舗はどの区画にも現れず、範囲にも関わらない | |
| 参加店舗に、写真のない店舗がある。その店舗に写真のある閲覧できる掲載がある | E で読む | その店舗の要約の写真は、掲載の代表写真で代用される（AC-29） | |
| 終了したイベント | そのイベントで読む | 参加店舗が返る | |
| イベントに参加店舗がない | E で読む | 空の並びと範囲 `null`。エラーにならない | |
| イベントが公開の取り下げ、運営による非公開、または存在しない | そのイベントで読む | `NotFoundError` | |

## 範囲の外の参加店舗

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| イベント E の参加店舗が、範囲 B の中に3件、B の外に2件 | E と範囲 B で読む | 区画には B の中の3件、`outside` には B の外の2件が、すべてを収める範囲の同じ格子でまとめて現れる。区画と `outside` を合わせて、各参加店舗は1回ずつ現れる | |
| 上と同じ | E と範囲なしで読む | 区画に5件が現れ、`outside` は空 | |
