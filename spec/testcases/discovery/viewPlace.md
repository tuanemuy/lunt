# viewPlace

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 営業中の店舗 P に、公開中の掲載、所属地域、参加中の開催前のイベント、P を紹介先に持つ公開中の読みものがある。ログインしていない | P を読む | 店舗の写真（登録された順）・名称・紹介・所在地・位置・営業時間・連絡先・営業状況と、掲載・地域・イベント・読みものの区分を返す。各区分の要約は、詳細を開くための ID を持つ（AC-02） | |
| 写真のない店舗 P に、写真のある公開中の掲載がある | P を読む | 店舗は写真なしで返る。掲載の写真で代用されない（AC-29） | |
| 休業中の店舗と、閉店した店舗 | それぞれを読む | どちらも閲覧でき、位置を含めて返る。休業・閉店を、営業中と区別できる（AC-14） | |
| 閉店した店舗に、公開中の掲載がある | 読む | 掲載の区分に、その掲載が現れる（店舗の詳細の掲載は参照の場面） | |
| 店舗に、提供終了の掲載 e1、提供開始前の掲載 u1、提供中の掲載 a1（先に公開）と a2（後に公開）がある | 読む | 掲載の区分は a2、a1、u1、e1 の順。それぞれ状態（提供開始前は開始日）を区別できる（AC-14） | |
| 店舗に公開中の掲載が8件ある。下書きと一時非公開の掲載もある | 読む | 掲載の区分は先頭6件と全件数 8。下書きと一時非公開の掲載は含まれない | |
| 店舗に公開中の掲載がない | 読む | 店舗の情報と残りの区分が返り、掲載の区分は空。エラーにならない | |
| 店舗が地域 X・Y の順に所属し、代表地域を選んでいない | 読む | 地域の区分は X、Y の順で、すべての所属地域が返る（AC-25） | |
| 店舗が地域 X・Y・Z の順に所属し、代表地域に Z を選んでいる。Z は公開の取り下げ中 | 読む | 地域の区分は X、Y の順。Z は現れない（AC-25） | |
| 店舗が、開催前のイベント E1、開催中のイベント E2、終了したイベント E3、中止のイベント E4 に参加中 | 読む | イベントの区分は E2、E1 の順（開催日の順）。E3 と E4 は現れない（AC-32） | |
| 店舗を紹介先に持つ公開中の読みものが4件ある | 読む | 読みものの区分は、公開の新しい順の先頭3件と全件数 4（AC-71） | |
| 店舗に店舗管理者がいない。ログインしていない | 読む | 店舗管理者がいないことと、閲覧者が店舗管理者でないことを返す。この2つの事実から、管理権限の申請に進める店舗であることが決まる（AC-56） | |
| 店舗に店舗管理者 A がいる | A として読む。別に、店舗管理者でない利用者 B として読む | どちらも、店舗管理者がいることを返す。A には閲覧者が店舗管理者であることを、B には店舗管理者でないことを返す | |
| 店舗が非公開。または、その ID の店舗がない | その店舗を読む | どちらも `NotFoundError`。理由を区別せず、店舗の名称・写真を返さない（AC-48） | |
| 非公開の店舗の店舗管理者 A | A としてその店舗を読む | `NotFoundError`。閲覧者の立場は、閲覧できるかどうかを変えない | |
