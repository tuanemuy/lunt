# getSavedTargets

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 掲載 L と店舗 P を保存済み。掲載 M は保存していない | L、M、P を示して読む | L と P を返す。M は返さない | |
| 何も保存していない | L を示して読む | 空の一覧を返す | |
| 掲載 L を保存済み | 空の一覧を示して読む | 空の一覧を返す | |
| 掲載 L を保存済み。L が紐づく店舗 P は保存していない | L と P を示して読む | L だけを返す | |
| 保存済みの掲載 L を `removeBookmark` で解除した | L を示して読む | 空の一覧を返す | |
| 保存済みの掲載 L が、その後に閲覧できなくなった | L を示して読む | L を返す。保存済みかどうかは、対象を閲覧できるかどうかと別に決まる | |
| 利用者 B が掲載 L を保存済み。利用者 A は保存していない | A として L を示して読む | 空の一覧を返す | |
