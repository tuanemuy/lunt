# removeBookmark

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 保存済みの、閲覧できる掲載 | その掲載の保存を解除する | 成功する。アカウントの保存からなくなり、`getSavedTargets` が返さず、`listBookmarks` に現れない。ドメインイベントは出ない（AC-07） | |
| 保存済みの掲載が、その後に一時非公開になった | その掲載の保存を解除する | 成功する。保存がなくなる（AC-07） | |
| 保存済みの掲載が、その後に削除された | その掲載の保存を解除する | 成功する。保存がなくなる（AC-27） | |
| 保存済みの店舗が、その後に非公開になった | その店舗の保存を解除する | 成功する。保存がなくなる | |
| 保存していない掲載 | その掲載の保存を解除する | 成功する。何も変わらない | |
| 同じアカウントの別の端末で、同じ掲載の解除が先に確定している | その掲載の保存を解除する | 成功する。何も変わらない | |
| 掲載と、その掲載が紐づく店舗の両方を保存済み | 掲載の保存だけを解除する | 掲載の保存だけがなくなる。店舗の保存は残る | |
| 解除した掲載 | 同じ掲載をもう一度 `saveBookmark` で保存する | 新しい保存になり、`savedAt` は保存し直した時刻になる | |
| 利用者 A と利用者 B が同じ掲載を保存済み | A が保存を解除する | A の保存だけがなくなる。B の保存は残る | |
