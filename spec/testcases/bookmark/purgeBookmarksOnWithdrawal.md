# purgeBookmarksOnWithdrawal

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者 A が掲載と店舗を保存済み。A が退会した | A の `account.withdrawn` を消費する | A の保存がすべて削除される。ドメインイベントは出ない | |
| 上の消費の後 | 同じ `account.withdrawn` をもう一度消費する | 成功する。何も変わらない | |
| 保存を1件も持たない利用者が退会した | その `account.withdrawn` を消費する | 成功する。何も変わらない | |
| 利用者 A と利用者 B が同じ掲載を保存済み。A が退会した | A の `account.withdrawn` を消費する | A の保存だけが削除される。B の保存は残る | |
| A の退会と保存の削除の後、同じメールアドレスで新しいアカウントが作られた | 新しいアカウントで `listBookmarks` を読む | 空の並びを返す。以前の保存を引き継がない | |
