# saveBookmark

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ログインした利用者。閲覧できる掲載を保存していない | その掲載を保存する | 成功する。アカウントの保存に、その掲載が `savedAt` を操作の時刻にして加わる。`getSavedTargets` がその掲載を返し、`listBookmarks` の先頭に現れる。ドメインイベントは出ない（AC-07） | |
| ログインした利用者。閲覧できる店舗を保存していない | その店舗を保存する | 成功する。アカウントの保存に、その店舗が加わる | |
| 掲載と、その掲載が紐づく店舗。どちらも保存していない | 掲載だけを保存する | 掲載の保存だけが加わる。店舗は保存済みにならない | |
| すでに保存済みの掲載 | 同じ掲載をもう一度保存する | 成功する。保存は1つのままで、`savedAt` は元の日時のまま | |
| 同じアカウントの別の端末で、同じ掲載の保存が先に確定している | その掲載を保存する | 成功する。保存は1つのままで、`savedAt` は先に確定した日時のまま | |
| 表示した後に、一時非公開になった掲載 | その掲載を保存する | 成功する。保存が加わり、`getSavedTargets` がその掲載を返す。`listBookmarks` の参照を `resolveReferences` に渡すと、その参照に閲覧できないことが返る（V-39） | |
| 表示した後に、運営によって非公開になった店舗 | その店舗を保存する | 成功する。保存が加わる | |
| 削除された掲載（存在しない `ListingId`） | その掲載を保存する | 成功する。保存が加わり、`listBookmarks` に現れる。対象があることを確かめない | |
| 保存済みの掲載が、その後に一時非公開になった | 同じ掲載をもう一度保存する | 成功する。保存は1つのままで、`savedAt` は元の日時のまま | |
| 時刻 T に保存した掲載が一時非公開になり、保存一覧で解除した | 同じ掲載を時刻 U に保存し直す | 成功する。閲覧できない対象も保存し直せる。`savedAt` は U で、`listBookmarks` の先頭に現れる | |
| 利用者 A と利用者 B。どちらも保存していない | A が掲載を保存する | A の保存にだけ加わる。B の保存は変わらない | |
