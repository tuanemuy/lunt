# restoreBookmark

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 時刻 T に保存し、その後に解除した、閲覧できる掲載 | 対象と保存した日時 T を渡して戻す | 成功する。保存が `savedAt` を T にして戻り、`listBookmarks` で元の位置に並ぶ。ドメインイベントは出ない | |
| 時刻 T に保存し、閲覧できなくなった後に解除した掲載 | 対象と保存した日時 T を渡して戻す | 成功する。保存が `savedAt` を T にして戻る。対象が閲覧できるかどうかを問わない | |
| 時刻 T に保存し、対象が削除された後に解除した掲載 | 対象と保存した日時 T を渡して戻す | 成功する。保存が戻り、`listBookmarks` に現れる | |
| 解除した後、戻すまでの間に、別の端末で同じ掲載を時刻 U に保存し直している | 対象と保存した日時 T を渡して戻す | 成功する。保存は1つのままで、`savedAt` は U のまま | |
| 解除した掲載 | 現在より後の日時を渡して戻す | 成功する。`savedAt` は操作の時刻になる | |
| 解除した掲載 | 同じ対象と日時で、2回続けて戻す | どちらも成功する。保存は1つで、`savedAt` は T | |
