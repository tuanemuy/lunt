# LoginMailSender

外部サービスのポート。テスト用の実装と本番の実装が、同じケースを通す。送ったメールの内容は、実装ごとの観測の手段（テスト用の実装は記録した送信、本番の実装は送信先のサービスの検証用の環境）で確かめる。UnitOfWork に参加しないので、UnitOfWork の中での振る舞いのケースは持たない。

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 送信を引き受けられる状態 | `send({ to, linkToken, code, expiresAt })` | 解決する。送信を引き受けた時点で解決し、相手への到達を待たない | |
| 送信を引き受けられる状態 | `send` の後、送ったメールを確かめる | `to` 宛てのメールが1通だけ送られている。1通のメールに、リンクとコードの両方が載っている | |
| 送信を引き受けられる状態 | `send` の後、送ったメールのリンクを確かめる | リンクは Lunt の行き先を指し、開いたブラウザが `linkToken` を Lunt に渡せる形で `linkToken` を含む | |
| 送信を引き受けられる状態 | 違う `to`・違う秘密の値で `send` を2回呼ぶ | それぞれの `to` に、それぞれのリンクとコードを載せたメールが1通ずつ送られている。秘密の値は混ざらない | |
| 送信を引き受けられない状態（送信先のサービスに届かない、またはサービスが拒否する） | `send` | `SystemError`（再試行できる）。メールは送られていない | |
| 送信を引き受けられる状態。記録を残す `Logger` を渡している | `send` の後、`Logger` の記録を確かめる | 記録のどこにも `linkToken` と `code` の値が現れない | |
| 送信を引き受けられない状態。記録を残す `Logger` を渡している | `send` が失敗した後、`Logger` の記録とエラーの内容を確かめる | 記録にもエラーの内容にも、`linkToken` と `code` の値が現れない | |
