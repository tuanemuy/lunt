# PhotoStorage

契約: [../../domains/media.md](../../domains/media.md) の `PhotoStorage`。テスト用の実装と本番の実装が、同じケースを通す。「取得できる」は、`displayRefs` が返した参照から、写真の実体を取得できることを指す。

## put

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 実体がない | `PhotoId` とファイルで `put` する | 解決する。その `PhotoId` の参照で、置いた写真を取得できる | |
| `put` した `PhotoId` | 同じ `PhotoId` と同じファイルで、もう一度 `put` する | 解決する。結果は1回目と同じで、取得できる | |
| `put` した `PhotoId` | 同じ `PhotoId` と別のファイルで `put` する | 解決する。実体が置き換わり、後から置いた写真を取得できる | |
| 実体がない | 2つの `PhotoId` に、それぞれ別のファイルを `put` する | それぞれの参照で、それぞれの写真を取得できる。互いに影響しない | |

## copy

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| `put` した元の `PhotoId` | 元から新しい `PhotoId` へ `copy` する | 解決する。新しい `PhotoId` の参照で、元と同じ写真を取得できる。元の実体も取得できる | |
| `copy` した元と複製 | 元を `delete` する | 複製は取得できる | |
| `copy` した元と複製 | 複製を `delete` する | 元は取得できる | |
| `copy` した元と複製 | 元に別のファイルを `put` する | 複製は、複製した時点の写真のまま取得できる | |
| 元と、すでに実体のある複製先 | 元から複製先へ `copy` する | 解決する。複製先の実体が、元の写真に置き換わる | |
| `copy` した元と複製 | 同じ引数で、もう一度 `copy` する | 解決する。結果は1回目と同じ | |
| `copy` で作った複製 | 複製を元にして、さらに別の `PhotoId` へ `copy` する | 解決する。`put` の後と同じく、`copy` の元にできる | |
| 元の `PhotoId` に実体がない | `copy` する | `NotFoundError`。複製先に実体は作られない | |
| 元の実体を `delete` した | その `PhotoId` を元に `copy` する | `NotFoundError` | |

## delete

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| `put` した `PhotoId` | `delete` する | 解決する。その `PhotoId` の参照で取得できない | |
| `delete` した `PhotoId` | もう一度 `delete` する | 解決する。エラーにならない | |
| 一度も実体を置いていない `PhotoId` | `delete` する | 解決する。エラーにならない | |
| 2つの `PhotoId` に `put` した | 片方を `delete` する | もう片方は取得できる | |
| `delete` した `PhotoId` | 同じ `PhotoId` に `put` する | 解決する。置いた写真を取得できる | |

## displayRefs

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| `put` した `PhotoId` が3つ | 3つを渡す | 3つすべての `PhotoId` を鍵に持つ対応を返す。それぞれの参照で、その写真を取得できる | |
| `put` した `PhotoId` と、実体のない `PhotoId` | 2つを渡す | 2つとも鍵に持つ対応を返す。実体の有無を確かめず、エラーにならない。実体のない側の参照では取得できない | |
| なし | 空の一覧を渡す | 空の対応を返す | |
| `put` した `PhotoId` | 1つを渡す | 1つの対応を返す | |
| 100個の `PhotoId` | 100個を渡す | 100個すべての対応を返す | |
| 101個の `PhotoId` | 101個を渡す | `BusinessRuleError`（`COMMON_INVALID_INPUT`） | |
| `put` した `PhotoId` | `displayRefs` を2回呼ぶ | どちらの参照でも、同じ写真を取得できる | |
| `put` した `PhotoId` の参照を得た後、同じ `PhotoId` に別のファイルを `put` した | もう一度 `displayRefs` を呼ぶ | 返された参照で、後から置いた写真を取得できる | |
| `put` した `PhotoId` の参照を得た後、`delete` した | もう一度 `displayRefs` を呼ぶ | 参照は返るが、取得できない | |

## UnitOfWork との関係

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| UnitOfWork の中で `put` し、その後に例外を投げた | その `PhotoId` の参照で取得する | 取得できる。`PhotoStorage` の書き込みはトランザクションに入らず、ロールバックされない | |
