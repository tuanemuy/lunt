# TakedownOutcomeMailer

契約は [Moderation](../../domains/moderation.md) の「TakedownOutcomeMailer」による。テスト用の実装と本番の実装が、同じケースを通す。送ったメールの数は、テスト用の実装では送信の記録で、本番の実装では送信先の検証用の環境（サンドボックス）で確かめる。`TakedownOutcomeMessage` は、対応済みの申立てから組み立てる。

## send

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| メールを送っていない | 宛先、対象、受け付けた日時、結果を載せて `send` を呼ぶ | 成功を返す（送信を引き受けた）。送信の記録は、その宛先への1通 | |
| メールを送っていない | 対象が掲載・店舗・地域・イベント・読みものの `TakedownOutcomeMessage` で、それぞれ `send` を呼ぶ | どの対象でも成功を返す。送信の記録のメールの文面は、結果（`outcome`）を含む | |
| メールを送っていない | 措置を行わないことを結果にした `TakedownOutcomeMessage` で `send` を呼ぶ | 成功を返す。送信の記録は1通 | |
| 対象がすでに削除されている申立ての `TakedownOutcomeMessage` がある | `send` を呼ぶ | 成功を返す。ポートは対象があることを確かめない | |
| ある `TakedownOutcomeMessage` の `send` が成立している | 同じ内容で、2回目の `send` を呼ぶ | 2回目も成功を返す。送信の記録は2通。ポートは送信の重なりを除かない | |

## 送信を引き受けられない場合

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 実装が送信を引き受けられない状態にある | `send` を呼ぶ | `SystemError`。送信の記録は0通 | |
| 上の失敗の後、実装が送信を引き受けられる状態に戻った | 同じ内容で、もう一度 `send` を呼ぶ | 成功を返す。送信の記録は1通 | |
