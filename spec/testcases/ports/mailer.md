# Mailer

契約: [../../domains/notification.md](../../domains/notification.md) の `Mailer`。テスト用の実装と本番の実装が、同じケースを通す。宛先に届いたメールは、実装の送信先で確かめる（テスト用の実装は送信の記録、本番の実装は送信先のサービスの検証用の環境）。

## send

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 宛先 M1、件名、本文を持つ `RenderedMail` | `send` を呼ぶ | エラーなく完了する（送信を引き受けた）。M1 に、その件名と本文のメールが1通届く | |
| アカウントのないメールアドレスを `to` とする `RenderedMail` | `send` を呼ぶ | エラーなく完了し、そのメールアドレスにメールが1通届く。ポートはアカウントを読まない | |
| 宛先 M1 への `send` が成立している | 宛先 M2 の `RenderedMail` で `send` を呼ぶ | M1 と M2 に1通ずつ届く | |
| 宛先 M1 への `send` が成立している | 同じ内容の `RenderedMail` で、もう一度 `send` を呼ぶ | エラーなく完了する。M1 に届くメールは2通（ポートは重複を防がない） | |

## 送信を引き受けられない場合

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 実装が送信を引き受けられない状態にある | `send` を呼ぶ | `SystemError`。メールは届かない | |
| 上の失敗の後、実装が送信を引き受けられる状態に戻った | 同じ `RenderedMail` で、もう一度 `send` を呼ぶ | エラーなく完了し、メールが1通届く | |
