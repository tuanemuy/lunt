# Lunt 付属資料：デザイン・画面構成・プロトタイプ

資料日：2026年9月20日

本資料はデザインと画面設計の参考資料とする。機能・業務上のルール・採用範囲は[要件定義書](requirements.md)を優先する。プロトタイプの画面名と操作例は、Figma上の構成を示す。

## 1. デザイン方針

- アプリ名はLunt（ラント）、ロゴはA、アイコンはA₂を使用する。
- 閲覧側のデザインはC₁とする。キャッチコピー・名称にはNoto Serif JP、本文・操作にはNoto Sans JPを使用する。
- 店舗管理画面はNoto Sans JPを中心とし、公開前プレビューには閲覧側の表現を使う。
- 個別掲載は写真・名称・店舗・地域で構成する。
- 地域・読みものを大きな枠で扱い、写真の上にキャッチコピーを置く。
- 地域・読みものの大きな枠と個別掲載の区切りには、前後で共通の罫線を使う。

## 2. フィードと操作の表現

代表画面は地域から始まり、個別掲載6件、読みもの、個別掲載6件、地域の順に並ぶ。個別掲載は2列とする。地域と個別掲載は独立して選ぶ。

地域・読みものの枠から各詳細へ移動する。個別掲載の写真カードから掲載詳細を開く。

カテゴリーは「食べる・買う・体験・見る」とする。

掲載写真は切り抜き位置を調整し、公開前にカードと詳細の見え方を確認する。店舗の管理入口は、店舗ページの「このお店を管理する」と店舗向け案内に置く。

## 4. 閲覧側の画面構成

下部ナビゲーションは「みつける / マップ / まち / 読む / 保存」とする。

| 画面群 | プロトタイプの画面 |
| --- | --- |
| 発見・検索 | ホーム、ジャンル別フィード、検索、検索結果、エリア選択、絞り込み |
| 地図 | 地図、地図の一覧、参加店舗マップ |
| 地域 | 地域一覧、地域詳細、地域内店舗、地域内イベント |
| 掲載・訪問先 | 商品・体験・景色・見どころの詳細、店舗・スポット詳細 |
| イベント | イベント一覧、イベント詳細、参加店舗一覧 |
| 読みもの | 一覧、記事 |
| 保存・補助状態 | 保存一覧、未保存、検索0件、イベント未開催、読み込み、通信エラー、位置情報未許可 |

Presentから「Lunt — みつける」を選択する。写真カード、下部ナビゲーション、検索候補、絞り込み、戻るを操作できる。長い画面は中央の内容を縦スクロールする。保存アイコンはオン・オフを切り替えられる。

## 5. 店舗側の画面構成

管理ナビゲーション案は「ホーム / 掲載 / イベント / 店舗情報」とする。

| 画面群 | プロトタイプの画面 | 状況 |
| --- | --- | --- |
| 管理開始 | 店舗を探す、管理申請、新規店舗登録 | 代表画面・操作後の状態あり |
| 店舗ホーム | 掲載追加、公開中・下書きなどの入口、イベント、店舗情報 | 代表画面あり |
| 掲載管理 | 編集、公開前プレビュー、公開・下書き保存後の状態 | 代表画面あり |
| イベント参加 | イベント詳細、提供内容・参加日、申請後の状態 | 代表画面あり |
| 店舗情報 | 店舗情報編集、保存後の状態 | 代表画面あり |
| 補助・詳細操作 | 認証、管理者確認、写真編集、一覧の状態切替、イベント修正・確定、メンバー管理 | 未設計 |

地域運営者・編集担当者・サービス運営者の専用画面は未設計とする。

## 6. 画面設計で扱う事項

| 対象 | 検討する内容 |
| --- | --- |
| フィード | 枠の比率、挿入間隔、先頭の表現 |
| エリア選択 | 郵便番号と対応する地名の提示、選択方法 |
| 地図 | 移動に応じた再検索、ピンの集約 |
| 入力・編集 | 入力項目の配置、写真の選択・並び替え・切り抜き、確認方法 |
| 申請 | 登録・修正・管理権限・所属・離脱の申請内容と結果の提示 |
| イベント | イベントの選択、参加店舗・掲載の一覧、参加申請と管理操作の配置 |
| 閲覧状態 | 終了・非公開・休業・閉店・空状態の表現 |
| 管理操作 | メンバー管理、地域運営、運営・編集機能の画面構成 |

## 7. プロトタイプの範囲

Figmaは閲覧側49画面・状態、店舗側12画面・状態を含む。件数には同じ画面の状態違いとサンプル内容違いを含む。

検索・絞り込みは、用意した状態への遷移を表す。保存一覧はサンプルで、保存アイコンとのデータ同期は行わない。フォーム入力、写真編集、認証、実際の公開・申請処理は未実装である。実検索・位置情報・地図データ・外部予約は未接続である。

写真・地名・店舗・営業時間・イベント・地図はデザイン確認用のサンプルとする。
