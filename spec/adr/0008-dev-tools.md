# ADR 0008: 開発用の道具を開発の構成と localhost だけで有効にする

- 状態: 採用

## 背景

手動テストは、時刻を進める・日次ジョブを手で実行する・メールを読む・外部ログインを疑似する・テストデータを入れる手段を前提にする（`spec/manual-tests/*.md` の前提条件）。疑似ログインは誰にでもなれるので、公開の環境で有効になると危ない。

## 決定

- 開発用の道具は `/__dev/*` に置く: 開発用受信箱、疑似外部ログイン、時刻のずれ（進める・0 に戻す。DO の開発用の表に置き、要求・消費者・日次ジョブの `Clock` に足す）、日次ジョブの手動実行、`/__dev/seed`（手順書ごとのテストデータを既存のユースケース経由で入れる）、`/__dev/stewards`
- `DEV_TOOLS=1` のときだけ有効で、さらに要求のホストが localhost・127.0.0.1・[::1] のときに限る。共有のテスト環境では `DEV_TOOLS_ALLOW_REMOTE=1` で解除する
- Cron の自動の実行は `DAILY_JOBS_AUTO="off"` で止められる（`DEV_TOOLS=1` のときだけ効く）
- `LUNT_STATE_DIR` で dev サーバーごとに DO・Queue・R2 の状態を分け、手動テストを並べて動かせる
- デプロイのビルドは `LUNT_WRANGLER_CONFIG` で本番の構成を指し、開発用の道具を含めない

## 結果

- 本番の構成と公開のホストでは、誤設定でも開発用の道具が開かない
