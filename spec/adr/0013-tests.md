# ADR 0013: テストを3層に分け、spec のテストケースに名前で対応づける

- 状態: 採用

## 背景

spec のテストケースは 3,500 行を超え、ユースケーステストとポート適合テストに分かれる。

## 決定

- ドメインは Node の単体テスト
- ユースケーステストは Node で、DO の保存のコードを `node:sqlite` の上で直接動かすコンテナで走らせる
- ポート適合テストはポートごとに1つのスイートを書き、Node と実際の DO（vitest-pool-workers）の両方で走らせる
- spec のケースとの対応は、テスト名に `{usecase}#{ファイル内の出現順}` とケースの見出しの文言を入れて付ける。spec に ID 列は足さず、見出しの文言で番号のずれを検出する。テストケースを足すときは既存の番号をずらさないよう、ファイルの末尾の新しい節に足す

## 結果

- 名前の照合でテストの欠け・ずれを機械的に見つけられる
