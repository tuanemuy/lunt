# ADR 0010: エリアのマスターを静的アセットとして配る

- 状態: 採用

## 背景

エリアは日本郵便の郵便番号データ（約12万行）に由来する読み取り専用のマスター（`spec/domains/area.md`）。

## 決定

- `pnpm area:import` が郵便番号データ（UTF-8 版）から分割した JSON を作り、Workers の静的アセット（ASSETS）として配る。DO には載せない
- 取り込みの規則は `spec/domains/area.md` の概念の節（注記の除き方、ビルの階、村一円、番地が続く町域）
- 生成物はコミットしない。テスト用のマスターと開発の最小の見本だけをコミットし、生成物がなければ見本で動く

## 結果

- マスターの更新は取り込みの再実行とデプロイで行う
