# ADR 0017: キーワード検索を保存済みの正規化文字列で判定する

- 状態: 採用

## 背景

読みものの本文は最大 2 万文字で、検索のたびに正規化すると1つの DO を長く止める。

## 決定

- 書き込みの時点で、ドメインの関数（`searchableText` 系と `KeywordRelevance` の正規化）から求めた検索用の文字列を、副表 `search_texts` に保存する。移行で既存の行を埋め戻し、埋め戻しは移行の時点の列の定義に固定する
- 検索は SQL の `instr` で全語を含む行に絞ってから、既存の関連度で点数を付ける
- 検索用の文字列を作れない行は、一致の結果に現れない（spec に反映）

## 結果

- 一致の規則はドメインの関数1か所に保たれ、結果は保存前の方式と同じ
- 一致の規則を変えたときは `search_texts` を作り直す
