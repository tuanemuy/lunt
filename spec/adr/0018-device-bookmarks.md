# ADR 0018: 端末の保存をブラウザに置き、ログインで合流する

- 状態: 採用

## 背景

ログインしていない閲覧者も保存でき、ログインでアカウントに引き継ぐ（`spec/domains/bookmark.md`）。

## 決定

- 端末の保存はブラウザの localStorage に `{kind, id, savedAt}` の配列で置き、サーバーは何も持たない
- ログインの後（メール・外部アカウントのどちらでも）、100 件ずつ `mergeDeviceBookmarks` へ送り、成功した分だけ端末から消す。送り直しは安全。壊れた項目は捨てて残りを合流する

## 結果

- 端末の保存は、ブラウザのデータの消去で失われる（spec の案内のとおり）
