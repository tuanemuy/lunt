# ADR 0016: フィードの候補を ID だけで読み、深さに上限を置く

- 状態: 採用

## 背景

フィードの深いページは、候補を何度も読み直すと1つの DO を長く止める。

## 決定

- フィードの候補は ID だけを返す `FeedCandidateQueries.findListingCandidates` で1回で読み、ページに入る掲載だけを組み立てる（spec に反映）
- 新しい順のための部分索引を持つ
- 転送境界で `page × limit ≤ 2,000` を上限にし、そこでフィードの終わりを示す（spec に反映）

## 結果

- どの深さでも、5万件の掲載で数十〜数百ミリ秒に収まる
