# ADR 0015: 地図を MapLibre と公開ベクトルタイルで描く

- 状態: 採用

## 背景

地図（VW-04・VW-08・DT-02・位置の選択）は実際の地図データを要する。

## 決定

- MapLibre GL JS と OpenFreeMap Positron のタイル（API キー不要、帰属表示あり。`MAP_STYLE_URL` で変える）を使い、見た目を `spec/design` の MapCanvas の色に寄せる
- ズームの操作を足し、地図を読み込めないときは CS-02 を示す
- 周辺の半径は `VICINITY_RADIUS_METERS`（既定 3,000 m）

## 結果

- 外部のタイル配信に依存する。将来 CSP を入れるときはタイルの取得元を許可する
