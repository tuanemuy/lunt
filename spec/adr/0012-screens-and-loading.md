# ADR 0012: 画面の殻とデザインの取り込み、読み込みの方式

- 状態: 採用

## 背景

閲覧側（スマホ中心）と管理側は同じサービスで、デザインは `spec/design/` を正本とする。

## 決定

- 画面は pathless のレイアウトルート `_viewer`・`_account`・`_apply`・`_manage` で殻を分ける。URL は英語の名詞で対象の ID をパスに持つ
- `spec/design/tokens.md` を `tokens.css` にし、Tailwind v4 の `@theme` で橋渡しする。書体は `@fontsource` で自己ホストし、アイコンは1つの `Icon` 部品
- デザインと spec が食い違うときは、機能・状態・行き先は `spec/pages`、見た目・配置・文言の置き方は `spec/design` に従う
- 一覧・詳細は断片のストリーミングで読み込む。ただし文書の HTTP 状態を最初の読み取りで決める画面（AM-02・SM-04・読みもの/掲載の CM-03）は、ローダーでその読み取りを待って 403・404 を返し、ルート単位の pending を示す
- 編集と申請のフォームは、準備ができるまで入力と送信を受け付けない

## 結果

- AGENTS.md の Frontend の節に読み込みの規則を書いた
