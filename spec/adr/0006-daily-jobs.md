# ADR 0006: 日次ジョブを Cron で起動し、1件の失敗で止めない

- 状態: 採用

## 背景

日付で決まる状態の記録、期間超過の通知、持ち主のない写真の削除、ログインの確認の掃除は日次のジョブが行う（`spec/flows/index.md`「共通の前提」）。

## 決定

- Cron Trigger（UTC `5 15 * * *` = 日本時間 0:05）で同じ Worker の `scheduled()` から5つのジョブを走らせ、ジョブどうしは独立に進める
- 進め方は application 層の `drainPages` 1つにまとめる。1回の実行で各対象は1回まで処理する。処理した対象が結果から外れる問い合わせは先頭を読み直し、未処理の対象がないページで打ち切る。外れない問い合わせはページを進める
- 対象を読むポートは `ScanResult<T>`（ページの結果と、復元できない行のキーと原因）を返し、ジョブはその対象を失敗として数えて進む

## 結果

- 毎回失敗する対象が先頭に1ページ分並ぶと、その後ろは進まない（spec の規則の性質）。対処の手順は `docs/runtime_cloudflare_do.md`
