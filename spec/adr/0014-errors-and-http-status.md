# ADR 0014: 業務エラーを共通の状態と HTTP 状態に型で対応づける

- 状態: 採用

## 背景

spec は業務エラーのコードと、画面の共通の状態（CS-xx）を定める。AGENTS.md は HTTP 状態の対応を presentation の責務とする。

## 決定

- 業務エラーのコードは型つきの台帳 `BusinessErrorCode` で共通の状態（CS-10・CS-08 など）と表示の文言に対応づける。各ドメインはコードを足すときに台帳に載せる（載せ漏れは型エラー）
- 文書の HTTP 状態はエラーの種類から決める（forbidden は 403、not found は 404、unauthorized は 401）
- 管理側の読み取りの想定外の失敗は、画面の状態を変えずに Logger ポートで記録する

## 結果

- ストリーミングの本文の中で描く共通の状態は 200 のまま。HTTP 状態が要る画面はローダーで判定する（ADR 0012）
