# 読みもの編集（AM）

編集担当者が、読みものを一覧で確かめ、作成・編集・公開・公開の取り下げを行う画面を定める。画面の一覧、ナビゲーション、共通の状態（CS）、共通の機能（CF）、状態の示し方は [index.md](index.md) が定める。

- AM の画面は、編集担当者の役割を持つ利用者だけが開ける（CS-05）。編集担当者は、誰が作成した読みものも同じく扱える
- 公開前の見え方の確認は CM-03 が負う。対象は、下書きと公開を取り下げた読みもの。AM-02 は入口を持ち、公開の操作を CM-03 と共有する
- 読みものを削除する操作は持たない

## AM-01 読みものの一覧

- 目的: すべての読みものを下書き・公開・公開の取り下げの別に確かめ、読みものを選ぶ
- シナリオ: EDT-01、EDT-03、EDT-04、EDT-05
- 入口: MY-01 の読みもの編集、AM-02 と CM-03 からの戻り、編集担当者への任命の通知

### 機能

- すべての編集担当者の読みものを、下書き・公開・公開の取り下げの別に、更新の新しい順の一覧で確かめる。状態の示し方は index.md の「管理する対象の状態」による
- 読みものを選び、AM-02 へ進む。状態と作成者にかかわらず選べる
- 新しい読みものの作成を始め、AM-02 を新規の状態で開く
- 公開と公開の取り下げの結果を、読みものの状態で確かめる。この画面は状態を変える操作を持たない

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-09 と CF-05 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | 読みものを状態の別に示す。申立てで写真が削除されて公開の取り下げになった読みものは、そのことを示す | 画面を開く |
| CS-09 空 | 読みものがないことを示し、新しい読みものの作成へ進める。状態の別ごとに、その状態の読みものがないことを示す | 読みものが1件もない。またはその状態の読みものがない |

## AM-02 読みものの編集

- 目的: 1件の読みものの内容と紹介先を作成・編集して保存し、公開し、公開を取り下げる
- シナリオ: EDT-01、EDT-02、EDT-03、EDT-04、EDT-05、EDT-06、MOD-03
- 入口: AM-01、CM-03 からの戻り、紹介先の変化と写真の削除の通知

### 機能

- タイトルと本文を入力する。写真を登録する（CF-01）。見せる範囲の調整は持たない
- 紹介先を結びつける。掲載・店舗・地域・イベントを探して選ぶ（CF-02）。候補は、閲覧者が閲覧できる対象とする。紹介先は複数結びつけられ、種類を混ぜられる。選んだ対象は紹介先の一覧の最後に加わる。すでに結びつけた対象は重ねて結びつかない
- 紹介先を並び替え、結びつけを外す。記事は、この順で紹介先を示す。紹介先は本文中の位置を持たない
- 結びつけた紹介先それぞれの現在の状態を示す。閲覧者が閲覧できない紹介先は、記事に表示されないことが分かる。提供開始前・提供終了の掲載、休業・閉店した店舗、開催前・終了・中止のイベントは、状態を区別して示す。閲覧できる紹介先から、閲覧側の詳細へ進める
- 保存する。写真・紹介先の変更は、保存で反映する
- 下書きと公開を取り下げた読みものは、保存した内容の閲覧者への見え方を、CM-03 へ進んで確かめる。確認は公開の必須手順ではない。公開中の読みものは CM-03 の対象にならず、DT-05 で確かめる
- 公開状態の操作は CF-08 による。下書きまたは公開を取り下げた読みものを公開し、公開中の読みものの公開を取り下げる。紹介先が1つもなくても、閲覧できない紹介先があっても公開できる。読みものは運営による非公開の対象にならない
- 本文は、紹介先の変化で自動では書き換わらない。紹介内容の修正は、本文の編集、紹介先の解除と差し替え、公開の取り下げで行う

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-07、CS-08、CS-10〜CS-13 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 新規 | 入力が空の状態で始まる。公開と CM-03 の操作は持たない。保存すると下書きとして作成される。保存せずにやめると、読みものは作成されない | AM-01 の新しい読みものの作成から開く |
| 下書き | 保存と公開を示す。CM-03 へ進める | 新規の保存が成立する。または下書きの読みものを開く |
| 公開 | 保存と公開の取り下げを示す | 公開が成立する。または公開中の読みものを開く |
| 公開の取り下げ | 保存と公開を示す。CM-03 へ進める | 取り下げが成立する。または取り下げた読みものを開く |
| 写真の削除による公開の取り下げ | CF-08 による | 写真の削除の通知から開く。または該当する読みものを開く |
| 閲覧できない紹介先がある | その紹介先が記事に表示されないことを示す。保存と公開はできる。結びつけを外すか、そのままにする。対象が再び閲覧できるようになると、記事に再び表示される | 結びつけた対象が非公開・公開の取り下げ・削除になる。保存までの間に閲覧できなくなった場合を含む |
| CS-10 公開条件の不足 | CF-08 による | 公開の操作、または公開中の読みものの保存で条件を欠く |
| CS-12 取り下げの確認 | 読みものが、読みものの一覧・フィード・キーワード検索・紹介先の詳細のどこにも表示されなくなること、内容と紹介先の結びつけは保たれることを示す | 公開の取り下げを始める |
| CS-13 完了 | 保存・公開・取り下げが成立したことを示す。公開中の読みものは DT-05 へ進める。AM-01 へ戻れる | 保存・公開・取り下げが成立する |
| CS-08 公開状態の変化 | 別の編集担当者がすでに公開している、または公開を取り下げている。現在の公開状態を示す | 公開・取り下げの時点で前提がない |
