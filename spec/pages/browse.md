# 発見と探索（VW）

閲覧者が、フィード・絞り込み・検索・地図・地域・イベント・読みもの・保存一覧から対象を探す画面を定める。

画面の一覧、ナビゲーションと入口の置き場所、共通の状態（CS）、共通の機能（CF）、状態の示し方、画面設計で定める値は [index.md](index.md) が定める。

## 画面群に共通

- すべての画面は、ログインせずに使える
- 一覧・地図・フィードから対象を選ぶと、その詳細（DT）を開く。詳細から戻ると、元の画面は位置・範囲・条件・読み込んだ続きを保っている
- 選んだ対象が、開くまでの間に閲覧できなくなった場合は、開いた詳細が CS-06 を示す。閲覧者は元の画面へ戻る
- 各画面は、発見の場面か参照の場面かを述べる。表示範囲の規則、掲載のカードと行の構成、一覧に示す地域名、写真のない店舗の示し方は、index.md の「公開中の対象の状態（閲覧側）」に従う

## VW-01 みつける

- 目的: 目的を決めていない閲覧者が、写真を中心に掲載・地域・イベント・読みものを眺めて見つける
- シナリオ: DIS-01、DIS-02、DIS-03、DIS-04、DIS-06、KEP-01
- 入口: Lunt を開いた最初の画面、下部ナビゲーション「みつける」

### 機能

- 目的・エリア・カテゴリーを選ばずに、フィードを眺める。フィードと絞り込みの結果は発見の場面に当たる。フィードの対象は DIS-01 が、絞り込みの間の対象は DIS-03 が定める
- 掲載は、商品・体験・景色・見どころのどれも同じ形のカードで、複数の地域のものを混ぜて並べる。混ぜ方（同じ店舗・同じ地域の掲載を続けて置かない規則と、その例外）は DIS-01 が定める
- 掲載の間に、地域・イベント・読みものを大きな枠で紹介する。挿入の間隔、種類の巡回の順、種類の中の順は、index.md の「フィード」に従う
- 大きな枠は写真と名称（読みものはタイトル）で示し、地域とイベントはキャッチコピーがあれば添える
- 下へ進むと、続きの掲載と紹介を読み込む（CF-05）。フィードは先頭から約 2,000 件の掲載まで読み込み（1回の要求が扱うページの深さの上限。`page × limit ≤ 2,000`）、そこで終わりを示す。それより先は、条件を絞るか検索・地図で探す
- 掲載のカードは DT-01、地域の枠は DT-03、イベントの枠は DT-04、読みものの枠は DT-05 を開く
- 掲載のカードで、保存と解除を切り替える（CF-04）
- 選択中の条件を確かめ、解除する（CF-03）。絞り込み（VW-02）へ進む
- イベントの一覧（VW-07）へ進む。検索の入口は、index.md の「閲覧側の下部ナビゲーション」による
- 現在地の利用を始める。ブラウザが位置情報の利用の許可を求める
- 下部ナビゲーションからマップ（VW-04）へ進むと、同じ条件で地図を確かめられる

### 状態

絞り込みの状態と現在地の状態は独立していて、重なる。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 絞り込みなし | フィードのすべての対象を並べる | 条件を選ばずに開く。条件をすべて解除する |
| 絞り込み中 | 選択中の条件に合う対象だけを、絞り込みなしと同じ間隔と順で並べる。カテゴリーだけを選択中の表示が「ジャンル別フィード」に当たる | VW-02 で条件を適用する。VW-04・VW-05 で選んだ条件のまま開く |
| 現在地を利用していない | 新しい掲載を優先して並べる。位置情報未許可であることは示さない | 位置情報の利用を許可していない状態で開く。許可を取り消した後に開く場合を含む |
| 現在地を利用中 | 現在地に近い掲載・地域・イベントを優先して並べる。絞り込み中は、条件に合う対象の中で優先する | 現在地の利用を始めて、ブラウザの求めに許可する。すでに許可している状態で開く |
| CS-03 | 新しい掲載を優先した並びのまま表示を続ける | 現在地の利用を始めたが、許可しない、端末で無効、または現在地を取得できない |
| CS-09（紹介できる掲載がない） | 絞り込みなしで、フィードの対象となる掲載がない。VW-03、VW-04、VW-05、VW-07、VW-09 へ進める | 開いた時点で対象の掲載がない |
| CS-09（条件に合う掲載がない） | 大きな枠も挿入しない。条件の変更（VW-02）と解除（CF-03）へ進める | 適用・変更した条件に合う掲載がない |
| CS-01 | — | 開く。条件または現在地の状態が変わる。続きを読み込む |
| CS-02 | 続きの読み込みで起きた場合は、読み込んだ分を保つ | 取得が通信エラーで成立しない |

## VW-02 絞り込み

- 目的: エリアとカテゴリーの条件を選び、適用・変更・解除する
- シナリオ: DIS-03、DIS-04
- 入口: VW-01・VW-04・VW-05 の絞り込みの入口と、選択中の条件の表示（CF-03）

### 機能

- エリアを選ぶ。たどり方、選べる単位、併せて選べる範囲は、index.md の「エリアの選択」に従う
- カテゴリーを選ぶ。現役のカテゴリー（`spec/scenario/listing.md` の「掲載の内容」）から複数選べる
- エリアだけ、カテゴリーだけ、両方のいずれでも適用できる
- 選択中の条件が選ばれた状態で始まる。条件を追加し、外し、別のものに変える
- 適用すると、呼び出した画面へ戻り、条件が表示に反映される。同じ条件が VW-01・VW-04 に、エリアの条件が VW-05 に効く
- 選択をすべて外して適用すると、絞り込みのない表示に戻る
- 適用せずにやめると、条件は変わらず、呼び出した画面の元の表示に戻る
- どの入口から開いても、同じ条件を扱う

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 選択 | 開いた時点の条件が選ばれている。エリアは階層をたどって選ぶ | 入口から開く |
| 適用 | 選んだ条件が確定し、呼び出した画面へ戻る | 適用の操作 |
| 取りやめ | 条件は変わらず、呼び出した画面へ戻る | 適用せずにやめる |
| CS-01 | — | エリアの階層とカテゴリーを取得している |
| CS-02 | 選びかけの内容は保つ | エリアの階層とカテゴリーの取得が通信エラーで成立しない |

## VW-03 検索

- 目的: キーワードで店舗・地域・掲載・イベント・読みものを探す
- シナリオ: DIS-05
- 入口: 閲覧側の5つのタブ画面の検索の入口、空の状態と通信エラーが示す別の探索手段

### 機能

- キーワードを入力して検索する。検索語を変えて、探し直す
- 結果を、店舗・地域・掲載・イベント・読みものの種類ごとに分けて示す。キーワードが当たる項目と、種類の中の並びは `spec/scenario/index.md` の「探し方」が定める。結果のない種類は示さない
- 種類ごとに、続きを読み込む（CF-05）
- 選択中のエリア・カテゴリーの条件は結果に効かない。選択中の条件の表示を持たない
- 検索結果は参照の場面に当たる
- 結果を選ぶと、DT-01〜DT-05 のうち対象の詳細を開く
- 検索せずに入力をやめると、元の画面へ戻る

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 入力前 | キーワードの入力を受け付ける。結果は示さない | 入口から開く |
| キーワード未入力 | 検索を行わず、キーワードの入力を求める | キーワードが空、または空白だけのまま検索する |
| 結果 | 種類ごとの結果を示す。検索語は保つ | 検索が成立し、どれかの種類に結果がある |
| CS-09（検索結果がない） | どの種類にも結果がない。検索語の変更と、VW-01・VW-04・VW-05・VW-07・VW-09 へ進める | 検索が成立し、結果がない |
| CS-01 | — | 検索する。続きを読み込む |
| CS-02 | 検索語は保つ | 検索が通信エラーで成立しない |

## VW-04 マップ

- 目的: 範囲と条件に合う店舗と地域を、地図と一覧で探す
- シナリオ: EXP-01、EXP-02、DIS-04、DIS-06
- 入口: 下部ナビゲーション「マップ」（VW-01 を含む閲覧側のどの画面からも、ここを通って開く）、DT-03（その地域を選んだ状態で開く）

### 機能

- 地図に、範囲と条件に合う店舗と地域を、それぞれの位置に示す。地域は1点で示す。地図、一覧、地域を選んだときの所属する店舗は、発見の場面に当たる。条件の効き方は EXP-01 が定める
- 初めの範囲、DT-03 から開いたときの範囲、地図を動かしたときの再検索、ピンのまとめ方、地域を選んでいる間の示し方と条件の効き方は、index.md の「地図」に従う
- 店舗を選ぶと、写真・名称・所在地と、休業中であればそのことを、概要として示す。概要から DT-02 を開く
- 地域を選ぶと、写真・名称・所在地を概要として示す。所属する店舗の位置から、地域の広がりを確かめられる。概要から DT-03 を開く
- 地図と一覧を切り替える。一覧は、地図と同じ範囲・同じ条件の店舗と地域を、種類ごとに分けて示す
- 一覧の店舗は写真・名称・所在地・地域名と休業中かどうかで、地域は写真・名称・所在地で示す。それぞれ、現在地を利用していれば現在地に近い順、利用していなければ新しい順に並べ、続きを読み込む（CF-05）
- 一覧の店舗は DT-02、地域は DT-03 を開く
- 選択中の条件を確かめ、解除する（CF-03）。絞り込み（VW-02）へ進む
- 現在地の利用を始める。許可すると、現在地の周辺を示す

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 地図の表示 | 範囲と条件に合う店舗と地域を地図に示す | 入口から開く。一覧から地図へ戻る |
| 再検索中 | 前の結果を示したまま、新しい範囲の対象を取得する | 地図を動かす、または縮尺を変える操作が止まる。条件が変わる |
| 店舗を選択中 | 選んだ店舗の概要を示す | 店舗のピンを選ぶ。同じ位置の店舗の一覧から店舗を選ぶ。別の対象を選ぶか、選択をやめると終わる |
| 同じ位置の店舗を選択中 | 同じ位置にある店舗の一覧を示す（index.md の「地図」） | 同じ位置の店舗だけのまとまりを選ぶ。一覧から店舗を選ぶか、選択をやめると終わる |
| 地域を選択中 | 選んだ地域の概要と、所属する店舗の位置の区別を示す。条件の効き方は index.md の「地図」に従う | 地域のピンを選ぶ。DT-03 から開く。別の対象を選ぶか、選択をやめると終わる。再検索では終わらない |
| 一覧の表示 | 最後に再検索した範囲と条件の対象を一覧で示す | 地図から一覧へ切り替える |
| CS-03 | — | 選択エリアも現在地もない状態で、下部ナビゲーションから開く。現在地の利用を始めたが、許可しない、端末で無効、または現在地を取得できない |
| CS-09（範囲と条件に合う対象がない） | 店舗も地域もない。地図を動かす（一覧では地図へ戻って範囲を変える）、条件の変更（VW-02）と解除（CF-03）へ進める | 再検索の結果がない |
| CS-01 | — | 開く。続きを読み込む |
| CS-02 | 再検索で起きた場合は、前の結果を保つ。VW-05 など別の探索手段へ進める | 地図または対象の取得が通信エラーで成立しない |

## VW-05 まち

- 目的: 選択エリアまたは周辺の地域を一覧から選ぶ
- シナリオ: EXP-03、DIS-04、DIS-06
- 入口: 下部ナビゲーション「まち」

### 機能

- 地域を、写真・名称・所在地で一覧に示す。地域の一覧は発見の場面に当たる。現在地を利用していれば現在地に近い順、利用していなければ新しい順に並べ、続きを読み込む（CF-05）
- 地域を選ぶと、DT-03 を開く
- 選択中の条件を確かめ、解除する（CF-03）。絞り込み（VW-02）へ進む。この画面にはエリアの条件だけが効く
- 現在地の利用を始める
- 下部ナビゲーションからマップ（VW-04）へ進むと、地図で地域を探せる

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 選択エリアの地域 | 選択エリアにある地域を示す（index.md の「公開中の対象の状態」が引く「地域の判定」） | エリアを選択中に開く。VW-02 でエリアを適用する |
| 周辺の地域 | 現在地の周辺にある地域を示す（同じく「地域の判定」） | エリアを選択せず、現在地を利用している状態で開く。現在地の利用を始めて許可する |
| すべての地域 | 公開中の地域を新しい順に示す。位置情報未許可であることは示さない | エリアを選択せず、位置情報の利用も許可していない状態で開く。許可を取り消した後に開く場合を含む |
| CS-03 | すべての地域の表示を続ける | 現在地の利用を始めたが、許可しない、端末で無効、または現在地を取得できない |
| CS-09（地域がない） | 選択エリアまたは周辺に地域がない。エリアの変更（VW-02）と解除（CF-03）、VW-04 へ進める | 表示する地域がない |
| CS-01 | — | 開く。条件または現在地の状態が変わる。続きを読み込む |
| CS-02 | — | 取得が通信エラーで成立しない |

## VW-06 地域内の一覧

- 目的: 1つの地域に所属する店舗と、その掲載を一覧で見る
- シナリオ: EXP-05
- 入口: DT-03

### 機能

- 店舗の一覧と掲載の一覧を持ち、切り替える。DT-03 で選んだ側の一覧で開く。どちらも発見の場面に当たる
- 店舗の一覧は、その地域に所属する店舗を、所属した日時の新しい順に示す
- 掲載の一覧は、その地域に所属する店舗の掲載を、新しい順に示す
- 店舗と掲載の地域名には、その地域を示す
- 選択中のエリア・カテゴリーの条件は効かない。選択中の条件の表示を持たない
- 続きを読み込む（CF-05）
- 店舗は DT-02、掲載は DT-01 を開く。DT-03 へ戻る

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 店舗の一覧 | 所属する店舗を示す | DT-03 の店舗の区分から開く。掲載の一覧から切り替える |
| 掲載の一覧 | 所属する店舗の掲載を示す | DT-03 の掲載の区分から開く。店舗の一覧から切り替える |
| CS-09（地域に閲覧できる掲載がない） | 掲載の一覧に示す掲載がない。店舗の一覧と DT-03 へ進める | 掲載の一覧を開いた時点で掲載がない |
| CS-06 | VW-05 など他の探索へ進める | 開いた時点で、地域が閲覧できなくなっている |
| CS-01 | — | 開く。一覧を切り替える。続きを読み込む |
| CS-02 | — | 取得が通信エラーで成立しない |

## VW-08 参加店舗マップ

- 目的: 1つのイベントの参加店舗の位置を地図で確かめる
- シナリオ: EXP-10
- 入口: DT-04

### 機能

- そのイベントのすべての参加店舗を、所在地の位置に示す。参加店舗の地図は参照の場面に当たる。エリア・カテゴリーの条件と、位置情報の許可は表示に効かない
- 初めの範囲、ピンのまとめ方、まとめたピンを選んだときの拡大は、index.md の「地図」に従う。地図を動かす・縮尺を変える操作では読み直さない（再検索を持たない）
- 店舗を選ぶと、写真・名称・所在地と店舗の状態を、概要として示す。概要から DT-02 を開き、所属地域をたどれる
- DT-04 へ戻る

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 地図の表示 | すべての参加店舗を地図に示す | DT-04 から開く |
| 店舗を選択中 | 選んだ店舗の概要を示す | 店舗のピンを選ぶ。同じ位置の店舗の一覧から店舗を選ぶ。別の店舗を選ぶか、選択をやめると終わる |
| 同じ位置の店舗を選択中 | 同じ位置にある参加店舗の一覧を示す（index.md の「地図」） | 同じ位置の店舗だけのまとまりを選ぶ。一覧から店舗を選ぶか、選択をやめると終わる |
| CS-09（参加店舗がない） | DT-04 へ戻れる | 開いた時点で、表示できる参加店舗がない |

## VW-10 保存

- 目的: 保存した掲載と店舗を見返し、保存を解除する
- シナリオ: KEP-02、KEP-03、KEP-04
- 入口: 下部ナビゲーション「保存」

### 機能

- 保存した掲載と店舗を、種類を区別して、保存した日時の新しい順に示す。ログインしていない間は端末の保存を、ログインしている間はアカウントの保存を示す
- 掲載は写真・名称・店舗の名称・地域名で、店舗は写真・名称で示す。保存一覧は参照の場面に当たる
- 続きを読み込む（CF-05）
- 掲載は DT-01、店舗は DT-02 を開く。位置は、DT-02 の地図で確かめる
- 対象の保存を解除する（CF-04）。解除した対象は、一覧を開き直すまで解除済みとして同じ行に残り、その行で保存し直せる。開き直すと、一覧からなくなる。保存し直した保存の日時は `spec/scenario/keep.md` の共通の規則による。一覧を開き直すまでは同じ行に示し、開き直すとその日時の順に並ぶ
- 閲覧できない保存は、詳細を開けず、解除と、解除済みの行での保存し直しだけを行える。解除しなければ保存は残り、対象が再び公開されると閲覧できる保存に戻る
- DT-01・DT-02・VW-01 で保存・解除した結果は、この画面に戻ると反映されている
- ログインしていない間は、端末のデータを消去すると保存が失われることと、ログインすると保存をアカウントに引き継げることを案内する。案内からログイン（MY-02）へ進む
- ログインが成立すると、端末の保存がアカウントの保存に合流した一覧を示す。閲覧者に確認は求めない。合流は取り消せず、不要な保存は個別に解除する

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 端末の保存 | 端末の保存と、データ消去・引き継ぎの案内を示す | ログインせずに開く |
| アカウントの保存 | アカウントの保存を示す。案内は示さない | ログインして開く。MY-02 でログインが成立して戻る |
| 閲覧できない保存を含む | 閲覧できない保存を、閲覧できる保存と区別して示す | 保存した対象が閲覧できなくなっている |
| 解除済みの行を含む | 解除した対象を、解除済みとして同じ行に示す。その行で保存し直せる | この画面で保存を解除する。一覧を開き直すと終わる |
| 引き継ぎの未了 | 端末の保存は失われずに残る。通信エラーを示し、再試行で引き継ぎを行う | ログインは成立したが、引き継ぎが通信エラーで成立しない |
| CS-09（保存がない） | 探索（VW-01、VW-03、VW-04、VW-05、VW-09）へ進める。ログインしていなければ、ログインして別の端末の保存を見返せることを案内する（MY-02） | 保存が1件もない |
| CS-01 | — | 開く。続きを読み込む |
| CS-02 | VW-01 など別の探索へ進める | 保存の取得が通信エラーで成立しない。ログインしていない間の端末の保存も、保存した対象の内容と閲覧できるかどうかの取得で当たる |
