# イベント運営（EM）

イベントの運営者が、管理する1つのイベントの参加店舗・申請・イベント情報・開催地域を扱う画面を定める。画面の一覧、ナビゲーション、共通の状態（CS）、共通の機能（CF）、状態の示し方は [index.md](index.md) が定める。

- EM の画面は、1つのイベントだけを扱う。対象のイベントは、開いた入口が指すイベントに決まる（index.md の「地域運営・イベント運営の管理ナビゲーション」）
- メンバーの管理は CM-02、申請の判断は CM-01、参加内容の編集は CM-04 が負う。EM の画面は入口だけを持つ
- 運営者が不在のイベントでは、サービス運営者が同じ画面を不在の代行で開き、各画面の機能と状態が同じく当てはまる。不在の代行の規則と入口（OM-02 と通知）は、index.md の「サービス運営者の不在の代行」「通知から開く画面」と CS-14・CS-15 による

EM-01 と EM-02 は、[region.md](region.md) の RM-01・RM-02 の機能と状態を、次の読み替えで持つ。EM-01・EM-02 の節は、読み替えで持つものを繰り返さず、入力する項目の違いと、イベントだけが持つ機能と状態だけを書く。

| RM-01・RM-02 の語 | EM-01・EM-02 での語 |
| --- | --- |
| 地域、地域運営者、地域の運営者 | イベント、イベント運営者、イベントの運営者 |
| 所属、所属店舗、所属中 | 参加、参加店舗、参加中 |
| 所属・離脱の申請 | 参加の申請 |
| 離脱の承認 | 参加の取りやめ |
| 他の地域への所属 | 他のイベントへの参加 |

| DT-03 | DT-04 |

## EM-01 参加店舗と申請

- 目的: イベントの参加店舗・参加の申請・参加内容を確かめ、店舗を除外する
- シナリオ: EVT-07、EVT-09
- 入口: MY-01 の管理するイベント、招待の承諾の後（MY-06）、管理ナビゲーション「参加店舗と申請」、OM-02（不在の代行）、通知（index.md の「通知から開く画面」）

### 機能

RM-01 の機能を読み替えで持つ。加えて、次を持つ。

- 参加の申請は種類（所属・離脱）を持たない。申請ごとに、添えた掲載と参加日を示す
- 参加店舗の除外は、店舗管理者の有無と、参加が成立した経緯、イベントの開催の状態にかかわらず行える
- 参加店舗ごとに、添えた掲載と参加日、店舗管理者がいるかどうかを示す。添えた掲載から DT-01 へ進める。提供終了になった掲載は状態を区別して示し、閲覧できなくなった掲載は状態とともに示す（index.md の「管理する対象の状態」）。開催期間の外になった参加日は、それと分かるように示す
- 管理者のいない店舗の追加を始め、CM-04 へ進む。管理者のいない参加店舗の参加内容を選び、CM-04 へ進んで変更する。どちらも、イベントの開催の状態にかかわらず行える。管理者のいる店舗の参加内容は変更できない
- 参加の取りやめと参加内容の変更の通知から開くと、その店舗の現在の参加内容を示す

### 状態

RM-01 の状態を読み替えで持つ（CS-17 を含む）。加えて、次を持つ。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| CS-09 空 | RM-01 の内容に加えて、管理者のいない店舗の追加へ進める | 参加店舗または申請が1件もない |
| CS-08 参加していない | 通知から開いた店舗の参加が、取りやめまたは別の運営者の除外で、すでに解除されている。最新の参加店舗を示す | 通知から開いた時点で参加がない |

## EM-02 イベント情報の編集

- 目的: イベントの情報を登録・編集して保存し、公開し、公開を取り下げ、中止にし、中止を取り消す
- シナリオ: EVT-04、EVT-06、EVT-11、EVT-12、MOD-03
- 入口: 管理ナビゲーション「イベント情報」、OM-02（登録）、通知（index.md の「通知から開く画面」）

### 機能

RM-02 の機能を読み替えで持つ。入力する項目は、名称・開催期間・開催場所（所在地・位置）・写真・紹介・キャッチコピー。開催場所の所在地は CF-07、位置は CF-09、写真は CF-01 による。関連する地域は EM-03 が負う。加えて、次を持つ。

- 延期は、開催期間を変更して保存することで行う。保存の後、開催期間と日付から決まる開催の状態を示す
- イベントを中止にする。確定の前に結果を確かめる（CS-12）
- 中止中のイベントの中止を取り消す。開催の状態は、開催期間と日付から決まる状態に戻る。取り消した後に、再び中止にできる。中止の取り消しは、確定の前の確認（CS-12）を持たない
- 中止と中止の取り消しは、開催の状態（開催前・開催中・終了）にも、公開状態にも、運営による非公開にもかかわらず行える。新規の状態では行えない

### 状態

RM-02 の状態を読み替えで持つ（CS-17 を含む）。公開状態と開催の状態は独立していて、併せて示す。加えて、次を持つ。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 開催前・開催中・終了 | 中止にできる。終了したイベントは、開催期間を未来へ変更して保存すると、開催前または開催中に戻る | 開催期間と日付から決まる。中止の取り消しが成立する |
| 中止 | 中止を取り消せる。開催期間を変更して保存しても、中止のまま | 中止が成立する |
| CS-10 開催期間の誤り | 終了日が開始日より前で、保存できない | 保存の時点で開催期間が誤っている |
| CS-12 中止の確認 | イベントがフィードとイベントの一覧と関連するイベントに表示されなくなること、参加は保たれること、確認中・差し戻し中の参加申請が失効して中止を取り消しても戻らないことを示す | 中止を始める |
| CS-13 完了 | 中止・中止の取り消しの成立も、保存・公開・取り下げと同じく示す | 中止・中止の取り消しが成立する |
| CS-08 開催の状態の変化 | 別の運営者がすでに中止にしている、または中止を取り消している。現在の開催の状態を示す | 中止・中止の取り消しの時点で前提がない |

## EM-03 開催地域の関連づけ

- 目的: イベントに開催地域を関連づけ、関連づけを外し、地域の運営者が解除した地域を関連づけ中の地域と区別して確かめる
- シナリオ: EVT-05
- 入口: 管理ナビゲーション「開催地域」、通知（index.md の「通知から開く画面」）

### 機能

- 関連づけている地域を一覧で確かめる。各地域から DT-03 へ進める
- 未公開または運営による非公開で閲覧できない地域との関連づけは、地域の状態とともに示す。関連づけを外す操作は、閲覧できる地域と同じく行える
- 公開中の地域を探して選び（CF-02）、関連づける。候補は公開中の地域とする。複数の地域を関連づけられる。地域の運営者の承認は要らず、選んだ時点で反映する
- 関連づけた地域を外す。外した地域は、あらためて関連づけられるので、確定の前の確認（CS-12）を持たない
- 地域の運営者が関連づけを解除した地域を、関連づけ中の地域と区別して示す。再び関連づけられないことと、地域の運営者が解除を取り消すと関連づけが回復することを示す
- CF-02 の候補では、関連づけ済みの地域と、地域の運営者が解除した地域を、選べない理由とともに示す

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-06、CS-08、CS-09、CS-13、CS-17 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | 関連づけ中の地域と、地域の運営者が解除した地域を区別して示す。閲覧できない地域は、その状態とともに示す | 画面を開く |
| CS-09 空 | 関連づけている地域がないことを示し、地域の選択へ進める | 関連づけ中の地域も解除された地域もない |
| CS-13 関連づけの完了 | 選んだ地域が関連づけ中に加わったことを示す。外せる | 関連づけが成立する |
| CS-13 外した完了 | 地域が一覧から外れたことを示す | 関連づけを外す操作が成立する |
| CS-06 関連づけられない | 選んだ地域が閲覧できない。関連づけを反映しない | 関連づけの時点で、地域が公開の取り下げまたは運営による非公開になっている |
| CS-08 関連づけの変化 | 関連づけようとした地域が関連づけ済み、または地域の運営者が解除済み。外そうとした関連づけがすでにない。最新の一覧を示す | 関連づけ・外す操作の時点で前提がない |
| CS-17 対象がない | RM-01 の CS-17 を読み替えで持つ | 存在しないイベントを開く |
