# イベント運営（EM）

イベント運営者が、管理する1つのイベントの参加店舗・申請・イベント情報・開催地域を扱う画面を定める。画面の一覧、ナビゲーション、共通の状態（CS）、共通の機能（CF）、状態の示し方は [index.md](index.md) が定める。

- 対象のイベントは MY-01 で選ぶ。EM の画面は、選んだ1つのイベントだけを扱う
- メンバーの管理は CM-02、申請の判断は CM-01、参加内容の編集は CM-04 が負う。EM の画面は入口だけを持つ
- 運営者が不在のイベントでは、サービス運営者が OM-03 から同じ画面を代行で開く（EVT-13）。各画面の機能と状態は、代行するサービス運営者にも同じく当てはまる。代行の規則は index.md の「サービス運営者の代行」による。運営者が不在のイベントについてのイベント運営者宛ての通知は、サービス運営者に届いて OM-03 を開き、EM の画面を直接は開かない
- EM-01・EM-02 は、RM-01・RM-02 と同じ機能と状態に、イベントだけが持つものを加えて持つ。イベントだけが持つ機能と状態は、その旨を示す

## EM-01 参加店舗と申請

- 目的: イベントの参加店舗・参加の申請・参加内容を確かめ、店舗を除外する
- シナリオ: EVT-07、EVT-09、EVT-13
- 入口: MY-01 の管理するイベント、招待の承諾の後（MY-06）、管理ナビゲーション「参加店舗と申請」、OM-03（代行）、管理権限の付与・参加の取りやめ・参加内容の変更の通知

### 機能

- 参加中の店舗を、参加の新しい順の一覧で確かめる。店舗の状態は index.md の「管理する対象の状態」のとおり示す。各店舗から DT-02 へ進める
- 参加の申請を一覧で確かめる。申請ごとに、対象の店舗、申請者、添えた掲載と参加日、状態を示す。確認中と差し戻しの申請を先に、提出の新しい順に並べる。示し方は index.md の「申請の状態」による。確認中の申請の件数を示す
- 確認中の申請を選び、CM-01 へ進んで判断する。この画面は判断の操作を持たない
- 参加店舗を選んで除外する。理由は求めない。店舗管理者の有無と、参加が成立した経緯、イベントの開催の状態にかかわらず除外できる。確定の前に結果を確かめる（CS-12）
- 参加店舗の情報と掲載を更新する操作は持たない
- イベントだけが持つ機能
  - 参加店舗ごとに、添えた掲載と参加日、店舗管理者がいるかどうかを示す。添えた掲載から DT-01 へ進める。提供終了になった掲載は状態を区別して示し、開催期間の外になった参加日は、それと分かるように示す
  - 店舗管理者のいない店舗の追加を始め、CM-04 へ進む。店舗管理者のいない参加店舗の参加内容を選び、CM-04 へ進んで変更する。どちらも、イベントの開催の状態にかかわらず行える。店舗管理者のいる店舗の参加内容は変更できない
  - 参加の取りやめと参加内容の変更の通知から開くと、その店舗の現在の参加内容を示す

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-08、CS-09、CS-12、CS-13 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | 参加店舗と申請を示す | 画面を開く |
| CS-09 空 | 参加店舗がないことと、申請がないことを、別々に示す。店舗管理者のいない店舗の追加へ進める | 参加店舗または申請が1件もない |
| CS-12 除外の確認 | 参加が解除されること、店舗と掲載の公開状態・提供状態は変わらないこと、除外は取り消せないことを示す | 参加店舗の除外を始める |
| CS-13 除外の完了 | 店舗が参加店舗から外れたことを示す | 除外が成立する |
| CS-08 参加していない | 除外しようとした店舗、または通知から開いた店舗の参加が、取りやめまたは別の運営者の除外で、すでに解除されている。最新の参加店舗を示す | 除外の確定の時点、または通知から開いた時点で参加がない |
| 代行中 | サービス運営者が開いている。管理ナビゲーションが代行中であることを示し、OM-03 へ戻れる | OM-03 から開く |
| 代行できない | イベントにイベント運営者が就いた。操作を反映しない | 代行の操作の確定の時点でイベント運営者がいる |

## EM-02 イベント情報の編集

- 目的: イベントの情報を登録・編集して保存し、公開し、公開を取り下げ、中止にし、中止を取り消す
- シナリオ: EVT-04、EVT-06、EVT-11、EVT-12、EVT-13、MOD-03
- 入口: 管理ナビゲーション「イベント情報」、OM-02（登録）、イベントの非公開と写真の削除の通知

### 機能

- 名称・開催期間・開催場所（所在地・位置）・写真・紹介・キャッチコピーを入力して保存する。開催場所の所在地は CF-07、写真は CF-01 による。位置は1点で指定する。関連する地域は EM-03 が負う
- サービス運営者は、OM-02 から新規の状態で開いてイベントを登録する。保存すると、イベントは下書きとして登録される。登録したイベントは運営者が不在のイベントになり、以後は代行で開く。管理ナビゲーションの「メンバー」（CM-02）から管理権限を付与する
- 公開状態の操作は CF-08 による。下書きまたは公開を取り下げたイベントを公開し、公開中のイベントの公開を取り下げる。イベント運営者がいなくても公開できる
- 参加店舗の情報と掲載を更新する操作は持たない
- イベントだけが持つ機能
  - 延期は、開催期間を変更して保存することで行う。保存の後、開催期間と日付から決まる開催の状態を示す
  - イベントを中止にする。確定の前に結果を確かめる（CS-12）
  - 中止中のイベントの中止を取り消す。開催の状態は、開催期間と日付から決まる状態に戻る。取り消した後に、再び中止にできる。中止の取り消しは、確定の前の確認（CS-12）を持たない
  - 中止と中止の取り消しは、開催の状態（開催前・開催中・終了）にも、公開状態にも、運営による非公開にもかかわらず行える

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-07、CS-08、CS-10〜CS-13 が当てはまる。この画面に固有の内容を持つものを表に書く。公開状態と開催の状態は独立していて、併せて示す。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 新規 | 入力が空の状態で始まる。サービス運営者だけが開ける。公開と中止の操作は持たない。保存せずにやめると、イベントは登録されない | OM-02 の新しい登録から開く |
| 下書き | 保存と公開を示す | 新規の保存が成立する。または下書きのイベントを開く |
| 公開 | 保存と公開の取り下げを示す | 公開が成立する。または公開中のイベントを開く |
| 公開の取り下げ | 保存と公開を示す | 取り下げが成立する。または取り下げたイベントを開く |
| 運営による非公開 | CF-08 による。中止と中止の取り消しは行える | サービス運営者が OM-03 で非公開にする、解除する |
| 写真の削除による公開の取り下げ | CF-08 による | 写真の削除の通知から開く。または該当するイベントを開く |
| 開催前・開催中・終了（イベントだけ） | 中止にできる。終了したイベントは、開催期間を未来へ変更して保存すると、開催前または開催中に戻る | 開催期間と日付から決まる。中止の取り消しが成立する |
| 中止（イベントだけ） | 中止を取り消せる。開催期間を変更して保存しても、中止のまま | 中止が成立する |
| CS-10 公開条件の不足 | CF-08 による | 公開の操作、または公開中のイベントの保存で条件を欠く |
| CS-10 開催期間の誤り（イベントだけ） | 終了日が開始日より前で、保存できない | 保存の時点で開催期間が誤っている |
| CS-12 取り下げの確認 | イベントがどの場面にも表示されなくなること、参加店舗と添えた掲載の関連するイベントとしても表示されなくなること、参加関係と開催地域の関連づけは保たれることを示す | 公開の取り下げを始める |
| CS-12 中止の確認（イベントだけ） | イベントがフィードとイベントの一覧と関連するイベントに表示されなくなること、参加は保たれること、確認中・差し戻し中の参加申請が失効して中止を取り消しても戻らないことを示す | 中止を始める |
| CS-13 完了 | 保存・公開・取り下げ・中止・中止の取り消しが成立したことを示す。公開中のイベントは DT-04 へ進める | 左の操作が成立する |
| CS-08 公開状態の変化 | 別の運営者がすでに公開している、または公開を取り下げている。現在の公開状態を示す | 公開・取り下げの時点で前提がない |
| CS-08 開催の状態の変化（イベントだけ） | 別の運営者がすでに中止にしている、または中止を取り消している。現在の開催の状態を示す | 中止・中止の取り消しの時点で前提がない |
| 代行中 | EM-01 と同じ | OM-03 または OM-02 から開く |
| 代行できない | EM-01 と同じ | 保存・公開・取り下げ・中止・中止の取り消しの時点でイベント運営者がいる |

## EM-03 開催地域の関連づけ

- 目的: イベントに開催地域を関連づけ、関連づけを外し、地域の運営者が解除した地域を関連づけ中の地域と区別して確かめる
- シナリオ: EVT-05、EVT-13
- 入口: 管理ナビゲーション「開催地域」、関連づけの解除の通知

### 機能

- 関連づけている地域を一覧で確かめる。各地域から DT-03 へ進める
- 公開の取り下げ中または運営による非公開で閲覧できない地域との関連づけは、地域の状態とともに示す。関連づけを外す操作は、閲覧できる地域と同じく行える
- 公開中の地域を探して選び（CF-02）、関連づける。候補は公開中の地域とする。複数の地域を関連づけられる。地域の運営者の承認は要らず、選んだ時点で反映する
- 関連づけた地域を外す。外した地域は、あらためて関連づけられるので、確定の前の確認（CS-12）を持たない
- 地域の運営者が関連づけを解除した地域を、関連づけ中の地域と区別して示す。再び関連づけられないことと、地域の運営者が解除を取り消すと関連づけが回復することを示す
- CF-02 の候補では、関連づけ済みの地域と、地域の運営者が解除した地域を、選べない理由とともに示す

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-06、CS-08、CS-09、CS-13 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | 関連づけ中の地域と、地域の運営者が解除した地域を区別して示す。閲覧できない地域は、その状態とともに示す | 画面を開く |
| CS-09 空 | 関連づけている地域がないことを示し、地域の選択へ進める | 関連づけ中の地域も解除された地域もない |
| CS-13 関連づけの完了 | 選んだ地域が関連づけ中に加わったことを示す。外せる | 関連づけが成立する |
| CS-13 外した完了 | 地域が一覧から外れたことを示す | 関連づけを外す操作が成立する |
| CS-06 関連づけられない | 選んだ地域が、公開の取り下げまたは運営による非公開で閲覧できなくなった。関連づけを反映しない | 関連づけの時点で地域を閲覧できない |
| CS-08 関連づけの変化 | 関連づけようとした地域が関連づけ済み、または地域の運営者が解除済み。外そうとした関連づけがすでにない。最新の一覧を示す | 関連づけ・外す操作の時点で前提がない |
| 代行中 | EM-01 と同じ | OM-03 から開く |
| 代行できない | EM-01 と同じ | 関連づけ・外す操作の時点でイベント運営者がいる |
