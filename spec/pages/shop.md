# 店舗管理（SM）

店舗管理者が、管理する店舗の情報・営業状況・掲載と、地域・イベントとの関係を管理する。画面の一覧、管理ナビゲーション、サービス運営者の不在の代行、共通の状態（CS）、共通の機能（CF）、状態の示し方は [index.md](index.md) が定める。

SM の画面は、1つの店舗を対象にする。対象の店舗は、開いた入口が指す店舗に決まり、管理ナビゲーションの店舗の切り替えで変える（index.md の「店舗側の管理ナビゲーション」）。店舗が非公開の間の示し方は、index.md の「管理する対象の状態（管理側）」に従う。

## SM-01 店舗ホーム

- 目的: 選んだ店舗の、店舗・掲載・対応が必要なことの状況を確かめる
- シナリオ: SHP-05、APP-06、MOD-06
- 入口: MY-01 の管理する店舗、DT-02（index.md の「詳細の手続きの入口」）、管理ナビゲーションの店舗の切り替え、管理権限の承認と招待の承諾の後、通知（index.md の「通知から開く画面」）

### 機能

- 選んだ店舗の名称、写真、営業状況、店舗が非公開かどうかを示す
- 掲載の件数を、SM-03 の区分（公開中・下書き・非公開・提供終了）ごとに示す。それぞれ、その区分に絞った SM-03 へ進める
- 対応が必要なことを、種類ごとの件数とともに示す
  - 店舗管理者として行った申請のうち、差し戻しの申請。別の店舗管理者が出した申請を含む。MY-05 へ進める
  - 確認依頼中の確認の依頼。SM-07 へ進める
- その店舗の店舗管理者として行ったすべての申請は、MY-04 の店舗の申請で確かめる。MY-04 へ進める
- 掲載の追加（SM-04）、店舗情報と営業状況（SM-02）、所属地域の状況（SM-05）、イベントの状況（SM-06）、メンバーの管理（CM-02）へ進める
- 閲覧者に見える店舗の詳細（DT-02）へ進める

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 店舗の状況 | 選んだ店舗の状況を示す | MY-01・DT-02・管理ナビゲーションの店舗の切り替え・通知から開く |
| 対応が必要なことがない | 対応が必要なことがないことを示す | 差し戻しの申請も、確認依頼中の依頼もない |
| 店舗が非公開 | 店舗が非公開であることと、店舗管理者は解除できないことを示す | サービス運営者が店舗を非公開にする |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-09。店舗の管理権限を持たない利用者が開いた場合は CS-05 に当たる。管理する店舗が1つもない利用者は、MY-01 に店舗の入口がなく、「店舗を登録・管理する」（RQ-01）から始める。

## SM-02 店舗情報

- 目的: 店舗の情報と営業状況を、申請なしで登録・更新する
- シナリオ: SHP-06、SHP-07、SHP-12、SHP-13、MOD-06
- 入口: 管理ナビゲーション「店舗情報」、OM-02（代理登録と不在の代行）、OM-05（不在の代行）、SM-07、通知（index.md の「通知から開く画面」）

### 機能

- 名称、写真（CF-01）、紹介、所在地、位置、営業時間、連絡先を編集して保存する。承認を求めず、保存した時点で閲覧者への表示に反映する
- 公開条件は CF-08 による。店舗は公開状態の操作を持たず、公開条件を欠く内容は保存しない（CS-10）
- 所在地は CF-07、位置は CF-09 で入力する。店舗とその掲載のエリアは、保存した所在地の町域で決まる
- 現在の営業状況（営業中・休業・閉店）を示す。営業状況は、情報の保存とは別の操作で、営業中・休業・閉店のどれへも変える。休業・閉店への変更は、確定の前に、変更後の閲覧者への見え方を示す（CS-12）。確定した時点で反映する
- 所属地域の変更を持たない。所属地域の状況（SM-05）へ進める
- メンバーの管理（CM-02）と、閲覧者に見える店舗の詳細（DT-02）へ進める
- 店舗を非公開にする操作と、削除する操作を持たない。Lunt への掲載をやめる店舗管理者には、DT-02 からの取り下げの申立て（RQ-07）を案内する
- 保存した内容を元に戻す操作を持たない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 編集 | 店舗の現在の情報と営業状況が入った状態で始まる | 店舗管理者が開く |
| 新規（代理登録） | 空の内容で始まる。情報を入力して登録する。登録した店舗は、管理者のいない店舗として公開される。登録の後、その店舗の不在の代行（CS-14）の編集と、掲載の一覧（SM-03）、OM-03 へ進める | サービス運営者が、OM-02 で既存の店舗にないことを確かめて開く |
| 営業状況の確認 | 休業は、店舗と掲載が休業中として表示され、掲載がフィードの対象のままであることを示す。閉店は、店舗と掲載が表示されなくなる場面と、閉店として表示される場面を示す。掲載の公開状態と提供状態は変わらないことを示す（CS-12） | 休業・閉店への変更を選ぶ |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-07、CS-10、CS-11、CS-12、CS-13、CS-16。CS-05 は、その店舗の店舗管理者でない利用者がたどり着いた場合に当たり、店舗の DT-02 へ進める。管理者のいない店舗なら、情報修正と営業状況の変更の申請（RQ-02）へ、管理者のいる店舗なら、情報の誤り・閉店の連絡（RQ-08）へ進める（SHP-06、SHP-07）。

## SM-03 掲載の一覧

- 目的: 店舗の掲載を公開状態と提供状態の別に確かめ、掲載を選ぶ
- シナリオ: LST-04、LST-05、LST-11、LST-16
- 入口: 管理ナビゲーション「掲載」、SM-01、SM-07、OM-02・OM-05（不在の代行）、通知（index.md の「通知から開く画面」）

### 機能

- 店舗のすべての掲載を、写真・名称・カテゴリー・公開状態・提供状態とともに示す。代理作成された掲載、申請の承認で公開された掲載、店舗管理者のいなかった時期の下書きを含む
- 表示する掲載を、公開中・下書き・非公開・提供終了の区分で切り替える。公開中・下書き・非公開は公開状態で分け、運営による非公開の掲載は、重なる公開状態にかかわらず非公開に入る。非公開は、一時非公開と運営による非公開を区別して示す。一時非公開のうち、申立てによる写真の削除で公開条件を欠いて公開していない状態になった掲載（`reason` が `photoTakedown`）は、そのことが分かるように示す（写真を変えて保存すれば再公開できる。SM-04 の CS-16）。提供終了は提供状態で分け、公開状態の区分と重なる（公開中かつ提供終了の掲載は、公開中と提供終了の両方に入る）。提供開始前の掲載は、それと分かる
- 掲載を選んで、SM-04 へ進める。公開中の掲載は、閲覧者に見える DT-01 へも進める
- 掲載の追加（SM-04 の新規）へ進める
- 公開状態と提供状態を変える操作、複製、削除を持たない。SM-04 が持つ
- 一覧は続きを読み込む（CF-05）

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | すべての掲載、または選んだ区分の掲載を示す | 開く。区分を切り替える。SM-01 から区分に絞って開く |
| 掲載がない | 店舗に掲載が1件もないことを示し、掲載の追加へ進める（CS-09） | 掲載のない店舗で開く |
| 当てはまる掲載がない | 選んだ区分に当てはまる掲載がないことを示す。別の区分へ切り替えられる（CS-09） | 掲載のない区分を選ぶ |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-09。

## SM-04 掲載の編集

- 目的: 1件の掲載の内容を作成・編集して保存し、公開状態と提供状態を変え、複製・削除する
- シナリオ: LST-01、LST-02、LST-03、LST-04、LST-06、LST-07、LST-08、LST-09、LST-10、LST-11、LST-15、LST-16、MOD-03、MOD-06
- 入口: SM-03、SM-01 の掲載の追加、SM-07、CM-03、OM-02・OM-05（不在の代行）、通知（index.md の「通知から開く画面」）

### 機能

- 名称、説明、カテゴリー、写真、提供の設定を編集する。価格とキャッチコピーの入力を持たない
- 紐づく店舗と、店舗情報から引いた所在地・所属地域を示す。掲載では入力しない
- カテゴリーは、現役のカテゴリー（`spec/scenario/listing.md` の「掲載の内容」）から1つを選ぶ
- 写真は CF-01 による。写真ごとに、閲覧者に見せる範囲を調整する
- 提供の設定は CF-06 による。開催日は追加と削除ができ、時刻・定員・予約の項目を持たない
- 現在の提供状態（提供開始前・提供中・提供終了）を示す。提供状態は、提供期間・開催日・店舗管理者による提供終了と、今日の日付から決まる
- 保存する。下書きは、店舗への紐づけだけで保存できる。保存で提供状態が変わる場合は、変わった後の提供状態を示す
- 公開状態の操作は CF-08 による。下書きを公開し、公開中の掲載を一時非公開にし、一時非公開の掲載を再公開する。公開と再公開は、公開前の確認（CM-03）を経ずに行える
- 下書きと一時非公開の掲載は、公開前の確認（CM-03）へ進める。公開の操作は CM-03 と共有する
- 公開中の掲載を提供終了にする（CS-12）。店舗管理者が提供終了にした掲載を、公開状態を問わず（一時非公開の掲載を含む）提供中に戻す
- 複製する。公開状態と提供状態を問わず、運営による非公開の掲載も複製できる。名称・説明・カテゴリー・写真（並び順と見せる範囲を含む）を引き継ぎ、提供期間と開催日を引き継がない新しい下書きが、同じ店舗の掲載としてできる。元の掲載は変わらない。できた下書きの SM-04 へ進む
- 削除する。公開状態と提供状態を問わない。復元できないことを示して確かめる（CS-12）。削除が成立すると SM-03 へ戻る
- 公開中の掲載は、閲覧者に見える DT-01 と DT-02 へ進める
- 保存した内容を元に戻す操作を持たない

### 状態

公開状態と提供状態は独立していて、重なる。各状態の行は、その軸で示す操作だけを書く。保存・複製・削除は、新規を除くどの状態でも示す。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 新規 | 店舗に紐づいた空の内容で始まる。保存のほかの操作は示さない。保存すると下書きになり、同じ画面のまま公開前の確認と公開へ進める（LST-04） | SM-03・SM-01 の掲載の追加から開く。OM-02 の管理者のいない店舗の掲載の追加から、不在の代行で開く |
| 下書き（公開状態） | 公開前の確認と公開を示す。閲覧者には表示されない | 新規の保存。複製 |
| 公開（公開状態） | 一時非公開を示す | 公開、再公開が成立する |
| 一時非公開（公開状態） | 公開前の確認と再公開を示す | 一時非公開が成立する。申立てによる写真の削除で写真がなくなる |
| 運営による非公開（公開状態に重なる） | CF-08 による。公開・一時非公開・再公開を示さない。提供状態の操作は、重なる公開状態に従って示す。複製でできる掲載は、運営による非公開ではない下書きになる | サービス運営者が運営による非公開にする、解除する |
| 提供開始前・提供中（提供状態） | 公開状態が公開の掲載に、提供終了にする操作を示す（CS-12） | 提供期間・開催日と今日の日付から決まる。提供中に戻す |
| 提供終了（店舗管理者による。提供状態） | 提供中に戻す操作を、重なる公開状態を問わず示す。終了日または最後の開催日を過ぎている掲載は、戻しても提供終了のままであることを示し、提供期間・開催日の変更へ案内する | 提供終了にする |
| 提供終了（自動。提供状態） | 提供中に戻す操作を示さない。提供期間を更新するか外す、または開催日を追加すると提供中に戻ることを示す | 終了日または最後の開催日を過ぎる |
| CS-17 対象がない | 掲載が削除されていることを示し、SM-03 へ戻れる | 削除された掲載を開く。保存・複製・状態の操作の時点で掲載が削除されている |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-07、CS-08、CS-10、CS-11、CS-12、CS-13、CS-16、CS-17。次の場合は CS-10 に当たる。

- 公開・再公開と、公開中の掲載の保存で、公開条件を欠く（CF-08）
- 提供の設定が、CF-06 の保存できない内容になっている

別の管理者が先に保存した掲載の保存は CS-07 に当たる。公開状態・提供状態を別の管理者が先に変えていた場合と、選んだカテゴリーが保存までに廃止されていた場合は CS-08 に当たる。廃止の場合は、現役のカテゴリーから選び直す。不在の代行で保存した下書きは、店舗に店舗管理者が就くと、店舗管理者の管理下に入る。

## SM-05 所属地域の状況

- 目的: 店舗の所属中・申請中の地域を確かめ、代表地域を選び、所属と離脱の申請へ進む
- シナリオ: REG-01、REG-02、REG-04、REG-05
- 入口: SM-01、SM-02、通知（index.md の「通知から開く画面」）

### 機能

- 所属中の地域を示す。店舗管理者のいなかった時期に成立した所属を含む。公開を取り下げた地域と、運営による非公開の地域は、その状態と、閲覧者には所属地域として表示されていないことを示す
- 現在の代表地域を示す。代表地域の決まり方と、閲覧者に表示されていない間に代わりに示す地域は、`spec/scenario/index.md` の「代表地域」が定める。代わりに表示されている所属地域が分かる
- 申請中の地域を、所属の申請と離脱の申請を区別して、申請の行として示す。別の店舗管理者が出した申請を含む。行から MY-05 へ、その店舗のすべての申請は MY-04 へ進める
- 所属中の地域から1つを選んで、代表地域にする。承認を求めず、選んだ時点で反映する。公開を取り下げた地域と、運営による非公開の地域も選べる。現在の代表地域は選択済みとして示し、選べない
- 所属の申請（RQ-05）へ進める
- 所属中の地域を選んで、その地域からの離脱の申請（RQ-05）へ進める。公開を取り下げた地域と、運営による非公開の地域も選べる
- 公開中の地域は、DT-03 へ進める
- 除外を取り消す操作を持たない。再び所属するには、所属を申請する

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 所属がない | 所属中の地域がないことを示し、所属の申請へ進める（CS-09） | 所属のない店舗で開く |
| 所属が1つ | その地域が一覧に表示されることを示す。代表地域を選ぶ操作を示さない | 所属が1つの店舗で開く |
| 所属が複数（代表地域を選んでいる） | 選んだ代表地域と、代表地域を選び直す操作を示す | 所属が2つ以上で、選んだ代表地域との所属が続いている店舗で開く |
| 所属が複数（選んだ代表地域がない） | 選んだ代表地域がなく、最初に所属した地域が代表地域になっていることを示す。代表地域を選ぶ操作を示す | 所属が2つ以上で、代表地域を選んでいない、または選んだ代表地域との所属が離脱の承認・除外で解除された店舗で開く |
| 選べない | 最新の所属と代表地域を示す。選んだ地域との所属が解除されていれば、そのことを示す。選んだ地域がすでに代表地域になっていれば、そのことを示し、何も変えない（CS-08） | 代表地域を選ぶまでの間に、所属が解除される。または別の画面で先に同じ地域が代表地域に選ばれる |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-08、CS-09、CS-13。

## SM-06 イベントの状況

- 目的: 店舗の参加中・申請中のイベントを確かめ、参加内容の編集と参加の申請へ進む
- シナリオ: EVT-01、EVT-02、EVT-03
- 入口: 管理ナビゲーション「イベント」、SM-01、通知（index.md の「通知から開く画面」）

### 機能

- 参加中のイベントを、開催期間・開催の状態・添えた掲載と参加日とともに示す。店舗管理者のいなかった時期にイベント運営者が追加した参加を含む。開催期間の外になった参加日がある参加は、それと分かる。閲覧できなくなった添えた掲載は、状態とともに示す（index.md の「管理する対象の状態」）
- 未公開または運営による非公開で閲覧できないイベントの参加は、イベントの状態とともに示す
- 参加中のイベントを選んで、参加内容の変更と取りやめ（CM-04）へ進める。終了・中止したイベントと、閲覧できないイベントの参加も同じ
- 申請中のイベントを、申請の行として示す。別の店舗管理者が出した申請を含む。行から MY-05 へ、その店舗のすべての申請は MY-04 へ進める。申請中の参加をやめる操作は、MY-05 の取り下げが負う
- 参加の申請（RQ-06）へ進める。参加するイベントは RQ-06 で選ぶ
- 除外を取り消す操作を持たない。再び参加するには、参加を申請する

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 状況 | 参加中のイベントと、申請中のイベントを示す | 開く |
| 参加も申請もない | 参加中・申請中のイベントがないことを示し、参加の申請（RQ-06）へ進める（CS-09） | 参加も申請もない店舗で開く |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-09。

## SM-07 確認の依頼

- 目的: 情報の誤り・閉店の連絡に基づく確認の依頼の内容を読み、店舗情報と掲載の更新へ進む
- シナリオ: MOD-06
- 入口: 通知（index.md の「通知から開く画面」）、SM-01

### 機能

- 依頼1件について、対象の店舗または掲載、連絡の種類（情報の誤り・閉店）、連絡の内容と、その連絡が確認依頼中か対応済みかを示す
- 確かめて直すための画面へ進める。店舗の情報と営業状況は SM-02、対象の掲載は SM-04、店舗の掲載の全体は SM-03
- 確認の結果をサービス運営者に伝える操作と、連絡を対応済みにする操作を持たない。誤りがなければ何も更新しない。サービス運営者が、店舗と掲載の現在の内容を見て対応を終える（OM-05）
- 依頼は、その店舗のすべての店舗管理者に同じ内容で示す。1人が対応すれば足りる

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 確認依頼中 | 依頼の内容と、SM-02・SM-03・SM-04 への入口を示す | 確認依頼中の依頼を開く |
| CS-17 対象の掲載がない | 連絡の対象の掲載が削除されていることを示す。残る店舗の情報と掲載の確認へ進める | 対象の掲載が削除されている依頼を開く |
| 対応済み | 連絡が対応済みであることを示す。依頼の内容は読め、店舗の情報と掲載は引き続き更新できる | サービス運営者が対応を終えた依頼を開く |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-17。
