# 店舗管理（SM）

店舗管理者が、管理する店舗の情報・営業状況・掲載と、地域・イベントとの関係を管理する。画面の一覧、管理ナビゲーション、サービス運営者の代行、共通の状態（CS）、共通の機能（CF）、状態の示し方は [index.md](index.md) が定める。

SM の画面は、選んだ1つの店舗を対象にする。店舗は、MY-01 の店舗ごとの入口と、管理ナビゲーションの店舗の切り替えで選ぶ。店舗が非公開の間の示し方は、index.md の「管理する対象の状態（管理側）」に従う。

## SM-01 店舗ホーム

- 目的: 選んだ店舗の、店舗・掲載・対応が必要なことの状況を確かめる
- シナリオ: SHP-05、APP-06
- 入口: MY-01 の管理する店舗、DT-02（自分が店舗管理者の店舗）、管理ナビゲーションの店舗の切り替え、管理権限の承認と招待の承諾の後、店舗の非公開とその解除の通知

### 機能

- 選んだ店舗の名称、写真、営業状況、店舗が非公開かどうかを示す
- 掲載の件数を、公開中・下書き・非公開・提供終了の別に示す。それぞれ、その状態に絞った SM-03 へ進める
- 対応が必要なことを示す
  - 店舗管理者として行った申請のうち、差し戻しの申請。MY-05 へ進める
  - 確認依頼中の確認の依頼。SM-07 へ進める
- 店舗管理者として行った確認中・差し戻しの申請を、申請の行として示す。別の店舗管理者が出した申請を含む。行から MY-05 へ、その店舗のすべての申請は MY-04 へ進める
- 掲載の追加（SM-04）、店舗情報と営業状況（SM-02）、所属地域の状況（SM-05）、イベントの状況（SM-06）、メンバーの管理（CM-02）へ進める
- 閲覧者に見える店舗の詳細（DT-02）へ進める

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 店舗の状況 | 選んだ店舗の状況を示す | MY-01・DT-02・管理ナビゲーションの店舗の切り替え・通知から開く |
| 対応が必要なことがない | 対応が必要なことがないことを示す | 差し戻しの申請も、確認依頼中の依頼もない |
| 店舗が非公開 | 店舗が非公開であることと、店舗管理者は解除できないことを示す | サービス運営者が店舗を非公開にする |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-09。店舗の管理権限を持たない利用者が開いた場合は CS-05 に当たる。管理する店舗が1つもない利用者は、MY-01 に店舗の入口がなく、「店舗・スポットを登録する」（RQ-02）から始める。

## SM-02 店舗情報

- 目的: 店舗の情報と営業状況を、申請なしで登録・更新する
- シナリオ: SHP-06、SHP-07、SHP-12、SHP-13、MOD-06
- 入口: 管理ナビゲーション「店舗情報」、OM-02（代理登録）、OM-03（代行）、SM-07、店舗の写真の削除の通知

### 機能

- 種別（店舗・スポット）、店舗名、写真（CF-01）、紹介、住所・位置、営業時間、連絡先を編集して保存する。承認を求めず、保存した時点で閲覧者への表示に反映する
- 名称・所在地・位置を欠く内容は保存しない（CS-10）。写真は任意
- 所在地は CF-07 で入力する。店舗とその掲載のエリアは、保存した所在地の町域で決まる
- 現在の営業状況（営業中・休業・閉店）を示す。営業状況は、情報の保存とは別の操作で、営業中・休業・閉店のどれへも変える。確定の前に、変更後の閲覧者への見え方を示す（CS-12）。確定した時点で反映する
- 所属地域の変更を持たない。所属地域の状況（SM-05）へ進める
- メンバーの管理（CM-02）と、閲覧者に見える店舗の詳細（DT-02）へ進める
- 店舗を非公開にする操作と、削除する操作を持たない。Lunt への掲載をやめる店舗管理者には、DT-02 からの取り下げの申立て（RQ-08）を案内する
- 保存した内容を元に戻す操作を持たない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 編集 | 店舗の現在の情報と営業状況が入った状態で始まる | 店舗管理者が開く |
| 新規（代理登録） | 空の内容で始まる。種別を選び、情報を入力して登録する。登録した店舗は、管理者のいない店舗として公開される。登録の後、その店舗の代行の状態と、掲載の一覧（SM-03）、OM-03 へ進める | サービス運営者が、OM-02 で既存の店舗にないことを確かめて開く |
| 代行 | サービス運営者が、店舗管理者のいない店舗の情報と営業状況を更新する。操作は編集と同じ | OM-03 から開く |
| 営業状況の確認 | 休業は、店舗と掲載が休業中として表示され、掲載がフィードの対象のままであることを示す。閉店は、店舗と掲載が表示されなくなる場面と、閉店として表示される場面を示す。営業中へ戻す場合は、営業中の表示範囲に戻ることを示す。掲載の公開状態と提供状態は変わらないことを示す（CS-12） | 営業状況の変更を選ぶ |
| 写真が削除された | 申立てによって写真が削除されたことを示す。店舗の公開は続く。写真の登録へ進める | 店舗の写真の削除の通知から開く |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-07、CS-10、CS-11、CS-12、CS-13。代行で開いた店舗に店舗管理者が就いた場合は、index.md の「サービス運営者の代行」に従う。

## SM-03 掲載の一覧

- 目的: 店舗の掲載を公開状態と提供状態の別に確かめ、掲載を選ぶ
- シナリオ: LST-05、LST-11、LST-16
- 入口: 管理ナビゲーション「掲載」、SM-01、SM-07、OM-03（代行）、カテゴリーの付け替えの通知

### 機能

- 店舗のすべての掲載を、写真・名称・カテゴリー・公開状態・提供状態とともに示す。代理作成された掲載、申請の承認で公開された掲載、店舗管理者のいなかった時期の下書きを含む
- 表示する掲載を、公開中・下書き・非公開（一時非公開、運営による非公開）・提供終了の別に切り替える。提供開始前の掲載は、それと分かる
- 掲載を選んで、SM-04 へ進める。公開中の掲載は、閲覧者に見える DT-01 へも進める
- 掲載の追加（SM-04 の新規）へ進める
- 公開状態と提供状態を変える操作、複製、削除を持たない。SM-04 が持つ
- 掲載は更新の新しい順に並べる（index.md の「管理側の一覧の並び順」）。一覧は続きを読み込む（CF-05）

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | すべての掲載、または選んだ状態の掲載を示す | 開く。状態を切り替える。SM-01 から状態に絞って開く |
| 掲載がない | 店舗に掲載が1件もないことを示し、掲載の追加へ進める（CS-09） | 掲載のない店舗で開く |
| 当てはまる掲載がない | 選んだ状態に当てはまる掲載がないことを示す。別の状態へ切り替えられる（CS-09） | 掲載のない状態を選ぶ |
| 代行 | サービス運営者が、店舗管理者のいない店舗の掲載を確かめる。操作は店舗管理者と同じ | OM-03 から開く |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-09。

## SM-04 掲載の編集

- 目的: 1件の掲載の内容を作成・編集して保存し、公開状態と提供状態を変え、複製・削除する
- シナリオ: LST-01、LST-02、LST-03、LST-04、LST-06、LST-07、LST-08、LST-09、LST-10、LST-11、LST-15、LST-16、MOD-03、MOD-06
- 入口: SM-03、SM-01 の掲載の追加、SM-07、CM-03、掲載の非公開と写真の削除の通知

### 機能

- 名称、説明、カテゴリー、写真、提供の設定を編集する。価格とキャッチコピーの入力を持たない
- 紐づく店舗と、店舗情報から引いた所在地・所属地域を示す。掲載では入力しない
- カテゴリーは、サービス運営者が提供するカテゴリーから1つを選ぶ
- 写真は CF-01 による。写真ごとに、閲覧者に見せる範囲を調整する
- 提供の設定は CF-06 による。開催日は追加と削除ができ、時刻・定員・予約の項目を持たない
- 現在の提供状態（提供開始前・提供中・提供終了）を示す。提供状態は、提供期間・開催日・店舗管理者による提供終了と、今日の日付から決まる
- 保存する。下書きは、店舗への紐づけだけで保存できる。保存で提供状態が変わる場合は、変わった後の提供状態を示す
- 公開状態の操作は CF-08 による。下書きを公開し、公開中の掲載を一時非公開にし、一時非公開の掲載を再公開する。公開と再公開は、公開前の確認（CM-03）を経ずに行える
- 下書きと一時非公開の掲載は、公開前の確認（CM-03）へ進める。公開の操作は CM-03 と共有する
- 公開中の掲載を提供終了にする（CS-12）。店舗管理者が提供終了にした掲載を、提供中に戻す
- 複製する。公開状態と提供状態を問わず、運営による非公開の掲載も複製できる。名称・説明・カテゴリー・写真（並び順と見せる範囲を含む）を引き継ぎ、提供期間と開催日を引き継がない新しい下書きが、同じ店舗の掲載としてできる。元の掲載は変わらない。できた下書きの SM-04 へ進む
- 削除する。公開状態と提供状態を問わない。復元できないことを示して確かめる（CS-12）。削除が成立すると SM-03 へ戻る
- 公開中の掲載は、閲覧者に見える DT-01 と DT-02 へ進める
- 保存した内容を元に戻す操作を持たない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 新規 | 店舗に紐づいた空の内容で始まる。保存すると下書きになる | SM-03・SM-01 の掲載の追加から開く |
| 下書き | 保存、公開前の確認、公開、複製、削除を示す。閲覧者には表示されない | 新規の保存。複製 |
| 公開 | 保存、一時非公開、提供終了と提供中への復帰、複製、削除を示す | 公開、再公開が成立する |
| 一時非公開 | 保存、公開前の確認、再公開、複製、削除を示す。提供状態は、その間も日付と店舗管理者の操作で決まる | 一時非公開が成立する。申立てによる写真の削除で写真がなくなる |
| 運営による非公開 | CF-08 による。公開・一時非公開・再公開を示さず、保存・複製・削除と、重なっている公開状態で行える提供状態の操作を示す。複製でできる掲載は、運営による非公開ではない下書きになる | サービス運営者が運営による非公開にする、解除する |
| 提供終了（店舗管理者による） | 提供中に戻す操作を示す。終了日または最後の開催日を過ぎている掲載は、戻しても提供終了のままであることを示し、提供期間・開催日の変更へ案内する | 提供終了にする |
| 提供終了（自動） | 提供中に戻す操作を示さない。提供期間を更新するか外す、または開催日を追加すると提供中に戻ることを示す | 終了日または最後の開催日を過ぎる |
| 写真が削除された | 申立てによって写真が削除されたことと、現在の公開状態を示す。写真がなくなった掲載の扱いは CF-08 による | 申立てによって写真が削除された掲載を開く |
| 存在しない | 掲載が削除されていることを示し、SM-03 へ戻れる | 削除された掲載を開く |
| 代行 | サービス運営者が、店舗管理者のいない店舗の掲載を作成・更新・一時非公開・再公開・提供終了・削除する。操作は店舗管理者と同じ | OM-03 から開いた SM-03 から進む |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-07、CS-08、CS-10、CS-11、CS-12、CS-13。次の場合は CS-10 に当たる。

- 公開・再公開と、公開中の掲載の保存で、公開条件を欠く（CF-08）。公開中の掲載から写真をすべて外す場合は、先に一時非公開にすることを案内する
- 終了日が開始日より前になっている

別の管理者が先に保存した掲載の保存は CS-07 に当たる。保存・複製までの間に掲載が削除されていた場合、公開状態・提供状態を別の管理者が先に変えていた場合、選んだカテゴリーが保存までに廃止されていた場合は CS-08 に当たる。廃止の場合は、提供中のカテゴリーから選び直す。代行で開いた店舗に店舗管理者が就いた場合は、index.md の「サービス運営者の代行」に従う。保存済みの下書きは、店舗管理者の管理下に入る。

## SM-05 所属地域の状況

- 目的: 店舗の所属中・申請中の地域を確かめ、代表地域を選び、所属と離脱の申請へ進む
- シナリオ: REG-01、REG-02、REG-04、REG-05
- 入口: SM-01、SM-02、地域からの除外の通知

### 機能

- 所属中の地域を示す。店舗管理者のいなかった時期に成立した所属を含む。公開を取り下げた地域と、運営による非公開の地域は、その状態と、閲覧者には所属地域として表示されていないことを示す
- 現在の代表地域を示す。代表地域が閲覧者に表示されていない間は、代わりに表示されている所属地域が分かる
- 申請中の地域を、所属の申請と離脱の申請を区別して、申請の行として示す。別の店舗管理者が出した申請を含む。行から MY-05 へ、その店舗のすべての申請は MY-04 へ進める
- 所属中の地域から1つを選んで、代表地域にする。承認を求めず、選んだ時点で反映する。公開を取り下げた地域と、運営による非公開の地域も選べる
- 所属の申請（RQ-06）へ進める
- 所属中の地域を選んで、その地域からの離脱の申請（RQ-06）へ進める。公開を取り下げた地域と、運営による非公開の地域も選べる
- 公開中の地域は、DT-03 へ進める
- 除外を取り消す操作を持たない。再び所属するには、所属を申請する

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 所属がない | 所属中の地域がないことを示し、所属の申請へ進める（CS-09） | 所属のない店舗で開く |
| 所属が1つ | その地域が一覧に表示されることを示す。代表地域を選ぶ操作を示さない | 所属が1つの店舗で開く |
| 所属が複数 | 代表地域を選ぶ操作を示す。選んでいない店舗は、最初に所属した地域が代表地域になっている | 所属が2つ以上の店舗で開く |
| 代表地域が替わった | 代表地域との所属が解除され、残る所属のうち最初に所属した地域が代表地域になっていることを示す。選び直せる | 離脱の承認、または除外で、代表地域との所属が解除される |
| 選べない | 選んだ地域との所属が解除されていることと、最新の所属を示す（CS-08） | 代表地域を選ぶまでの間に、所属が解除される |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-08、CS-09、CS-13。

## SM-06 イベントの状況

- 目的: 店舗の参加中・申請中のイベントを確かめ、参加するイベントを選ぶ
- シナリオ: EVT-01、EVT-02、EVT-03
- 入口: 管理ナビゲーション「イベント」、SM-01、イベントからの除外の通知

### 機能

- 参加中のイベントを、開催期間・開催の状態・添えた掲載と参加日とともに示す。店舗管理者のいなかった時期にイベント運営者が追加した参加を含む。開催期間の外になった参加日がある参加は、それと分かる
- 公開の取り下げ中または運営による非公開で閲覧できないイベントの参加は、イベントの状態とともに示す
- 参加中のイベントを選んで、参加内容の変更と取りやめ（CM-04）へ進める。終了・中止したイベントと、閲覧できないイベントの参加も同じ
- 申請中のイベントを、申請の行として示す。別の店舗管理者が出した申請を含む。行から MY-05 へ、その店舗のすべての申請は MY-04 へ進める。申請中の参加をやめる操作は、MY-05 の取り下げが負う
- 参加するイベントを探して選ぶ（CF-02）。候補は、公開中で、開催前または開催中のイベント。すでに参加中のイベントと、申請中のイベントは、理由とともに選べない対象として示し、それぞれ CM-04 と MY-05 へ進める。候補から DT-04 を開いて、開催期間・開催場所・紹介を確かめられる
- 選んだイベントへの参加の申請（RQ-07）へ進める
- 除外を取り消す操作を持たない。再び参加するには、参加を申請する

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 状況 | 参加中のイベントと、申請中のイベントを示す | 開く |
| 参加も申請もない | 参加中・申請中のイベントがないことを示し、参加するイベントの選択へ進める（CS-09） | 参加も申請もない店舗で開く |
| イベントの選択 | CF-02 による。候補がない場合は、参加を申請できるイベントがないことを示す | 参加するイベントを選ぶ操作を始める |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-09。

## SM-07 確認の依頼

- 目的: 情報の誤り・閉店の連絡に基づく確認の依頼の内容を読み、店舗情報と掲載の更新へ進む
- シナリオ: MOD-06
- 入口: 確認の依頼の通知、SM-01

### 機能

- 依頼1件について、対象の店舗または掲載、連絡の種類（情報の誤り・閉店）、連絡の内容と、その連絡が確認依頼中か対応済みかを示す
- 確かめて直すための画面へ進める。店舗の情報と営業状況は SM-02、対象の掲載は SM-04、店舗の掲載の全体は SM-03
- 確認の結果をサービス運営者に伝える操作と、連絡を対応済みにする操作を持たない。誤りがなければ何も更新しない。サービス運営者が、店舗と掲載の現在の内容を見て対応を終える（OM-05）
- 依頼は、その店舗のすべての店舗管理者に同じ内容で示す。1人が対応すれば足りる
