# 共通の管理（CM）

対象の種類が違っても目的が同じ管理の操作を、1つの画面で扱う。画面の一覧、ナビゲーション、共通の状態（CS）、共通の機能（CF）、状態の示し方は [index.md](index.md) が定める。

CM の画面は、開いた利用者の立場（管理者、承認者、編集担当者、申請者、サービス運営者）で示す操作が変わる。複数の立場を併せ持つ利用者には、立場ごとの操作を併せて示す。示すナビゲーションは、開いた立場で決まる（index.md の「読みもの編集とサービス運営のナビゲーション」と「サービス運営者の不在の代行」）。

## CM-01 申請の判断

- 目的: 承認者が確認中の申請1件の内容を確かめ、承認・否認・差し戻しする
- シナリオ: APP-07、APP-08、SHP-09、SHP-10、SHP-11、LST-14、REG-09、EVT-08、REG-13、EVT-13
- 入口: 通知（index.md の「通知から開く画面」）、OM-01、RM-01、EM-01

### 機能

- 申請1件の種類、対象、申請者、状態、申請の内容を示す。示し方（再提出に添えた回答、廃止されたカテゴリーの読み替え、対象がなくなった修正の申請を含む）は index.md の「申請の状態」による
- 申請の種類ごとに、次の内容を確かめる

| 申請の種類 | 確かめる内容 | 確かめるために進める先 |
| --- | --- | --- |
| 店舗の新規登録 | 店舗の情報。管理権限の申請を併せているかどうか。名称・所在地が近い既存の店舗を、非公開の店舗を含めて示す。名称・所在地で既存の店舗を探せる（CF-02。候補は非公開の店舗を含むすべての店舗） | 照合する店舗の OM-03 |
| 店舗の管理権限取得 | 対象の店舗、申請者が記した店舗との関係と確認に使える連絡先・資料、既存の店舗管理者の有無 | DT-02、併せた登録申請の CM-01 |
| 管理者のいない店舗の情報修正、営業状況の変更 | 変更する項目ごとの、店舗の現在の値と申請の値 | DT-02 |
| 管理者のいない店舗の掲載 | 対象の店舗、名称、説明、カテゴリー、写真と見せる範囲、提供の設定 | DT-02 |
| 掲載の修正 | 変更する項目ごとの、掲載の現在の値と申請の値 | DT-01 |
| 地域への所属、地域からの離脱 | 申請の種類（所属・離脱）、対象の店舗、対象の地域 | DT-02 |
| イベントへの参加 | 対象の店舗、添えた掲載、参加日 | DT-02、DT-01 |

- 承認する。承認で反映される内容を示して確かめる（CS-12）。承認は申請の前提を確かめ、前提を欠く申請は承認しない（CS-08）
- 理由を添えて否認する（CS-12）。理由は必須
- 追加で必要な確認を添えて差し戻す（CS-12）。必要な確認は必須。期間超過の代行では差し戻しを示さない
- 自分が出した申請も、同じ操作で判断する
- 対象が運営による非公開、または店舗の非公開であることを示す。申請は確認中のまま判断できる。確認中の登録申請と、登録の承認前の併せた管理権限の申請は、対象がまだないことを示す（index.md の「申請の状態」）
- 判断が成立すると、結果と、承認で反映された対象への入口を示す（CS-13）。登録申請の承認では、併せた管理権限の申請の判断へ進める
- 元の一覧（サービス運営者は OM-01、地域運営者は RM-01、イベント運営者は EM-01）へ戻る。通知から開いた場合も同じ

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 判断 | 承認・否認・差し戻しを示す | 自分が承認者である確認中の申請を開く。運営者が不在の地域・イベントの申請を、地域の運営者・イベントの運営者としてサービス運営者が開いた場合を含む |
| 期間超過の代行 | 期間超過の代行であることを示し、承認と否認だけを示す | 運営者のいる地域・イベントへの、一定の期間を過ぎた確認中の申請を、サービス運営者が開く。運営者が不在の間に「判断」の状態で開いた、一定の期間を過ぎた申請の差し戻しの時点で、運営者が就いていた |
| 期間超過の前 | 運営者の判断を待つ申請であることを示し、判断の操作を示さない | 運営者がいて、一定の期間を過ぎていない申請を、サービス運営者が開く |
| 登録の判断待ち | 併せた登録申請が確認中・差し戻し中の間は判断できないことを示し、登録申請の判断へ進める | 登録申請が確認中または差し戻し中の、併せた管理権限の申請を開く |
| 確認中でない | 申請の現在の状態（差し戻し・承認・否認・取り下げ・失効）を示し、判断の操作を示さない。期間超過の代行で判断された申請、運営者が先に判断した申請は、そのことが分かる。取り下げになった申請は、状態を確かめるだけで判断は要らない | 確認中でない申請を開く。申請の取り下げの通知から開く |
| 判断済み | 判断の結果を示す（CS-13）。期間超過の代行として反映した判断は、そのことが分かる。判断は変えられない | 承認・否認・差し戻しが成立する |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-07、CS-08、CS-10、CS-12、CS-13、CS-15、CS-17。運営者が不在の地域・イベントの申請を地域の運営者・イベントの運営者として判断するサービス運営者は、判断の時点で対象に地域運営者・イベント運営者が就いていれば、期間超過の代行ができる申請では、承認・否認はその1回で期間超過の代行として反映し、判断済みを示す。差し戻しは反映せず、「期間超過の代行」の状態に移る。期間超過の前の申請では CS-15 に当たる（`spec/scenario/index.md` の「立場を失ったとき」）。別の承認者（期間超過の代行をするサービス運営者を含む）が先に判断した場合、判断の前に申請が取り下げ・失効となった場合、承認の時点で申請が前提を欠く場合は CS-08 に当たる。開いてから判断するまでの間に、申請が差し戻しと再提出を経て内容が変わっていた場合は CS-07 に当たる。掲載の修正の申請の承認の時点で、申請の写真が提出の後に掲載から外れるか削除されていて、1枚も反映できない場合は、承認できないことと理由を示し、承認を反映しない。申請は確認中のまま残り、否認か差し戻しへ進める（LST-14）。申請の写真の一部だけが提出の後に掲載から外れるか削除されている場合は、承認で反映される内容（CS-12）に残る写真だけを示し、外された写真があることを示す。承認でき、残る写真だけを反映する（LST-14）。CS-10 は、否認の理由・差し戻しの必要な確認がない場合と、照合する店舗を名称も所在地も入力せずに探した場合に当たる。存在しない申請を開いた場合は CS-17 に当たり、元の一覧へ戻れる。対象の詳細を開いたときの CS-06 は、開いた先の画面が示す。

## CM-02 メンバーの管理

- 目的: 1つの店舗・地域・イベントの管理者と承諾前の招待を確かめ、招待・招待の取り消し・辞任・解除・付与を行う
- シナリオ: MEM-01、MEM-02、MEM-04、MEM-05、REG-12、EVT-12
- 入口: SM-01、SM-02、地域運営とイベント運営の管理ナビゲーション、OM-03、OM-05（連絡の対象の店舗）、MY-07（後任の招待）、通知（index.md の「通知から開く画面」）

### 機能

- 対象の管理者の一覧と、承諾前の招待を宛先のメールアドレスとともに示す
- 対象の管理者に、次の操作を示す
  - 招待する相手のメールアドレスを入力して、招待を送る。すでに管理者であるメールアドレスと、承諾前の招待があるメールアドレスには、そのことを示して送らない
  - 承諾前の招待を取り消す（MEM-02）。同じ対象のどの管理者も取り消せる
  - 辞任する（CS-12）。後任の招待が承諾される前でも辞任できる。招待は有効のまま残る
- サービス運営者に、次の操作を示す
  - 管理者を選んで、管理権限を解除する（MEM-05。CS-12）
  - 地域とイベントでは、既存のアカウントをメールアドレスで指定して、管理権限を付与する。アカウントのないメールアドレスと、すでにその対象の管理者であるアカウントには、そのことを示して付与しない。店舗では付与を示さない
  - 管理者が不在の対象では、承諾前の招待を取り消す（MEM-02）
- 招待と付与に、サービス運営者の承認を求めない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 管理者の操作 | 招待、招待の取り消し、辞任を示す | 対象の管理者が開く |
| サービス運営者の操作 | 解除を示す。地域とイベントでは付与を示す。招待と、管理者のいる対象の招待の取り消しを示さない | サービス運営者が OM-03 または OM-05 から開く |
| 管理者不在 | 管理者がいないことと、残っている承諾前の招待を示す。招待の取り消しを示す。地域とイベントでは付与へ進める。店舗では、管理権限の申請の承認か、残っている招待の承諾で店舗管理者が就くことを示す | 管理者のいない対象を、サービス運営者が開く |
| 辞任の確認 | 他に管理者がいるかを示す。最後の管理者には、index.md の「管理する対象の状態」が定める管理者不在の帰結を示す（CS-12） | 辞任を選ぶ |
| 解除の確認 | 解除する管理者を示す。最後の管理者の解除には、辞任の確認と同じ帰結を示す（CS-12） | 解除を選ぶ |
| 辞任済み | 対象の管理者でなくなったことを示し、MY-01 へ進める。対象の管理の入口は示さない | 辞任が成立する |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-08、CS-09、CS-10、CS-12、CS-13、CS-15。承諾前の招待がない場合は CS-09、解除の前に本人が辞任・退会していた、または別のサービス運営者が解除していた場合と、取り消す前に招待が承諾または取り消されていた場合は CS-08 に当たる。サービス運営者が管理者不在の対象の招待を取り消す確定の時点で、対象に管理者が就いていた（取り消す招待の承諾による場合を含む）ときは、CS-08 ではなく CS-15 に当たる。招待の取り消しの CS-08 は、取り消せないことと、最新の管理者と招待の一覧を示す。辞任の確定の時点で、すでに管理者でない（解除された、別のブラウザで辞任した）場合は CS-05 に当たり、すでに管理者でないことを示して MY-01 へ戻る。CS-10 は招待と付与のメールアドレスの形式の誤りに当たる。

## CM-03 公開前の確認

- 目的: 公開していない掲載（下書き・一時非公開・申請の提出前）と未公開の読みものの、閲覧者への見え方を確かめる
- シナリオ: LST-04、LST-12、LST-13、LST-15、EDT-03
- 入口: SM-04、AM-02、RQ-04

### 機能

- 内容を、閲覧者に見えるのと同じ表現で示す。SM-04 と AM-02 から開いたときは保存した内容を、RQ-04 から開いたときは提出の前の入力中の内容（修正の申請は修正後の内容）を対象にする
  - 掲載は、一覧のカードでの見え方と、DT-01 での見え方を示す。写真の見せる範囲、名称、店舗の名称、地域名、カテゴリー、説明、提供の設定が分かる
  - 読みものは、DT-05 での見え方（写真・本文・紹介先）と、VW-09 とフィードで紹介されるときの見え方を示す。閲覧者が閲覧できない紹介先は表示されないことが分かる
- 開いた画面（SM-04、AM-02、RQ-04）へ戻る。RQ-04 へ戻ると、入力中の内容は保たれている
- SM-04 と AM-02 から開いたときは、公開する（一時非公開の掲載は再公開）。公開の操作は CF-08 による。公開条件を欠く場合は、編集へ戻れる。読みものは紹介先がなくても公開できる
- RQ-04 から開いたときは、公開の操作を持たない。提出は RQ-04 が負う
- 公開が成立すると、閲覧者に見える詳細（DT-01、DT-05）へ進める。掲載では DT-02 へも進める（CS-13）
- 確認は公開と提出の必須手順ではない。公開せずに離れると、対象は変わらない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 確認 | 見え方と、公開の操作を示す | 下書き・一時非公開の掲載、未公開の読みものの編集画面から開く |
| 申請の確認 | 見え方だけを示し、公開の操作を示さない | RQ-04 から開く |
| 公開できない | 見え方を示し、公開の操作を示さない（CF-08） | 運営による非公開の掲載から開く |
| 店舗が非公開 | 公開はできるが、店舗の非公開が解除されるまで閲覧者に表示されないことを示す | 非公開の店舗の掲載から開く |
| 公開済み（CS-08） | 他の人がすでに公開していることを示し、編集へ進める | 開いた対象がすでに公開されている。または公開の時点ですでに公開されている |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-06、CS-08、CS-10、CS-13、CS-17。CS-05 は SM-04 と AM-02 から開いたときに当たる。確かめている間に掲載が削除されていた場合は CS-17 に当たり、SM-03 へ戻れる。RQ-04 から開いたとき、入力の途中で申請の対象の店舗が閲覧できなくなっていた場合は CS-06 に当たり、見え方を示さない。

## CM-04 参加内容の編集

- 目的: 店舗とイベントの参加の内容（添える掲載と参加日）を、承認なしで追加・変更し、参加を取りやめる
- シナリオ: EVT-02、EVT-03、EVT-10
- 入口: 店舗管理者は SM-06、イベント運営者は EM-01、通知（index.md の「通知から開く画面」）

### 機能

- 1つの店舗と1つのイベントの参加について、イベントの名称・開催期間・開催の状態と、添えた掲載・参加日を示す。店舗管理者のいなかった時期に成立した参加も同じように示す
- 変更・取りやめ・追加は、イベントの開催の状態（開催前・開催中・終了・中止）にかかわらず行える
- 店舗管理者には、未公開または運営による非公開で閲覧できないイベントの参加も、イベントの状態とともに示す。参加内容の変更と取りやめを行える
- 添える掲載を追加し、外す。追加できるのは、その店舗の公開中の掲載で、提供状態は問わない。添えた掲載と追加の候補は、提供開始前・提供終了を区別して示す。閲覧できなくなった添えた掲載は、状態とともに示し、閲覧者に表示されていないことが分かる（index.md の「管理する対象の状態」）
- 参加日を追加し、外す。参加日は開催期間内の日付に限る。開催期間の外になった参加日は、それと分かるように示し、閲覧者に表示されていないことを示す
- 掲載と参加日は、どちらも複数添えられ、添えなくてもよい
- 保存する。承認を求めず、保存した時点で反映する
- 店舗管理者は、参加を取りやめる（CS-12）
- イベント運営者は、管理者のいない公開中の店舗を探して選び（CF-02）、掲載と参加日を添えて参加店舗として追加する。候補は管理者のいない公開中の店舗に限り、管理者のいる店舗は示さない。すでに参加中の店舗は、理由とともに選べない対象として示し、その参加内容の変更へ進める
- イベント運営者は、管理者のいない参加店舗の参加内容を、成立の経緯にかかわらず変更する
- DT-04 と、添えた掲載の DT-01 へ進める
- 除外の操作を持たない。イベント運営者は EM-01 で除外する

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 変更（店舗管理者） | 参加内容の変更と、取りやめを示す | 店舗管理者が、SM-06 の参加中のイベントまたは通知から開く |
| 追加 | 店舗の選択（CF-02）から始まり、掲載と参加日を添えて追加する | イベント運営者が、EM-01 の店舗の追加から開く |
| 変更（イベント運営者） | 参加内容の変更を示す。取りやめを示さない | イベント運営者が、EM-01 の管理者のいない参加店舗から開く |
| 店舗管理者が就いた | 店舗に店舗管理者が就いたため、イベントの運営者は追加・変更できないことを示し、追加・保存を反映しない。追加の途中なら参加は成立せず、店舗管理者の参加の申請を待つ。変更の途中なら参加は保たれ、以後の変更は店舗管理者が行う | 追加・保存までの間に、店舗に店舗管理者が就く |

共通の状態: CS-01、CS-02、CS-04、CS-05、CS-06、CS-07、CS-08、CS-10、CS-11、CS-12、CS-13。追加の確定の時点で、選んだ店舗が非公開などで閲覧できなくなっていた場合は CS-06 に当たり、追加を反映しない。別の店舗を選ぶ。別の人が先に保存した参加内容の保存は CS-07 に、保存・取りやめまでの間に参加が除外・取りやめで解除されていた場合は CS-08 に当たる。新たに添えた掲載が、追加・保存の時点で添えられなくなっていた（`spec/scenario/event.md` の共通の規則）場合も CS-08 に当たり、追加・保存を反映せず、最新の添えられる掲載を示して選び直す。保存が成立すると、店舗管理者は SM-06 と DT-04 へ、イベント運営者は EM-01 と DT-04 へ進める（CS-13）。
