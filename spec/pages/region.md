# 地域運営（RM）

地域運営者が、管理する1つの地域の所属店舗・申請・地域情報・関連づけられたイベントを扱う画面を定める。画面の一覧、ナビゲーション、共通の状態（CS）、共通の機能（CF）、状態の示し方は [index.md](index.md) が定める。

- 対象の地域は MY-01 で選ぶ。RM の画面は、選んだ1つの地域だけを扱う
- メンバーの管理は CM-02、申請の判断は CM-01 が負う。RM の画面は入口だけを持つ
- 運営者が不在の地域では、サービス運営者が OM-03 から同じ画面を代行で開く（REG-13）。各画面の機能と状態は、代行するサービス運営者にも同じく当てはまる。代行の規則は index.md の「サービス運営者の代行」による。運営者が不在の地域についての地域運営者宛ての通知は、サービス運営者に届いて OM-03 を開き、RM の画面を直接は開かない
- EM-01・EM-02 は、RM-01・RM-02 と同じ機能と状態に、イベントだけが持つものを加えて持つ

## RM-01 所属店舗と申請

- 目的: 地域の所属店舗と所属・離脱の申請を確かめ、店舗を除外する
- シナリオ: REG-08、REG-10、REG-13
- 入口: MY-01 の管理する地域、招待の承諾の後（MY-06）、管理ナビゲーション「所属店舗と申請」、OM-03（代行）、管理権限の付与の通知

### 機能

- 所属中の店舗を、所属の新しい順の一覧で確かめる。店舗の状態は index.md の「管理する対象の状態」のとおり示す。各店舗から DT-02 へ進める
- 所属・離脱の申請を一覧で確かめる。申請ごとに、種類（所属・離脱）、対象の店舗、申請者、状態を示す。確認中と差し戻しの申請を先に、提出の新しい順に並べる。示し方は index.md の「申請の状態」による。確認中の申請の件数を示す
- 確認中の申請を選び、CM-01 へ進んで判断する。この画面は判断の操作を持たない
- 所属店舗を選んで除外する。理由は求めない。確定の前に結果を確かめる（CS-12）
- 所属店舗の情報と掲載を更新する操作は持たない

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-08、CS-09、CS-12、CS-13 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | 所属店舗と申請を示す | 画面を開く |
| CS-09 空 | 所属店舗がないことと、申請がないことを、別々に示す | 所属店舗または申請が1件もない |
| CS-12 除外の確認 | 所属が解除されること、店舗と掲載の公開状態・提供状態と他の地域への所属は変わらないこと、除外は取り消せないことを示す | 所属店舗の除外を始める |
| CS-13 除外の完了 | 店舗が所属店舗から外れたことを示す | 除外が成立する |
| CS-08 所属していない | 除外しようとした店舗の所属が、離脱の承認または別の運営者の除外で、すでに解除されている。最新の所属店舗を示す | 除外の確定の時点で所属がない |
| 代行中 | サービス運営者が開いている。管理ナビゲーションが代行中であることを示し、OM-03 へ戻れる | OM-03 から開く |
| 代行できない | 地域に地域運営者が就いた。操作を反映しない | 代行の操作の確定の時点で地域運営者がいる |

## RM-02 地域情報の編集

- 目的: 地域の情報を登録・編集して保存し、公開し、公開を取り下げる
- シナリオ: REG-06、REG-07、REG-12、REG-13、MOD-03
- 入口: 管理ナビゲーション「地域情報」、OM-02（登録）、地域の非公開と写真の削除の通知

### 機能

- 名称・所在地・位置・写真・紹介・キャッチコピーを入力して保存する。所在地は CF-07、写真は CF-01 による。位置は1点で指定する
- サービス運営者は、OM-02 から新規の状態で開いて地域を登録する。保存すると、地域は下書きとして登録される。登録した地域は運営者が不在の地域になり、以後は代行で開く。管理ナビゲーションの「メンバー」（CM-02）から管理権限を付与する
- 公開状態の操作は CF-08 による。下書きまたは公開を取り下げた地域を公開し、公開中の地域の公開を取り下げる。地域運営者がいなくても公開できる
- 所属店舗の情報と掲載を更新する操作は持たない

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-07、CS-08、CS-10〜CS-13 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 新規 | 入力が空の状態で始まる。サービス運営者だけが開ける。公開の操作は持たない。保存せずにやめると、地域は登録されない | OM-02 の新しい登録から開く |
| 下書き | 保存と公開を示す | 新規の保存が成立する。または下書きの地域を開く |
| 公開 | 保存と公開の取り下げを示す | 公開が成立する。または公開中の地域を開く |
| 公開の取り下げ | 保存と公開を示す | 取り下げが成立する。または取り下げた地域を開く |
| 運営による非公開 | CF-08 による | サービス運営者が OM-03 で非公開にする、解除する |
| 写真の削除による公開の取り下げ | CF-08 による | 写真の削除の通知から開く。または該当する地域を開く |
| CS-10 公開条件の不足 | CF-08 による | 公開の操作、または公開中の地域の保存で条件を欠く |
| CS-08 公開状態の変化 | 別の運営者がすでに公開している、または公開を取り下げている。現在の公開状態を示す | 公開・取り下げの時点で前提がない |
| CS-12 取り下げの確認 | 地域がどの場面にも表示されなくなること、所属店舗と掲載の所属地域としても表示されなくなること、所属関係と関連づけは保たれることを示す | 公開の取り下げを始める |
| CS-13 完了 | 保存・公開・取り下げが成立したことを示す。公開中の地域は DT-03 へ進める | 保存・公開・取り下げが成立する |
| 代行中 | RM-01 と同じ | OM-03 または OM-02 から開く |
| 代行できない | RM-01 と同じ | 保存・公開・取り下げの時点で地域運営者がいる |

## RM-03 関連づけられたイベント

- 目的: 地域に関連づけられたイベントを確かめ、関連づけを解除し、解除を取り消す
- シナリオ: REG-11、REG-13
- 入口: 管理ナビゲーション「関連イベント」、開催地域の関連づけの通知

### 機能

- 地域を開催地域として関連づけているイベントを一覧で確かめる。イベントは開催の状態とともに示す。各イベントから DT-04 へ進める
- 公開の取り下げ中または運営による非公開で閲覧できないイベントとの関連づけは、イベントの状態とともに示す。解除と解除の取り消しは、閲覧できるイベントと同じく行える
- 関連づけを解除する。解除すると、地域詳細とイベント詳細の両方から関連が外れ、イベントの運営者はこの地域に同じイベントを再び関連づけられない。解除の操作とともに、このことを示す。解除は取り消せるので、確定の前の確認（CS-12）を持たない
- 解除したイベントを、関連づけ中のイベントと区別して一覧で確かめる
- 解除を取り消す。関連づけが回復する。取り消した後に、再び解除できる
- 関連づける操作は持たない。関連づけは EM-03 が負う

### 状態

共通の状態のうち CS-01、CS-02、CS-04、CS-05、CS-08、CS-09、CS-13 が当てはまる。この画面に固有の内容を持つものを表に書く。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 一覧 | 関連づけ中のイベントと、解除したイベントを区別して示す。閲覧できないイベントは、その状態とともに示す | 画面を開く |
| CS-09 空 | 関連づけられたイベントがないことを示す | 関連づけ中のイベントも解除したイベントもない |
| CS-13 解除の完了 | イベントが解除したイベントへ移ったことを示す。解除を取り消せる | 解除が成立する |
| CS-13 取り消しの完了 | イベントが関連づけ中へ戻ったことを示す | 解除の取り消しが成立する |
| CS-08 関連づけの変化 | 解除しようとしたイベントの関連づけを、イベントの運営者がすでに外している、または別の運営者がすでに解除している。取り消そうとした解除を、別の運営者がすでに取り消している。最新の一覧を示す | 解除・取り消しの時点で前提がない |
| 代行中 | RM-01 と同じ | OM-03 から開く |
| 代行できない | RM-01 と同じ | 解除・取り消しの時点で地域運営者がいる |
