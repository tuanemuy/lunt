# 詳細（DT）

閲覧者が、掲載・店舗・地域・イベント・読みものの1件の内容と状態を確かめ、関係のある対象をたどる画面を定める。

画面の一覧、ナビゲーション、共通の状態（CS）、共通の機能（CF）、状態の示し方、関連情報の選び方は [index.md](index.md) が定める。

## 画面群に共通

- すべての画面は、ログインせずに閲覧できる
- 写真は、登録された順にすべて見られる。1枚目が代表写真
- 関連情報の区分、選ぶ対象、順、件数は、index.md の「詳細の関連情報」に従う。区分の対象を選ぶと、その詳細を開く。戻ると、元の詳細に戻る
- 関連先が閲覧できなくなっても、この画面は閲覧できる。閲覧できない関連先は、区分に表示しない
- 区分の続き（CF-05）を読み込む時点で、この画面の対象そのものが閲覧できなくなっていれば、CS-06 を示す
- 各画面は、対象そのものと区分が、発見の場面か参照の場面かを述べる。表示範囲の規則は、index.md の「公開中の対象の状態（閲覧側）」に従う
- 手続き（申請・申立て・連絡）の入口と、それを示す条件は、index.md の「詳細の手続きの入口」だけが定める。取り下げの申立て（RQ-07）は、この画面の対象を指定して開く

## DT-01 掲載詳細

- 目的: 1つの掲載の内容と状態を確かめ、店舗・地域・イベント・読みものへたどる
- シナリオ: EXP-06、KEP-01
- 入口: VW-01、VW-03、VW-06、VW-10、DT-01（他の掲載）、DT-02、DT-03、DT-04、DT-05

### 機能

- 掲載の写真、名称、説明、カテゴリーを示す。商品・体験・景色・見どころのどれも同じ形で示す
- 提供期間または開催日が設定されていれば示す。開催日は、複数あればすべて示す
- 関連情報として、店舗、地域、イベント、他の掲載、読みものの区分を示す。順に DT-02、DT-03、DT-04、DT-01、DT-05 を開く
- 掲載そのものと紐づく店舗は参照の場面に、他の掲載とイベントの区分は発見の場面に当たる
- 保存と解除を切り替える（CF-04）。掲載と店舗の状態にかかわらず保存できる

### 状態

提供の状態と店舗の営業状況は独立していて、重なる。

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 提供中 | 掲載の内容と関連情報を示す | 提供中の掲載を開く |
| 提供開始前 | 提供開始前であることと開始日を示す。内容の閲覧と保存は提供中と同じ | 提供開始前の掲載を開く |
| 提供終了 | 提供の終了を知らせ、店舗（DT-02）と別の掲載へ案内する。内容の閲覧と保存は提供中と同じ | 提供終了の掲載を開く |
| 店舗が休業中・閉店 | 店舗の休業中・閉店を、営業中と区別して示す。DT-02 へ進める | 紐づく店舗が休業中または閉店している |
| CS-06 | — | 掲載が下書き・一時非公開・運営による非公開・削除、店舗が非公開、または掲載が存在しない |
| CS-01 | — | 開く。読みものの区分の続きを読み込む |
| CS-02 | — | 取得が通信エラーで成立しない |

## DT-02 店舗詳細

- 目的: 1つの店舗の情報・位置・営業状況を確かめ、掲載・所属地域・イベント・読みものへたどる
- シナリオ: EXP-07、KEP-01、SHP-01、REG-03
- 入口: VW-03、VW-04、VW-06、VW-08、VW-10、DT-01、DT-03、DT-04、DT-05、RQ-01

### 機能

- 店舗の写真、名称、紹介、所在地、訪問に必要な情報（営業時間、連絡先）、営業状況を示す
- 店舗の位置を、画面の中の地図で示す
- 関連情報として、掲載、地域、イベント、読みものの区分を示す。順に DT-01、DT-03、DT-04、DT-05 を開く。イベントから見つけた店舗も、地域の区分から所属地域をたどれる
- 店舗そのもの、掲載の区分、地図は参照の場面に、イベントの区分は発見の場面に当たる
- 保存と解除を切り替える（CF-04）。店舗の状態にかかわらず保存できる
- 「このお店を管理する」は、その店舗の管理権限の申請（RQ-03）を開く。ログインしていない閲覧者は、ログイン（CS-04）を経て RQ-03 へ進む。ログインをやめると申請は始まらず、この画面の閲覧を続けられる

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 営業中 | 店舗の情報と関連情報を示す | 営業中の店舗を開く |
| 休業中 | 休業中であることを、営業中と区別して示す | 休業中の店舗を開く |
| 閉店 | 閉店を、営業中と区別して示す。地図を含めて閲覧できる。地域の区分から別の店舗を探せる（DT-03） | 閉店した店舗を開く |
| 掲載なし | 掲載の区分を表示せず、店舗の情報と残りの区分を示す。空の状態（CS-09）は示さない | 店舗に公開中の掲載がない |
| 店舗管理者として閲覧 | index.md の「詳細の手続きの入口」の、店舗管理者である閲覧者の入口を示す | その店舗の店舗管理者としてログインしている |
| CS-06 | — | 店舗が非公開、または存在しない |
| CS-01 | — | 開く。掲載と読みものの区分の続きを読み込む |
| CS-02 | — | 取得が通信エラーで成立しない |

## DT-03 地域詳細

- 目的: 1つの地域を、所属する店舗とその掲載を通して知る
- シナリオ: EXP-04、REG-01、REG-03
- 入口: VW-01、VW-03、VW-04、VW-05、DT-01、DT-02、DT-04、DT-05

### 機能

- 地域の写真、名称、キャッチコピー、紹介、所在地を示す
- 関連情報として、店舗、掲載、イベント、読みものの区分を示す。順に DT-02、DT-01、DT-04、DT-05 を開く。店舗、掲載、イベントの区分は発見の場面に当たる
- イベントの区分は、その地域に関連するすべてのイベントを示す（APX 4 の「地域内イベント」）
- 店舗と掲載の区分のカードの地域名には、その地域を示す
- 店舗の区分から所属する店舗の一覧へ、掲載の区分から掲載の一覧へ進む（VW-06）
- 地域の位置と所属する店舗の位置を、地図で確かめる（VW-04）。VW-04 は、この地域を選んだ状態で開く
- この地域への所属の申請（RQ-05）へ進む。申請する店舗は RQ-05 で選ぶ。ログインしていない閲覧者は、ログイン（CS-04）を経て RQ-05 へ進む
- 保存の操作を持たない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 表示 | 地域の内容と関連情報を示す | 公開中の地域を開く |
| CS-09（地域に閲覧できる掲載がない） | 掲載の区分に代えて、閲覧できる掲載がないことを示す。店舗の区分から DT-02 へ、または他の地域（VW-05）へ進める | 掲載の区分に示す掲載がない |
| CS-06 | — | 地域が公開の取り下げ、運営による非公開、または存在しない |
| CS-01 | — | 開く。読みものの区分の続きを読み込む |
| CS-02 | — | 取得が通信エラーで成立しない |

## DT-04 イベント詳細

- 目的: 1つのイベントの内容と開催の状態、参加店舗と添えた掲載・参加日を確かめる
- シナリオ: EXP-09、EVT-01
- 入口: VW-01、VW-03、VW-07、DT-01、DT-02、DT-03、DT-05

### 機能

- イベントの写真、名称、キャッチコピー、紹介、開催期間、開催場所を示す
- 関連情報として、参加店舗、地域、読みものの区分を示す。参加店舗の区分は、すべての参加店舗を、店舗ごとに添えた掲載と参加日とともに示す（APX 4 の「参加店舗一覧」）。開催期間の外の参加日は示さない
- 参加店舗は DT-02、添えた掲載は DT-01、地域は DT-03、読みものは DT-05 を開く
- イベントそのもの、参加店舗、添えた掲載は参照の場面に当たる
- 参加店舗の位置を、地図で確かめる（VW-08）
- このイベントへの参加の申請（RQ-06）へ進む。申請する店舗は RQ-06 で選ぶ。ログインしていない閲覧者は、ログイン（CS-04）を経て RQ-06 へ進む
- イベントの一覧（VW-07）へ進み、他のイベントを探す
- 保存の操作を持たない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 開催前 | 開催予定として示す | 開催期間の開始より前に開く |
| 開催中 | イベントの内容と関連情報を示す | 開催期間の間に開く |
| 終了 | 終了を、開催中と区別して示す。内容は閲覧できる。VW-07 へ進める | 開催期間の終了より後に開く |
| 中止 | 中止を、開催中と区別して示す。内容は閲覧できる。VW-07 へ進める | イベントの運営者が中止にしたイベントを開く |
| CS-09（イベントに閲覧できる掲載がない） | 閲覧できる掲載がないことを示す。参加店舗があれば、参加店舗の区分は示し、そこから DT-02 へ進める。VW-07 へ進める | 参加店舗がない場合を含め、参加に添えた掲載に閲覧できるものがない |
| CS-06 | — | イベントが公開の取り下げ、運営による非公開、または存在しない |
| CS-01 | — | 開く。読みものの区分の続きを読み込む |
| CS-02 | — | 取得が通信エラーで成立しない |

## DT-05 記事

- 目的: 1つの読みものを読み、紹介先の詳細へ進む
- シナリオ: EXP-12
- 入口: VW-01、VW-03、VW-09、DT-01〜DT-04

### 機能

- 記事のタイトル、写真、本文を示す
- 記事が紹介する掲載・店舗・地域・イベントを、紹介先の区分に示す。紹介先は参照の場面に当たる
- 紹介先を選ぶと、DT-01〜DT-04 のうち対象の詳細を開く
- 読みものの一覧（VW-09）へ進む
- 保存の操作を持たない

### 状態

| 状態 | 内容 | 遷移のきっかけ |
| --- | --- | --- |
| 表示 | 記事と紹介先を示す | 公開中の読みものを開く |
| 閲覧できない紹介先がある | 本文は変わらずに閲覧できる。その対象を紹介先に示さない。閲覧できる紹介先が1件もなければ、紹介先の区分を表示しない | 紹介先が非公開・公開の取り下げ・削除になっている |
| CS-06 | VW-09、または他の探索へ進める | 読みものの公開が取り下げられている、または存在しない |
| CS-01 | — | 開く |
| CS-02 | — | 取得が通信エラーで成立しない |
