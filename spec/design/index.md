# デザイン方針

Lunt の画面デザインの方針を定める。値は [tokens.md](tokens.md) が、画面ごとのデザインは `pages/` の HTML が定める。デザインは Figma から取り込んだ（「取り込み元」）。

## UI 構造

### 閲覧側（VW・DT）

Figma の 30 App Screens の構成に従う。

- 画面は上から、ヘッダー（Header）、縦にスクロールする本文（Viewport）、下部ナビゲーション（BottomNavigation）の3段で組む
- ヘッダーは2種類を持つ。5つのタブ画面（VW-01・VW-04・VW-05・VW-09・VW-10）はタブ画面用、それ以外の画面は戻る操作と画面名を持つ詳細用
- 下部ナビゲーションは「みつける / マップ / まち / 読む / 保存」の5項目を常に示し、開いている画面の項目を選択中として示す
- フィードは、地域・読みもの・イベントを写真に重ねた大きな枠（EditorialFeature）で区切り、その間に掲載のカード（DiscoverCard）を2列で並べる
- 詳細は、写真を先頭に置き（DetailHero）、名称・店舗・地域・紹介・操作、関連する区分（ContentRow）の順に並べる

### 管理側（MY・RQ・CM・SM・RM・EM・OM・AM）

Figma の 40 Merchant Screens の構成に従う。

- 画面は上から、ブランドの帯（Brand bar）、画面名と対象の状態を示す帯（Title bar）、縦にスクロールする本文（Viewport）、主要な操作を置く帯（Actions）の4段で組む
- 店舗管理のナビゲーション「ホーム / 掲載 / イベント / 店舗情報」は、Figma の店舗ホーム（M02）の形で示す。地域運営・イベント運営・サービス運営のナビゲーションは、同じ形で項目を差し替えて補う
- 入力の画面は、項目名と「必須・任意」を1行に置き、その下に入力欄と補足を置く
- 公開前の確認（CM-03）は、閲覧側の表現（明朝の名称、DetailHero）をそのまま使う
- 操作の後の完了（CS-13）は、Figma の「状態/…」フレームの形（見出し・説明・戻る操作）で示す

## デザイン様式

Figma のデザイン C₁（`spec/design-appendix.md` の「デザイン方針」）。写真を入口にした、落ち着いた編集的な様式。

- **写真が主役**: 掲載・地域・読みもの・イベントは写真を大きく見せ、文字は写真を補う。写真の角丸は `--radius-2` と控えめにする
- **明朝とゴシックの役割分担**: キャッチコピー・画面名・区分の見出し・対象の名称は明朝（`--font-display`、字間 `--tracking-display`）。本文・操作・メタ情報はゴシック（`--font-base`）。管理側は、閲覧者への見え方を示す箇所を除いてゴシックを中心にする
- **キャッチコピーは地域と読みものに集める**: 個々の掲載は、名称・店舗名・地域名を区別して示し、キャッチコピーを持たない
- **色は少なく**: 文字は `--ink`・`--secondary`・`--muted` の3段、地は `--white`・`--paper`・`--light`。色で強調するのは主要な操作と選択中（`--green`）と、フォーカス・エラー（`--focus`）だけ
- **罫線で区切る**: 区分と大きな枠の前後は `--line` の細い罫線で区切り、影は重なる要素（メニュー、ダイアログ、地図の上に重ねたラベル）にだけ使う（`--shadow-overlay`）

## レイアウトの原則

- 画面の左右の余白は `--space-21`、カードの間は `--space-16`（Figma の Foundations）
- 操作は `--size-touch`（44px）以上の大きさを持つ
- 余白は `--space-*` の段階だけを使う
- 掲載のカードは2列を基本にし、幅の広いビューポートで列を増やす（「レスポンシブ戦略」）

## レスポンシブ戦略

Figma はモバイル（幅 390px）のフレームだけを持つ。タブレットとデスクトップは、Figma の部品と値から補った（「補ったもの」）。モバイルファーストで書き、Figma のフレームの構造を基準のスタイルにする。

| 幅 | 閲覧側 | 管理側 |
| --- | --- | --- |
| 〜767px | Figma のとおり。掲載のカードは2列 | Figma のとおり |
| `md` 768px〜 | モバイルの構造のまま、左右の余白を `--space-32` にし、掲載のカードを3列にする | モバイルの構造のまま、左右の余白を `--space-32` にする |
| `lg` 1024px〜 | デスクトップの構造に切り替える。下部ナビゲーションを消し、ヘッダーの中にロゴ・5項目・検索・マイページを並べる。本文は最大幅 1200px で中央に置き、掲載のカードを4列にする。詳細は、写真と本文を左右の2列にする | デスクトップの構造に切り替える。管理ナビゲーションを左の縦のナビゲーションにし、本文を最大幅 720px で置く。Actions の帯は本文の末尾に置く |

- デスクトップとモバイルを切り替えるブレークポイントは `lg`（1024px）。1023px まではモバイルの構造、1024px からはデスクトップの構造
- 横スクロールを出さない。幅の広い内容（表）は、モバイルでカードに組み替える
- 下部ナビゲーションと Actions の帯は、モバイルで画面の下端に固定する。本文は、固定した帯に隠れない余白を下端に持つ
- タッチの操作は `--size-touch` 以上を保つ

## インタラクションの方針

- ホバー: ポインターのある端末（`@media (hover: hover)`）でだけ示す。カードは写真をわずかに暗くし、ボタンとリンクは地の色を変える。タッチ端末ではホバーに頼らない
- フォーカス: キーボード操作（`:focus-visible`）で、`--focus` のリングを示す
- アクティブ: 押している間、地の色を一段濃くする
- 無効: 文字を `--muted`、地を `--paper` にし、操作できないことを示す
- エラー: 入力欄の枠を `--focus` にし、欄の下に理由を示す
- トランジションは `--transition-default` を使う
- Figma のコンポーネントのバリアントにある状態は、そのバリアントの値で示す。無い状態は、上の規則で補う（「補ったもの」）

## 画像・アイコンの方針

- 写真は Figma の素材（`assets/`）を使い、`object-fit: cover` で枠を満たす。枠の比率は Figma のフレームの比率に従う
- アイコンは Figma の Icon を SVG で書き出して使う（`assets/`）
- 写真が読み込まれる前と写真のない対象は、`--paper` の地で示す

## アクセシビリティ

- 文字と地のコントラストは WCAG AA 以上を保つ
- フォーカスのリングを消さない
- 状態を色だけで示さず、文言を添える

## 状態の切り替え（デザイン確認用）

同じ画面の状態は、1つの HTML の中で切り替えて見られる。画面本体の外に置いた `<nav data-design-states>` が `<body>` の `data-state` を切り替える。この切り替えはデザインを確認するためのもので、実装の対象ではない。ホバー・フォーカスなどのインタラクションの状態は疑似クラスで書き、この切り替えに含めない。

## スコープ外

- ダークモード。Figma の Variables は Light モードだけを持つ
- 端末のステータスバー（Figma のフレームの `Status`）。端末の表示で、ページの要素ではない
- 地図の実データ。地図は Figma の MapCanvas の見た目で示す

### 補ったもの

- 全画面のタブレット（768px〜）とデスクトップ（1024px〜）の表示。「レスポンシブ戦略」のとおり
- Figma に無い画面（上の表の「補った」）。管理側の部品と閲覧側の部品から作った
- `spec/pages/` にあって Figma に無い状態。各 HTML の状態の切り替えに載っていて、Figma のフレームを持たないもの
- `--transition-default`。Figma はトランジションを持たない
- 書体のフォールバック: Noto Serif JP → `serif`、Noto Sans JP → `sans-serif`。どちらも Google Fonts から読み込めるため、フォールバックは総称だけにした
- `--color-scrim`（重なる面の背景）と `--color-green-hover`（Button Primary のホバー）。Figma はどちらの値も持たない
- Figma のフレームにあるデバイスのステータスバー（Status）は取り込まない
- 外部アカウントの提供元の名前「Google」「Apple」（MY-02）はサンプルのラベル。spec は提供元を定めない

- 画面の左右の余白の `md` 以上での値（`--space-gutter` を 32px に上書き）
