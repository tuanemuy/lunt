# イベント

店舗のイベントへの参加・取りやめ・除外と、イベント運営者・サービス運営者によるイベントの運営を扱う。

## 共通の規則

- 店舗管理者のいる店舗の参加は、店舗管理者の参加申請をイベントの運営者が承認して成立する。店舗管理者のいない店舗の参加は、イベント運営者による直接の追加で成立する。利用者は、店舗管理者のいない店舗の参加を申請できない（E-05、E-11、B-36）
- 店舗とイベントの関係は、申請中と参加中を区別して示す。参加は取りやめまたは除外で解除される（P-85）
- 参加には、掲載と参加日を添えられる。どちらも任意で、それぞれ複数添えられる。添えられるのは、その店舗の公開中で、提供中または提供開始前の掲載。イベント運営者による直接の追加でも同じ（P-46、E-11）
- 参加日は、イベントの開催期間内の日付に限る。開催期間の変更で期間外になった参加日は、閲覧者に表示されない
- 参加の承認・取りやめ・除外・直接の追加と参加内容の変更は、イベントの参加店舗と、店舗・掲載のイベント情報の両方に反映される（E-08）。店舗と掲載の公開状態・提供状態は変わらない（B-06）
- 公開中の対象の表示は、[index.md](index.md) の「表示範囲」による。イベント詳細の参加店舗と添えた掲載は参照の場面で、提供開始前の掲載と、添えた後に提供終了になった掲載は、状態を区別して表示される（V-26）
- イベントの開催前・開催中・終了は、開催期間と日本時間の日付で自動で決まる。中止は日付では決まらず、EVT-11 の操作で設定し、取り消す（P-84、I-08）
- 終了・中止したイベントは、発見の場面に表示されず、参照の場面で終了・中止を区別して表示される
- 参加内容の変更、取りやめ、直接の追加、除外、中止、中止の取り消しは、開催の状態にかかわらず行える。参加の申請だけが、開催前・開催中のイベントに限られる。閲覧できないイベントには、参加を申請できない
- 公開を取り下げたイベントと運営による非公開のイベントは、閲覧者のどの場面にも表示されない。参加関係は保たれ、店舗管理者のイベントの状況には、イベントの状態と分かるように示される。こうしたイベントへの参加も、参加内容の変更と取りやめができる
- 開催地域の関連づけの相手（地域）が公開を取り下げた、または運営による非公開の間、関連づけは保たれ、イベント運営者の関連する地域の確認には、地域の状態と分かるように示される
- 参加申請の承認者は対象イベントのイベント運営者。イベント運営者が不在のイベントではサービス運営者（E-09）。イベント運営者が一定の期間確認しない申請は、サービス運営者が APP-08 で代行して承認・否認できる
- 同じ店舗が、同じイベントへの確認中・差し戻し中の参加申請を持つ間は、重ねて申請できない
- 確認中・差し戻し中の参加申請の失効は、[index.md](index.md) の「申請の前提」による。前提を欠く申請は承認もできない。参加の申請には、イベントの開催の状態と参加の有無の前提と、店舗管理者がいることの前提の両方が当たる。前提を失って失効した申請は、前提が再び成り立っても戻らない（I-08、I-19）
- 確認中・差し戻し中の参加申請は、イベントが運営による非公開になっても、店舗が非公開になっても失効しない。承認者が判断する
- 否認・取り下げ・失効の後の再申請は APP-04 による。前の申請の掲載・参加日が入った状態で始まり、新しい申請として提出される
- 店舗管理者として行った申請の申請者宛ての通知の宛先は `application.md` の共通の規則が、店舗管理者・イベント運営者・地域運営者が不在の対象への通知の宛先と通知から進む先は [index.md](index.md) の「不在の対象への通知」が定める
- 他の人が先に保存した対象を保存しようとすると、競合が示される。最新の内容を読み直して操作し直す
- 申請の確認・再提出・取り下げ・再申請・失効と、承認・否認・差し戻しの共通の流れは APP-01〜APP-08 による。店舗管理者として行った申請は、その店舗のすべての店舗管理者が扱える（APP-06）
- イベント運営者の権限は、イベント情報と参加関係の管理に限る。参加店舗の情報・掲載を更新するには、その店舗の管理権限が要る（E-04）
- 管理権限のない利用者は、イベントの情報修正を申請できない。入口は示されない（P-51、B-43）
- イベントの開催場所の所在地の入力と、その入力エラーは、[index.md](index.md) の「所在地の入力」が定める。イベントのエリアはこの所在地から決まる
- イベントは地域から独立する。開催地域の関連づけは、店舗の地域所属、イベント参加、店舗・掲載の公開状態・提供状態に影響しない（B-15、AC-73）
- イベントの公開状態は 下書き・公開・公開の取り下げ。運営による非公開はそれとは別の状態で、その間に行える操作と解除の後の公開状態は [index.md](index.md) の「運営による非公開」が定める（E-15）。中止と中止の取り消しは公開状態の変更ではなく、その間も行える
- 写真の登録のたびの同意と、その入力エラーは、[index.md](index.md) の「写真の登録と同意」が定める
- イベント運営者の管理メンバーの招待・辞任・解除は MEM-01〜MEM-05 による
- サービス運営者が行う EVT-12・EVT-13 の入口と、サービス運営者でない利用者がたどり着いたときの扱いは、[index.md](index.md) の「サービス運営者の操作」が定める

## EVT-01 掲載と参加日を添えてイベントへの参加を申請する

- 利用者: 店舗管理者
- 契約: E-05、E-07、P-17、P-46、P-70（15 行）、P-74、P-77（b・g）、P-85、I-08、UC-14、AC-17
- 前提: ログインしている。店舗の管理権限を持つ。対象のイベントが公開中で、開催前または開催中

### 流れ

1. 管理する店舗のイベントの状況を開く。参加中のイベントと、申請中のイベントを確認する
2. 参加するイベントを、開催前・開催中のイベントから探して選ぶ。イベントの詳細（開催期間・開催場所・紹介）を確認する
3. 参加の申請を始める。その店舗の公開中で、提供中または提供開始前の掲載から、イベントで提供する掲載を選んで添える。開催期間内の日付から、参加日を添える。掲載も参加日も複数添えられ、添えずに申請することもできる
4. 内容を確認して申請する。申請は確認中になり、そのイベントとの関係が申請中として示される
5. 対象イベントのイベント運営者に、新しい申請が通知される。イベント運営者が不在のイベントでは、サービス運営者に通知される
6. 確認状況と結果は APP-01 で確認する。承認されると通知を受け、参加が成立する。イベント詳細の参加店舗に、店舗と添えた掲載・参加日が表示される。店舗詳細と掲載詳細の関連するイベントに、イベントが表示される

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー（P-46） | 下書き・一時非公開・運営による非公開の掲載と、提供終了の掲載は、添える対象に示されない | 公開中で提供中または提供開始前の掲載から選ぶ。掲載を添えずに申請することもできる。添えたい掲載が未公開なら、先に LST-04 で公開する |
| 入力エラー | 開催期間の外の日付を参加日にした。申請できないことが示される | 開催期間内の日付に直す |
| 権限不足 | 管理権限のない店舗では、参加申請の入口が示されない。直接たどり着いても申請できないことが示される。店舗管理者のいない店舗の参加を、利用者は申請できない | 店舗の関係者は SHP-04 で管理権限を申請する |
| 権限不足 | 申請の途中で管理権限を失った。申請できないことが示される | 申請をやめる |
| リソース不在 | 選んだイベントが、公開を取り下げられた、または運営による非公開になった。閲覧できないことが示され、申請できない | 別のイベントを選ぶ |
| 契約（申請の前提） | 選んだイベントが終了または中止している。申請できないことが示される | 別のイベントを選ぶ |
| 契約（申請の前提） | すでに参加中のイベントを選んだ。参加中であることが示され、申請できない | 参加内容は EVT-02 で変更する |
| 契約（P-74） | その店舗からそのイベントへの参加申請が、すでに確認中または差し戻し中にある。申請中であることが示され、重ねて申請できない | APP-01 でその申請を確認する。同じ店舗の別の店舗管理者が行った申請も扱える（APP-06） |
| 契約（申請の前提） | 確認中・差し戻し中に、イベントが終了または中止した。申請は前提を失って失効し、通知を受ける。延期または中止の取り消しでイベントが開催前・開催中に戻っても、失効した申請は戻らない | イベントが開催前・開催中に戻った場合は、APP-04 で再申請する |
| 契約（申請の前提） | 確認中・差し戻し中に、店舗の店舗管理者が不在になった。申請は前提を失って失効する | APP-05 による |
| 契約（P-71） | 否認された。理由を確認できる。差し戻された場合は追加で必要な確認が示される | 否認は APP-04 で再申請する。差し戻しは APP-02 で掲載・参加日を修正して再提出する |
| 操作の取り消し | 申請する前にやめた。申請は作られない | イベントの状況に戻る |
| 操作の取り消し | 申請した後にやめたい | APP-03 で取り下げる |

## EVT-02 参加に添えた掲載・参加日を変更する

- 利用者: 店舗管理者
- 契約: E-08、E-10、E-11、P-46、P-70（16 行）、P-93、P-95、B-26、AC-26、AC-33
- 前提: ログインしている。店舗の管理権限を持つ。店舗が対象のイベントに参加中

### 流れ

1. 管理する店舗のイベントの状況から、参加中のイベントを開く。公開を取り下げたイベント・運営による非公開のイベントも、その状態と分かるように示され、開ける。現在添えている掲載と参加日を確認する。店舗管理者のいなかった時期にイベント運営者が追加した参加も含まれる
2. 添える掲載を追加し、外す。参加日を追加し、外す。終了・中止したイベントの参加内容も変更できる。添える掲載は、その店舗の公開中で、提供中または提供開始前の掲載から選ぶ。参加日は開催期間内の日付にする
3. 保存する。承認は要らず、保存した時点でイベント詳細の参加店舗と、掲載詳細の関連するイベントに反映される
4. イベント運営者に、参加内容の変更が通知される。イベント運営者が不在のイベントでは、サービス運営者に通知される
5. 参加するイベントの開催期間が変更されると、店舗のすべての店舗管理者に通知が届く。期間外になった参加日は閲覧者に表示されない。通知を受けて、参加日を開催期間内の日付に変更する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー（P-46） | 下書き・一時非公開・運営による非公開の掲載と、提供終了の掲載は、新たに添える対象に示されない。すでに添えた掲載が提供終了になっても、添えたまま状態を区別して表示される | 公開中で提供中または提供開始前の掲載から選ぶ |
| 入力エラー | 開催期間の外の日付を参加日にした。保存できないことが示される | 開催期間内の日付に直す |
| 権限不足 | 管理権限のない店舗の参加内容は変更できない。入口が示されず、直接たどり着いても操作できないことが示される | 操作をやめる |
| リソース不在 | 保存するまでの間に、イベント運営者が店舗を除外した、または別の店舗管理者が参加を取りやめた。参加していないことが示され、保存できない | 再び参加するには EVT-01 で申請する |
| リソース不在 | イベントが公開を取り下げられた、または運営による非公開になっている。その状態が示され、参加内容は変更できる。変更は、イベントが再び閲覧できるようになるまで閲覧者に表示されない | 変更を続ける。参加をやめる場合は EVT-03 で取りやめる |
| 操作の取り消し | 保存せずに変更をやめた。参加内容は変わらない | イベントの状況に戻る |
| 操作の取り消し | 保存した後に元へ戻したい | もう一度変更して保存する |

## EVT-03 参加を取りやめる

- 利用者: 店舗管理者
- 契約: E-08、E-10、E-11、P-70（16 行）、P-85、P-95、B-06、B-26、AC-26、AC-33
- 前提: ログインしている。店舗の管理権限を持つ。店舗が対象のイベントに参加中

### 流れ

1. 管理する店舗のイベントの状況から、参加中のイベントを開く。公開を取り下げたイベント・運営による非公開のイベントも、その状態と分かるように示され、開ける
2. 参加を取りやめる。承認は要らない。イベントの開催の状態と公開状態にかかわらず取りやめられる
3. 参加が解除される。イベント詳細の参加店舗から店舗と添えた掲載が外れ、店舗詳細と掲載詳細の関連するイベントからイベントが外れる。店舗と掲載の公開状態・提供状態は変わらない
4. イベント運営者に、参加の取りやめが通知される。イベント運営者が不在のイベントでは、サービス運営者に通知される

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 権限不足 | 管理権限のない店舗の参加は取りやめられない。入口が示されず、直接たどり着いても操作できないことが示される | 操作をやめる |
| リソース不在 | 取りやめるまでの間に、除外または別の店舗管理者の取りやめで参加が解除されていた。参加していないことが示される | イベントの状況に戻る |
| 操作の取り消し | 実行する前にやめた。参加は続く | イベントの状況に戻る |
| 操作の取り消し | 取りやめた後に参加へ戻したい。取りやめは取り消せない | EVT-01 で参加を申請する。申請できるのは、イベントが開催前・開催中の間に限られる |
| 操作の取り消し | 参加中ではなく、申請中の参加をやめたい | APP-03 で申請を取り下げる |

## EVT-04 イベント情報を更新する（延期を含む）

- 利用者: イベント運営者
- 契約: E-01、E-04、E-13、E-14、M-37、P-12、P-17、P-51、P-77（g）、P-84、P-93、B-41、B-43、B-53、I-06、I-08、AC-18、AC-61
- 前提: ログインしている。イベントの管理権限を持つ

### 流れ

1. 管理するイベントの情報を開く
2. 名称・開催期間・開催場所（所在地・位置）・写真・紹介・キャッチコピーを編集する。写真は複数登録でき、並び替えられる。1枚目が代表写真になる。関連する地域は EVT-05 で扱う
3. 写真を登録するときは、登録のたびに同意を確認する
4. 保存する。公開中のイベントでは、保存した時点で閲覧者に反映される。イベントのエリアは、開催場所の所在地から決まる
5. 延期は、開催期間の更新で行う。開催の状態は、更新後の開催期間と日付で決まる。終了したイベントの開催期間を未来へ更新すると、開催前または開催中に戻り、発見の場面に再び表示される
6. 開催期間を変更すると、参加店舗の店舗管理者に通知される。参加中の店舗の参加は保たれる。期間外になった参加日は閲覧者に表示されず、店舗管理者が EVT-02 で変更する。店舗管理者のいない店舗の参加日は、EVT-10 で変更する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー（E-13） | 公開中のイベントで、名称・開催期間・開催場所・写真のいずれかを欠く内容を保存しようとした。不足する項目が示され、保存できない | 不足を埋めて保存する。欠いたまま保存するなら、先に EVT-06 で公開を取り下げる |
| 入力エラー | 開催期間の終了日が開始日より前になっている。保存できない | 開催期間を直して保存する |
| 権限不足 | 管理権限のない利用者には、イベント情報の更新の入口が示されない。情報修正の申請もできない（P-51、B-43） | 操作をやめる |
| 権限不足（E-04） | 参加店舗の情報や掲載を更新しようとした。イベント運営者の権限ではできない | その店舗の管理権限を持つ場合に限り、SHP-06・LST-06 で更新する |
| リソース不在 | 編集の途中で管理権限を解除された。保存できず、操作できないことが示される | 操作をやめる |
| 契約（E-15） | イベントが運営による非公開になっている。イベント情報は更新できるが、解除まで閲覧者に表示されない | 更新を続ける。公開状態は解除の後に EVT-06 で変更する |
| 契約（申請の前提、I-08） | 開催期間の更新でイベントが終了になった。参加申請は申請の前提により失効する。期間を未来へ更新し直しても、失効した申請は戻らない | 参加を希望する店舗管理者の再申請（APP-04）を待つ |
| 契約（E-14） | 中止したイベントの開催期間を更新した。開催期間は更新されるが、中止のまま | 開催する場合は EVT-11 で中止を取り消す |
| 操作の取り消し | 保存せずに編集をやめた。変更は残らない | イベントの管理に戻る |

## EVT-05 開催地域を関連づける

- 利用者: イベント運営者
- 契約: E-01、E-12、R-13、P-17、P-70（19 行）、P-94、P-95、B-15、B-37、AC-34、AC-73
- 前提: ログインしている。イベントの管理権限を持つ

### 流れ

1. 管理するイベントの関連する地域を開く。関連づけている地域を確認する。公開を取り下げた地域・運営による非公開の地域は、その状態と分かるように示される
2. 公開中の地域から開催地域を探して選び、関連づける。複数の地域を関連づけられる。地域運営者の承認は要らない
3. 関連づけた時点で、イベント詳細の関連する地域と、地域詳細の関連するイベントに反映される。地域の地域運営者に、関連づけが通知される

6. 参加店舗と参加の申請を確認し、申請を承認・否認・差し戻しする。操作と異常系は EVT-07・EVT-08 と同じ
7. 参加店舗を除外する。操作と異常系は EVT-09 と同じ
8. 店舗管理者のいない店舗を参加店舗として追加し、参加内容を変更する。操作と異常系は EVT-10 と同じ
9. イベントは、運営者が不在の間も公開を継続する。EVT-12 で管理権限を付与すると、以後はイベント運営者が管理する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 契約（E-15、P-70 の 17・18・21・26 行） | イベント運営者のいるイベントを、更新・開催地域の関連づけ・公開・取り下げ・中止・除外・店舗の追加の対象にしようとした。代行できないことが示される | 確認されない申請は APP-08 で代行する。イベントを閲覧できなくするには MOD-07、イベント運営者の権限を解くには MEM-05 による |
| 契約（E-15） | イベントが運営による非公開になっている。イベント情報は更新できるが、公開も公開の取り下げもできないことが示される | MOD-07 で解除する |
| リソース不在 | 操作するまでの間に、別のサービス運営者がイベント運営者に管理権限を付与した。代行できないことが示される | 操作をやめ、イベント運営者に任せる |
| リソース不在 | 判断するまでの間に、申請が取り下げ・失効となった、または別のサービス運営者が判断した。その状態が示される | 申請の一覧に戻る |
