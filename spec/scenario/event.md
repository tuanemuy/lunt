# イベント

店舗のイベントへの参加・取りやめ・除外と、イベントの運営者によるイベントの運営を扱う。

## 共通の規則

- イベントの運営者は、[index.md](index.md) の「利用者」が定める（イベント運営者のいるイベントではそのイベント運営者、不在のイベントではサービス運営者）。EVT-04〜EVT-11 はイベントの運営者が行う
- 店舗管理者のいる店舗の参加は、店舗管理者の参加申請をイベントの運営者が承認して成立する。管理者のいない店舗の参加は、イベントの運営者による直接の追加で成立する。利用者は、管理者のいない店舗の参加を申請できない（E-05、E-11、B-36）
- 店舗とイベントの関係は、申請中と参加中を区別して示す。参加は取りやめまたは除外で解除される（P-85）
- 参加には、掲載と参加日を添えられる。どちらも任意で、それぞれ複数添えられる。添えられるのは、その店舗の公開中の掲載で、提供状態（提供開始前・提供中・提供終了）を問わない。イベントの運営者による直接の追加でも同じ（P-46、E-11、I-22）。新たに添える掲載は、提出・再提出・直接の追加・保存の時点でも確かめる。選んだ掲載がその時点までに公開中でなくなっていれば（一時非公開・運営による非公開・削除）、提出・追加・保存できないことが示され、最新の添えられる掲載から選び直す
- 添えた掲載が、削除・一時非公開・運営による非公開になっても、参加内容と、確認中・差し戻し中の参加申請の内容から外さない。承認すると、申請の内容のまま参加内容になる。閲覧者には、添えた掲載のうち閲覧できるものだけを示し、再公開・解除で閲覧できるようになると再び示す。店舗管理者とイベントの運営者には、閲覧できない掲載も状態とともに示す。外すのは、参加内容の変更（EVT-02、EVT-10）と差し戻し後の再提出（APP-02）による
- 参加日は、イベントの開催期間内の日付に限る。開催期間の変更で期間外になった参加日は、閲覧者に表示されない
- 参加の承認・取りやめ・除外・直接の追加と参加内容の変更は、イベントの参加店舗と、店舗・掲載のイベント情報の両方に反映される（E-08）。店舗と掲載の公開状態・提供状態は変わらない（B-06）
- 公開中の対象の表示は、[index.md](index.md) の「表示範囲」による。イベント詳細の参加店舗と添えた掲載は参照の場面で、提供開始前・提供終了の掲載は、状態を区別して表示される（V-26）
- イベントの開催前・開催中・終了は、開催期間と日本時間の日付で自動で決まる。中止は日付では決まらず、EVT-11 の操作で設定し、取り消す（P-84、I-08）
- 終了・中止したイベントは、発見の場面に表示されず、参照の場面で終了・中止を区別して表示される
- 参加内容の変更、取りやめ、直接の追加、除外、中止、中止の取り消しは、開催の状態にかかわらず行える。参加の申請だけが、開催前・開催中のイベントに限られる。閲覧できないイベントには、参加を申請できない
- 未公開のイベントと運営による非公開のイベントは、閲覧者のどの場面にも表示されない。参加関係は保たれ、店舗管理者のイベントの状況には、イベントの状態と分かるように示される。こうしたイベントへの参加も、参加内容の変更と取りやめができる
- 開催地域の関連づけの相手（地域）が未公開、または運営による非公開の間、関連づけは保たれ、イベントの運営者の関連する地域の確認には、地域の状態と分かるように示される
- 参加申請の承認者は、対象イベントのイベントの運営者（E-09）。イベント運営者が一定の期間確認しない申請は、サービス運営者が期間超過の代行（APP-08）で承認・否認できる
- 重ねて申請できない規則と、その異常系は、[index.md](index.md) の「重ねて申請できない」が定める。参加の申請の申請者は店舗、対象は店舗とイベントの組
- 確認中・差し戻し中の参加申請の失効は、[index.md](index.md) の「申請の前提」による。前提を欠く申請は承認もできない。参加の申請には、イベントの開催の状態と参加の有無の前提と、店舗管理者がいることの前提の両方が当たる。前提を失って失効した申請は、前提が再び成り立っても戻らない（I-08、I-19）
- 対象のイベント・店舗が非公開になっても、確認中・差し戻し中の参加申請は失効しない（`application.md` の共通の規則）
- 否認・取り下げ・失効の後の再申請は APP-04 による。前の申請の掲載・参加日が入った状態で始まり、新しい申請として提出される。前の申請の掲載のうち、その時点で添えられない掲載（一時非公開・運営による非公開・削除）と、開催期間の外になった参加日は、始まりの内容から外され、外されたことが示される
- 通知は ACC-03 の表による。店舗管理者として行った申請の申請者宛ての通知の宛先は `application.md` の共通の規則が、店舗管理者・イベント運営者・地域運営者が不在の対象への通知の宛先と通知から進む先は [index.md](index.md) の「不在の対象への通知」が定める
- 同時編集の競合と、その異常系は、[index.md](index.md) の「同時編集の競合」が定める
- 申請の確認・再提出・取り下げ・再申請・失効と、承認・否認・差し戻しの共通の流れは APP-01〜APP-08 による。店舗管理者として行った申請は、その店舗のすべての店舗管理者が扱える（APP-06）
- イベントの運営者の権限は、イベント情報と参加関係の管理に限る。参加店舗の情報・掲載を更新するには、その店舗の管理権限が要る（E-04）
- 管理権限のない利用者は、イベントの情報修正を申請できない。入口は示されない（P-51、B-43）
- イベントの開催場所の所在地の入力と、その入力エラーは、[index.md](index.md) の「所在地の入力」が定める。イベントのエリアはこの所在地から決まる
- イベントは地域から独立する。開催地域の関連づけは、店舗の地域所属、イベント参加、店舗・掲載の公開状態・提供状態に影響しない（B-15、AC-73）
- イベントの公開状態は 下書き・公開・公開の取り下げ。下書きと公開の取り下げは未公開（[index.md](index.md) の「用語」）。運営による非公開はそれとは別の状態で、その間に行える操作と解除の後の公開状態は [index.md](index.md) の「運営による非公開」が定める（E-15）。中止と中止の取り消しは公開状態の変更ではなく、その間も行える
- 写真の登録のたびの同意と、その入力エラーは、[index.md](index.md) の「写真の登録と同意」が定める
- イベント運営者の管理メンバーの招待・辞任・解除は MEM-01〜MEM-05 による
- サービス運営者が行う EVT-12・EVT-13 の入口と、サービス運営者でない利用者がたどり着いたときの扱いは、[index.md](index.md) の「サービス運営者の操作」が定める
- 操作の途中で、店舗の管理権限を失った店舗管理者、またはイベントのイベントの運営者でなくなった利用者の扱いは、[index.md](index.md) の「立場を失ったとき」が定める
- イベントの運営者に共通の異常系（EVT-04〜EVT-11）は、[region.md](region.md) の地域の運営者に共通の異常系を、下の読み替えの表で読み替えて当てる（E-15、P-70 の 17・18・21・26 行）

## EVT-01 掲載と参加日を添えてイベントへの参加を申請する

- 利用者: 店舗管理者
- 契約: E-05、E-07、P-17、P-46、P-70（15 行）、P-74、P-77（b・g）、P-85、I-08、I-22、UC-14、AC-17
- 前提: ログインしている。店舗の管理権限を持つ。対象のイベントが公開中で、開催前または開催中

### 流れ

1. 管理する店舗のイベントの状況を開く。参加中のイベントと、申請中のイベントを確認する
2. 参加するイベントを、公開中で開催前・開催中のイベントからキーワードで探して選ぶ（[index.md](index.md) の「探し方」）。イベントの詳細（開催期間・開催場所・紹介）を確認する。または、閲覧中のイベントの詳細（EXP-09）から参加の申請へ進み、管理する店舗を選ぶ（管理する店舗が1つなら選ばない）。このときは、そのイベントが選ばれた状態で手順3へ進む
3. 参加の申請を始める。その店舗の公開中の掲載から、イベントで提供する掲載を選んで添える。開催期間内の日付から、参加日を添える。掲載も参加日も複数添えられ、添えずに申請することもできる
4. 内容を確認して申請する。申請は確認中になり、そのイベントとの関係が申請中として示される
5. 確認状況と結果は APP-01 で確認する。承認されると参加が成立する。イベント詳細の参加店舗に、店舗と添えた掲載・参加日が表示される。店舗詳細と掲載詳細の関連するイベントに、イベントが表示される

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー（P-46、I-22） | 下書き・一時非公開・運営による非公開の掲載は、添える対象に示されない | 公開中の掲載から選ぶ。掲載を添えずに申請することもできる。添えたい掲載が下書きなら先に LST-04 で公開し、一時非公開なら先に LST-07 で再公開する |
| 入力エラー | 開催期間の外の日付を参加日にした。申請できないことが示される | 開催期間内の日付に直す |
| 権限不足 | 管理権限のない店舗では、参加申請の入口が示されない。直接たどり着いても申請できないことが示される。管理者のいない店舗の参加を、利用者は申請できない | 店舗の関係者は SHP-04 で管理権限を申請する |
| リソース不在 | 選んだイベントが、公開を取り下げられた、または運営による非公開になった。閲覧できないことが示され、申請できない | 別のイベントを選ぶ |
| 契約（申請の前提） | イベントの詳細から始めたイベントが終了または中止している。または選んだイベントが、申請するまでの間に終了または中止した。申請できないことが示される | 別のイベントを選ぶ |
| 契約（申請の前提） | すでに参加中のイベントは、キーワードの候補では参加中を理由に選べない対象として示される。イベントの詳細から始めた場合は、参加中であることが示され、申請できない | 別のイベントを選ぶ。参加内容は EVT-02 で変更する |
| 契約（申請の前提） | 確認中・差し戻し中に、イベントが終了または中止した。申請は前提を失って失効する。延期または中止の取り消しでイベントが開催前・開催中に戻っても、失効した申請は戻らない | イベントが開催前・開催中に戻った場合は、APP-04 で再申請する |
| 契約（申請の前提） | 確認中・差し戻し中に、店舗の店舗管理者が不在になった。申請は前提を失って失効する | APP-05 による |
| 契約（P-71） | 否認された。理由を確認できる。差し戻された場合は追加で必要な確認が示される | 否認は APP-04 で再申請する。差し戻しは APP-02 で掲載・参加日を修正して再提出する |
| 操作の取り消し | 申請する前にやめた。申請は作られない | イベントの状況に戻る |
| 操作の取り消し | 申請した後にやめたい | APP-03 で取り下げる |

## EVT-02 参加に添えた掲載・参加日を変更する

- 利用者: 店舗管理者
- 契約: E-08、E-10、E-11、P-46、P-70（16 行）、P-93、P-95、B-26、I-22、AC-26、AC-33
- 前提: ログインしている。店舗の管理権限を持つ。店舗が対象のイベントに参加中

### 流れ

1. 管理する店舗のイベントの状況から、参加中のイベントを開く。未公開のイベント・運営による非公開のイベントも、その状態と分かるように示され、開ける。現在添えている掲載と参加日を確認する。閲覧できなくなった掲載は、状態とともに示される（共通の規則）。店舗管理者のいなかった時期にイベントの運営者が追加した参加も含まれる
2. 添える掲載を追加し、外す。参加日を追加し、外す。終了・中止したイベントの参加内容も変更できる。添える掲載は、その店舗の公開中の掲載から選ぶ。参加日は開催期間内の日付にする
3. 保存する。承認は要らず、保存した時点でイベント詳細の参加店舗と、掲載詳細の関連するイベントに反映される
4. 参加するイベントの開催期間が変更されると、期間外になった参加日は閲覧者に表示されない。店舗管理者は、開催期間の変更の通知から参加内容を開き、参加日を開催期間内の日付に変更する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー（P-46、I-22） | 下書き・一時非公開・運営による非公開の掲載は、新たに添える対象に示されない | 公開中の掲載から選ぶ |
| 入力エラー | 開催期間の外の日付を参加日にした。保存できないことが示される | 開催期間内の日付に直す |
| 権限不足 | 管理権限のない店舗の参加内容は変更できない。入口が示されず、直接たどり着いても操作できないことが示される | 操作をやめる |
| リソース不在 | 保存するまでの間に、イベントの運営者が店舗を除外した、または別の店舗管理者が参加を取りやめた。参加していないことが示され、保存できない | 再び参加するには EVT-01 で申請する |
| リソース不在 | イベントが公開を取り下げられた、または運営による非公開になっている。その状態が示され、参加内容は変更できる。変更は、イベントが再び閲覧できるようになるまで閲覧者に表示されない | 変更を続ける。参加をやめる場合は EVT-03 で取りやめる |
| 操作の取り消し | 保存せずに変更をやめた。参加内容は変わらない | イベントの状況に戻る |
| 操作の取り消し | 保存した後に元へ戻したい | もう一度変更して保存する |

## EVT-03 参加を取りやめる

- 利用者: 店舗管理者
- 契約: E-08、E-10、E-11、P-70（16 行）、P-85、P-95、B-06、B-26、AC-26、AC-33
- 前提: ログインしている。店舗の管理権限を持つ。店舗が対象のイベントに参加中

### 流れ

1. 管理する店舗のイベントの状況から、参加中のイベントを開く。未公開のイベント・運営による非公開のイベントも、その状態と分かるように示され、開ける
2. 参加を取りやめる。承認は要らない。イベントの開催の状態と公開状態にかかわらず取りやめられる
3. 参加が解除される。イベント詳細の参加店舗から店舗と添えた掲載が外れ、店舗詳細と掲載詳細の関連するイベントからイベントが外れる。店舗と掲載の公開状態・提供状態は変わらない

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 権限不足 | 管理権限のない店舗の参加は取りやめられない。入口が示されず、直接たどり着いても操作できないことが示される | 操作をやめる |
| リソース不在 | 取りやめるまでの間に、除外または別の店舗管理者の取りやめで参加が解除されていた。参加していないことが示される | イベントの状況に戻る |
| 操作の取り消し | 実行する前にやめた。参加は続く | イベントの状況に戻る |
| 操作の取り消し | 取りやめた後に参加へ戻したい。取りやめは取り消せない | EVT-01 で参加を申請する。申請できるのは、イベントが開催前・開催中の間に限られる |
| 操作の取り消し | 参加中ではなく、申請中の参加をやめたい | APP-03 で申請を取り下げる |

## EVT-04 イベント情報を更新する（延期を含む）

- 利用者: イベントの運営者
- 契約: E-01、E-04、E-13、E-14、M-37、P-12、P-17、P-51、P-77（g）、P-84、P-93、B-41、B-43、B-53、I-06、I-08、AC-18、AC-61、AC-74
- 前提: ログインしている。対象のイベントのイベントの運営者である

### 流れ

1. REG-06 の手順1〜4を、読み替えの表で読み替えて行う。関連する地域は EVT-05 で扱う
2. イベントのエリアは、開催場所の所在地から決まる
3. 延期は、開催期間の更新で行う。開催の状態は、更新後の開催期間と日付で決まる。終了したイベントの開催期間を未来へ更新すると、開催前または開催中に戻り、発見の場面に再び表示される
4. 開催期間を変更しても、参加中の店舗の参加は保たれる。期間外になった参加日は閲覧者に表示されず、店舗管理者が EVT-02 で変更する。管理者のいない店舗の参加日は、EVT-10 で変更する

### 異常系

REG-06 の異常系を、読み替えの表で読み替えて当てる。加えて、次の異常系がある。

## EVT-05 開催地域を関連づける

- 利用者: イベントの運営者
- 契約: E-01、E-12、R-13、P-17、P-70（19 行）、P-94、P-95、B-15、B-37、AC-34、AC-73
- 前提: ログインしている。対象のイベントのイベントの運営者である

### 流れ

1. 管理するイベントの関連する地域を開く。関連づけている地域を確認する。未公開の地域・運営による非公開の地域は、その状態と分かるように示される
2. 公開中の地域から開催地域をキーワードで探して選び（[index.md](index.md) の「探し方」）、関連づける。複数の地域を関連づけられる。地域の運営者の承認は要らない
3. 関連づけた時点で、イベント詳細の関連する地域と、地域詳細の関連するイベントに反映される
4. 関連づけた地域を外す。外した地域は、あらためて関連づけられる
5. 地域の運営者が関連づけを解除すると（REG-11）、その地域は関連する地域から外れ、再び関連づけられない。地域の運営者が解除を取り消すと、関連づけが回復する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 契約（E-12） | 地域の運営者が関連づけを解除した地域は、候補の中で、解除されていることを理由に選べない対象として示される。選んだ後、関連づけるまでの間に解除された場合も、関連づけられないことが示される | 別の地域を選ぶ。または地域の運営者による解除の取り消しを待つ |
| 入力エラー | すでに関連づけている地域は、候補の中で、関連づけ済みを理由に選べない対象として示される。選んだ後、関連づけるまでの間に別のイベントの運営者が関連づけた場合は、関連づけ済みであることが示される | 別の地域を選ぶ |
| リソース不在 | 選んだ地域が、公開を取り下げられた、または運営による非公開になった。閲覧できないことが示され、関連づけられない | 別の地域を選ぶ |
| 操作の取り消し | 関連づけを元に戻したい | 関連づけた地域を外す |

## EVT-07 参加店舗、参加の申請、参加内容の変更を確認する

- 利用者: イベントの運営者
- 契約: E-03、E-04、E-10、E-11、P-85、P-92、P-95、AC-61
- 前提: ログインしている。対象のイベントのイベントの運営者である

### 流れ

1. 管理するイベントを開く
2. 参加中の店舗の一覧を確認する。店舗ごとに、添えた掲載と参加日、店舗管理者がいるかどうかが分かる。各店舗と掲載の詳細へ進める
3. 参加の申請を確認する。対象の店舗、添えた掲載・参加日、確認中か差し戻し中かが分かる。申請についての通知から開いてもよい
4. 店舗管理者による参加の取りやめと、添えた掲載・参加日の変更を、その通知から開いて確認する
5. 確認中の申請を選び、EVT-08 で判断する。参加店舗を選び、EVT-09 で除外する。管理者のいない店舗は、EVT-10 で参加内容を変更する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 権限不足（E-04） | 参加店舗の情報や掲載は、この確認から更新できない。店舗管理者のいる店舗の参加内容も変更できない | 店舗の管理権限を持つ場合に限り、店舗の管理から更新する |
| リソース不在 | 参加店舗がない、または申請がない。ないことが示される | イベントの管理に戻る。管理者のいない店舗は EVT-10 で追加できる |
| リソース不在 | 通知から開いた申請が、取り下げ・失効となった、またはサービス運営者の期間超過の代行で判断済みだった。その状態が示される | 申請の一覧に戻る |
| リソース不在 | 変更の通知から開いた店舗が、その後に参加を取りやめていた。参加していないことが示される | 参加店舗の一覧に戻る |

## EVT-08 参加の申請を判断する

- 利用者: イベントの運営者
- 契約: E-05、E-08、E-09、P-70（15 行）、P-71、P-77（g）、P-78、B-06、B-42、AC-17
- 前提: ログインしている。対象のイベントのイベントの運営者である。対象の申請が確認中

### 流れ

1. EVT-07 から確認中の申請を開く。対象の店舗、添えた掲載、参加日を確認する。店舗と掲載の詳細を確認できる
2. 承認・否認・差し戻しのいずれかを行う。共通の流れは APP-07 による。添えた掲載・参加日の見直しが必要な申請は、差し戻す
3. 承認すると参加が成立する。イベント詳細の参加店舗に、店舗と添えた掲載・参加日が表示される。店舗詳細と掲載詳細の関連するイベントに、イベントが表示される。店舗と掲載の公開状態・提供状態は変わらない
4. 店舗管理者を兼ねるイベントの運営者は、自分が行った申請も承認できる（P-04）

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー | 理由を添えずに否認しようとした | APP-07 による |
| リソース不在 | 判断するまでの間に、申請が取り下げられた、または前提を失って失効した。判断できないことが示される。前提を欠く申請は承認できない | EVT-07 の申請の一覧に戻る |
| 契約（申請の前提） | イベントが終了または中止し、参加申請がすべて失効した。判断できない | 延期または中止の取り消しの後は、店舗管理者の再申請（APP-04）を待つ |
| 契約（P-78） | 一定の期間確認しなかった申請を、サービス運営者が期間超過の代行で判断した（APP-08）。判断済みであることが示される | EVT-07 で結果を確認する |
| 操作の取り消し | 承認した後に取り消したい。承認は取り消せない | EVT-09 で店舗を除外する |
| 操作の取り消し | 否認した後に取り消したい。否認は取り消せない | 店舗管理者の再申請（APP-04）を待って判断する |

## EVT-09 参加店舗を除外する

- 利用者: イベントの運営者
- 契約: E-06、E-08、P-70（17 行）、P-85、P-93、B-06、AC-17
- 前提: ログインしている。対象のイベントのイベントの運営者である。対象の店舗が参加中

3. 参加が解除される。イベント詳細の参加店舗から店舗と添えた掲載が外れ、店舗詳細と掲載詳細の関連するイベントからイベントが外れる。店舗と掲載の公開状態・提供状態は変わらない

| 操作の取り消し | 実行する前にやめた。参加は変わらない | EVT-07 の参加店舗に戻る |
| 操作の取り消し | 除外した後に取り消したい。除外は取り消せない | 管理者のいない店舗は、EVT-10 で追加する。店舗管理者のいる店舗は、参加申請（EVT-01）を待って EVT-08 で承認する。申請できるのは、イベントが開催前・開催中の間に限られる |

## EVT-10 管理者のいない店舗を参加店舗として追加し、参加内容を変更する

- 利用者: イベントの運営者
- 契約: E-08、E-11、P-70（18 行）、B-06、B-36、I-22、AC-33
- 前提: ログインしている。対象のイベントのイベントの運営者である。対象の店舗に店舗管理者がいない

### 流れ

1. 管理するイベントの参加店舗から、店舗の追加を始める。追加と参加内容の変更は、イベントの開催の状態にかかわらず行える
2. 管理者のいない公開中の店舗をキーワードで探して選ぶ（[index.md](index.md) の「探し方」）
3. その店舗の公開中の掲載から、イベントで提供する掲載を選んで添える。開催期間内の日付から、参加日を添える。どちらも任意で、複数添えられる
4. 追加する。承認は要らず、追加した時点で参加が成立する。イベント詳細の参加店舗と、店舗詳細・掲載詳細の関連するイベントに反映される
5. 管理者のいない参加店舗の参加内容を開き、添えた掲載・参加日を変更して保存する。保存した時点で反映される。店舗管理者の申請で成立し、その後に店舗管理者が不在になった参加も変更できる
6. 店舗に店舗管理者が就いた後は、店舗管理者が EVT-02・EVT-03 で変更と取りやめを行う。参加は保たれる

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 契約（E-11） | 選んだ店舗に、追加するまでの間に店舗管理者が就いた。追加できないことが示される | 店舗管理者の参加申請（EVT-01）を待ち、EVT-08 で判断する |
| 契約（E-11） | 参加内容を保存するまでの間に、店舗に店舗管理者が就いた。変更できないことが示される | 変更をやめる。以後の変更は店舗管理者が行う |
| 入力エラー（I-22） | 公開中でない掲載は、添える対象に示されない | 公開中の掲載から選ぶ。掲載を添えずに追加することもできる |
| 入力エラー | 開催期間の外の日付を参加日にした。追加・保存できないことが示される | 開催期間内の日付に直す |
| リソース不在 | 選んだ店舗が非公開になり、閲覧できない | 別の店舗を選ぶ |
| 入力エラー | すでに参加中の店舗は、候補の中で参加中を理由に選べない対象として示される。選んだ後、追加するまでの間に参加が成立した場合も、参加中であることが示される | 別の店舗を選ぶ。または、その店舗の参加内容を変更する |
| 操作の取り消し | 追加または保存の前にやめた。参加と参加内容は変わらない | EVT-07 の参加店舗に戻る |
| 操作の取り消し | 追加した後に取り消したい | EVT-09 で除外する |

## EVT-11 イベントを中止にし、中止を取り消す

- 利用者: イベントの運営者
- 契約: E-14、V-43、P-70（21 行）、P-77（g）、P-84、P-87（d）、P-93、P-96、B-35、I-08、AC-69
- 前提: ログインしている。対象のイベントのイベントの運営者である

### 流れ

1. 管理するイベントを開き、中止にする。承認は要らず、開催の状態にかかわらず中止にできる。開催しないことになった場合に行い、延期は EVT-04 の開催期間の更新で行う
2. 開催の状態が中止になる。イベントは発見の場面に表示されなくなり、参照の場面では中止を確認して閲覧できる
3. 参加中の店舗の参加は保たれ、店舗管理者は EVT-03 で取りやめられる
4. 参加申請は、申請の前提により失効する
5. 中止中のイベントの中止を取り消す。開催期間を過ぎていても取り消せる。開催の状態は、開催期間と日付で決まる状態（開催前・開催中・終了）に戻る。開催前・開催中に戻ったイベントは、発見の場面に再び表示される。失効した参加申請は戻らない

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| リソース不在 | 別のイベントの運営者がすでに中止にしていた、または中止を取り消していた。現在の開催の状態が示される | 状態を確認して、必要なら操作し直す |
| 操作の取り消し | 実行する前にやめた。開催の状態は変わらない | イベントの管理に戻る |
| 操作の取り消し | 中止を元に戻したい | 中止を取り消す。取り消した後に、再び中止にできる |
| 契約（I-08） | 中止を取り消したが、失効した参加申請は戻らない | 店舗管理者の再申請（APP-04）を待ち、EVT-08 で判断する |
