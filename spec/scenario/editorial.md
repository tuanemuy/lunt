# 読みもの編集

編集担当者が、掲載・店舗・地域・イベントを紹介する読みものを作成・編集・公開し、紹介先の変化に応じて内容を保つ。

## 共通の規則

- すべての操作は、編集担当者の役割を持つアカウントでログインして行う。役割を持たない利用者には読みもの編集の入口が示されず、直接たどり着いても操作できないことが示される。店舗管理者・地域運営者・イベント運営者・サービス運営者も、編集担当者に任命されていなければ読みものを作成・編集・公開できない
- 編集担当者は全員が同じ操作範囲を持ち、誰が作成した読みものも編集・公開・取り下げできる（I-05）
- 通知は ACC-03 の表による
- 同時編集の競合と、その異常系は、[index.md](index.md) の「同時編集の競合」が定める。他の編集担当者が先に公開・取り下げた読みものを公開・取り下げしようとすると、現在の状態が示され、操作は反映されない
- 操作の途中で任命を解かれた利用者の扱いは、[index.md](index.md) の「立場を失ったとき」が定める（AC-75）
- 読みものの公開状態は、下書き・公開・公開の取り下げの3つ。下書きと公開の取り下げは未公開（[index.md](index.md) の「用語」）。閲覧者が閲覧できるのは公開の読みものだけ
- 読みものを削除する操作はない。不要な下書きは下書きのまま残り、公開した読みものをやめるときは公開を取り下げる
- 読みものはサービス全体に属し、地域・イベント・店舗に所属しない。紹介先との結びつきは所属を表さない（P-20）
- 読みものには複数の写真を登録して並び替えられ、1枚目が代表写真になる。見せる範囲の調整はない（I-06）
- 写真の登録のたびの同意と、その入力エラーは、[index.md](index.md) の「写真の登録と同意」が定める
- 紹介先への公開前の確認と事実確認の依頼は、サービス外で行う
- 申立てによって読みものの写真がなくなると、公開が取り下げられる（MOD-02）。写真を登録して再び公開する流れは MOD-03 が定める

## EDT-01 読みものを作成し、下書きを保存する

- 利用者: 編集担当者
- 契約: O-08、P-60、B-19、P-83、M-37、B-53、I-05、I-06

### 流れ

1. 編集担当者は、読みもの編集の入口から読みものの一覧を開く。すべての編集担当者の読みものを、下書き・公開・公開の取り下げの状態とともに確認する
2. 新しい読みものの作成を始める
3. タイトルと本文を入力する
4. 写真を登録する。登録のたびに同意を確認する。複数の写真を登録でき、並び替えられる。1枚目が代表写真になる
5. 紹介先を結びつける場合は EDT-02 へ進む
6. 下書きとして保存する。タイトル・写真・本文がそろっていなくても保存できる。すぐに公開するときは、保存してそのまま公開へ進む（EDT-03 手順2）
7. 下書きは閲覧者に表示されない。読みものの一覧に下書きとして現れ、どの編集担当者も後から編集（EDT-04）・公開（EDT-03）できる

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー | 入力したタイトルの内容に誤りがあり、保存できない。誤りが示される | タイトルを直して保存する |
| 操作の取り消し | 保存せずに作成をやめる | 読みものは作成されず、入力した内容は残らない |
| 操作の取り消し | 保存した下書きが不要になる | 削除する操作はない。下書きのまま残す |

## EDT-02 紹介先の掲載・店舗・地域・イベントを記事に結びつける

- 利用者: 編集担当者
- 契約: O-08、B-54、P-19、P-20、P-87、P-88、V-23、V-33、AC-71
- 前提: 読みものを作成中または編集中である

### 流れ

1. 編集担当者は、読みものの作成・編集の中で、紹介先の追加を始める
2. 掲載・店舗・地域・イベントをキーワードで探す（[index.md](index.md) の「探し方」）。候補は閲覧者が閲覧できる対象で、種類ごとに分かれる。提供開始前・提供終了の掲載、休業・閉店した店舗、終了・中止したイベントは状態を区別して示される
3. 候補から対象を選び、紹介先として結びつける。紹介先は複数結びつけられ、種類を混ぜられる。紹介先は記事に付随する順序つきの一覧になり、本文中の位置は持たない。選んだ対象は一覧の最後に加わる
4. 紹介先を並び替える。記事では、この順で紹介先が表示される
5. 結びつけを外す場合は、結びつけた紹介先から対象を選んで外す
6. 読みものを保存する。紹介先の管理者の承認は要らない
7. 公開中の読みものでは、保存した時点で記事に紹介先が一覧の順で表示され、閲覧者は紹介先の詳細を開ける。紹介先の掲載・店舗・地域・イベントの詳細からは、その読みものをたどれる。外した紹介先は記事から消え、その対象の詳細から読みものをたどれなくなる
8. 未公開の読みものでは、結びつけは保存されるが、閲覧者には表示されない。紹介先の詳細からもたどれない

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| リソース不在 | 探した対象が候補に現れない。非公開・公開の取り下げ・下書き・未登録の対象は候補にならない | 検索語を変えて探し直すか、結びつけずに続ける |
| リソース不在 | 選んだ対象が、保存までの間に非公開・公開の取り下げ・削除で閲覧できなくなる | 保存はできる。その紹介先は記事に表示されず、EDT-06 の閲覧できない紹介先と同じ扱いになる。結びつけを外すか、そのままにする |
| 入力エラー | すでに結びつけた対象は、候補の中で、結びつけ済みを理由に選べない対象として示される | 別の対象を選ぶ。または結びつけずに続ける |
| 操作の取り消し | 保存せずにやめる | 結びつけ・並び替え・解除は反映されない |
| 操作の取り消し | 保存した結びつけを取り消したい | 結びつけを外して保存する。外した結びつけは、同じ対象を結びつけ直して戻す |

## EDT-03 公開前に見え方を確認して公開する

- 利用者: 編集担当者
- 契約: O-08、O-17、B-51、B-10、P-61、P-83、V-11、V-30、V-31、V-46、V-47、AC-62、AC-68
- 前提: 未公開の読みものを作成・編集している、または読みものの一覧から開いている

### 流れ

1. 編集担当者は、読みものの作成・編集の中で保存して、公開へ進む。または、読みものの一覧から未公開の読みものを開く
2. 閲覧者への見え方を確認する。確認は公開の必須手順ではなく、確認せずに手順4へ進める。記事の写真・本文・紹介先と、読みものの一覧やフィードで紹介されるときの見え方を、閲覧者に見えるのと同じ表現で確認する
3. 直したいところがあれば編集に戻り、保存してから再び確認する
4. 公開する。紹介先が1つもなくても公開できる
5. 公開した読みものは、読みものの一覧、キーワード検索の結果、紹介先の詳細から閲覧できる。フィードには自動で紹介の対象になり、エリア・カテゴリーの条件にかかわらず紹介される
6. 読みものの一覧で、状態が公開に変わったことを確認する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 契約（B-51、AC-68） | タイトル・写真・本文のいずれかがない | 公開できず、足りない項目が示される。編集に戻って補い、やり直す |
| 契約（B-10） | 結びつけた紹介先に、閲覧者が閲覧できない対象がある | 見え方の確認と、編集の中の紹介先の現在の状態で、その紹介先が表示されないことが分かる。公開はできる。結びつけを外す・差し替える（EDT-02）か、そのまま公開する |
| リソース不在 | 開いた読みものを、他の編集担当者がすでに公開している | 公開中であることが示される。内容を直すなら EDT-04 へ進む |
| 操作の取り消し | 公開の前にやめる | 未公開のまま残る |
| 操作の取り消し | 公開の後に取り消したい | EDT-05 で公開を取り下げる |

## EDT-04 読みものを編集する

- 利用者: 編集担当者
- 契約: O-08、B-12、B-51、P-60、I-05、I-06

### 流れ

1. 編集担当者は、読みものの一覧から読みものを選ぶ。状態と作成者にかかわらず選べる
2. タイトル、本文、写真（追加・削除・並び替え）、紹介先（追加・並び替え・解除。EDT-02）を直す。写真の追加では、登録のたびに同意を確認する
3. 保存する
4. 未公開の読みものでは、保存しても閲覧者への表示は変わらない。保存してそのまま公開へ進める（EDT-03）
5. 公開中の読みものでは、保存した時点で閲覧者への表示に反映される。公開状態は変わらない

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| 入力エラー | 入力したタイトルの内容に誤りがあり、保存できない。誤りが示される | タイトルを直して保存する |
| 契約（B-51） | 公開中の読みものから、タイトル・本文・すべての写真のいずれかをなくして保存する | 保存できず、公開に必要な項目が示される。項目を補って保存するか、先に EDT-05 で公開を取り下げてから編集する |
| 操作の取り消し | 保存せずにやめる | 読みものは変わらない |
| 操作の取り消し | 保存の後に取り消したい | 保存前の内容に戻す操作はない。編集し直して保存する |

## EDT-05 読みものの公開を取り下げる

- 利用者: 編集担当者
- 契約: O-08、P-83、P-88、P-96、AC-62
- 前提: 公開中の読みものがある

### 流れ

1. 編集担当者は、読みものの一覧から公開中の読みものを選び、公開を取り下げることを確認して確定する
2. 読みものは、読みものの一覧、フィード、キーワード検索の結果、紹介先の詳細のいずれにも表示されなくなる。閲覧者が直接開くと、閲覧できないことが示され、他の探索へ進める
3. 編集担当者の読みものの一覧には、公開の取り下げとして残る。内容と紹介先の結びつけは保たれ、編集できる（EDT-04）
4. 再び公開する場合は、EDT-03 で見え方を確認して公開する

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| リソース不在 | 選んだ読みものの公開を、他の編集担当者がすでに取り下げている | 公開の取り下げであることが示され、何も変わらない。読みものの一覧に戻る |
| 操作の取り消し | 確定の前にやめる | 公開のまま残る |
| 操作の取り消し | 確定の後に取り消したい | EDT-03 で再び公開する |

## EDT-06 紹介先の変化を知り、紹介内容を修正する

- 利用者: 編集担当者
- 契約: O-09、P-96、P-87、P-88、B-10、B-12、B-27、I-05、AC-15
- 前提: 公開中の読みものが、掲載・店舗・地域・イベントを紹介している

### 流れ

1. 公開中の読みものが紹介する対象に変化が起きると、編集担当者に通知が届く。通知する変化は ACC-03 の表による。通知で、読みもの、対象、変化の内容が分かる
2. 編集担当者は、通知から該当の読みものを開く。通知によらず、読みものの編集の中でも、結びつけた紹介先それぞれの現在の状態を確認できる
3. 変化の後の記事の状態を確認する
   - 非公開・公開の取り下げ・削除で閲覧できなくなった紹介先は、記事に表示されず、閲覧者はたどれない。読みものの公開は続く
   - 閉店した店舗、提供終了の掲載、終了・中止したイベントは、紹介先として残り、状態を区別して表示される。閲覧者は詳細を開いて状態を確認できる
   - 本文はどの場合も自動では書き換わらない
4. 紹介内容をどうするかを決めて直す
   - 本文の記述を書き換える（EDT-04）
   - 紹介先の結びつけを外す、または別の対象に差し替える（EDT-02）
   - 記事として成り立たなければ、公開を取り下げる（EDT-05）
   - 直す必要がなければ、何もしない
5. 保存すると、その時点で閲覧者への表示に反映される
6. 結びつけは編集担当者が外すまで残る。非公開の解除や再公開で対象が再び閲覧できるようになると、紹介先は記事に再び表示される。削除された対象は戻らない

### 異常系

| 観点 | 状況 | 利用者の次の操作 |
| --- | --- | --- |
| リソース不在 | 通知から開いた読みものを、他の編集担当者がすでに直しているか、公開を取り下げている | 現在の内容と状態を確認する。直す必要がなければ何もしない |
| 契約（P-96） | 未公開の読みものの紹介先に変化が起きる。通知は届かない | 公開の前に EDT-03 の見え方の確認と紹介先の現在の状態で気づき、EDT-02 で直す |
| 契約（B-51） | 修正で、公開中の読みものからタイトル・本文・すべての写真のいずれかをなくして保存する | 保存できない。EDT-04 の異常系と同じ |
| 操作の取り消し | 保存せずにやめる | 読みものは変わらない |
